## 二、真气运行法概述

### 2.1 理论渊源

真气运行法由李少波教授在潜心钻研《黄帝内经》《道德经》《易经》《勿药元诠》等经典，结合数十年的行医经验与自身实践所创立，是一种自练自养的医疗保健养生方法。

核心理念源自《黄帝内经》：「恬憺虚无，真气从之，精神内守，病安从来。」

李少波试图补充《黄帝内经》「师之隐之」的第七卷「全真导气」内容，揭示上古真人之养生秘技。唐代太仆令王冰在整理《素问》时发现原九卷仅存八卷，缺失的第七卷正是关于养生方法的内容。千年之后，李少波从「全真导气」得到启迪，创立了真气运行学说，揭开了千古之谜。

### 2.2 核心原理

真气运行法通过 **调息凝神，培养真气，贯通经络**，挖掘身体内部的潜能，发挥自我调节、自我修复、自我治疗、自我重建等一系列自我疗能，达到防病治病、延年益寿的效果。

### 2.3 方法特点

| 特点 | 说明 |
|------|------|
| 立足中医科学 | 以《黄帝内经》为理论根基 |
| 简明易学 | 五步功法，操作简单 |
| 克期通督 | 约100天（或集中100小时）可打通任督二脉 |
| 疗效显著 | 对80多种慢性疑难病症有显著调理效果 |
| 无副作用 | 自练自养，不依赖药物 |
| 老少咸宜 | 适应面广 |

## 三、真气运行五步静功（核心功法）

真气运行五步静功分为五个步骤，前一步是后一步的基础。整个过程经历三个阶段：

- **第一阶段（第1-2步）**：「炼精化气」—— 调整呼吸推动真气集中于丹田
- **第二阶段（第3-4步）**：「炼气化神」—— 丹田真气冲通督脉，小周天运转
- **第三阶段（第5步）**：「炼神还虚」—— 经络畅通，静定蓄养

---

### 第一步 · 呼气注意心窝部

| 项目 | 内容 |
|------|------|
| **方法** | 练功准备，放松身心，集中思想，精神内守。在呼气的同时，意念随呼气趋向心窝部。吸气任其自然，不加注意 |
| **时间** | 每日早、中、晚三次，每次20分钟。认真操作，约一周完成 |
| **反应** | 3-5天后心窝部感到沉重；随后每呼气时有一股热流注入心窝部 |
| **效果** | 真气集中的表现，为第二步打基础 |

> ⚠️ **注意**：心窝部即胃区（巨阙穴处），非心脏部位。意念越轻越好，「能用一分就别用两分」。如感觉心脏不适，须立即停止，改为意守小腹。

---

### 第二步 · 意息相随丹田趋

| 项目 | 内容 |
|------|------|
| **方法** | 当第一步做到每一呼气心窝发热时，意息相随，自心窝部开始，呼气注意下丹田（关元穴处）。不可操之过急 |
| **时间** | 每日三次，每次25-30分钟，约10天气沉丹田 |
| **效果** | 脾胃功能改善，食欲增进；大小肠、膀胱、肾等周围脏器产生生理改善 |

> 「丹田」指下丹田，位于脐下三寸（关元穴）深处。

---

### 第三步 · 调息凝神守丹田

| 项目 | 内容 |
|------|------|
| **方法** | 丹田有了明显感觉后，呼气有意无意地止于丹田。呼吸放自然，只将意念守在丹田部位，用**文火温养**（「少火生气」） |
| **时间** | 每日三次以上，每次半小时以上。需较长时间培养丹田实力，约一个月小腹充实有力 |
| **关键** | 不可过分注意呼气往下送，以免发热太过，耗伤阴液——此为「壮火食气」之弊 |

**完成标志**：任脉通畅，心肾相交，中气旺盛。具体表现为：
- 心神安泰，睡眠安静
- 脾胃消化吸收增强，体重增加，精神充沛
- 肾功能增强，阳痿、月经不调改善
- 慢性肝炎、初期肝硬化有明显好转

---

### 第四步 · 通督勿忘复勿助

| 项目 | 内容 |
|------|------|
| **方法** | 原则上仍按第三步操作。真气沿督脉上行时，意识跟随上行的力量——这是「**勿忘**」；若行到某处停下来，不要用意念导引——这是「**勿助**」 |
| **时间** | 每天增加次数，每次延长到40-60分钟。大多数在**10天左右通督** |
| **关键** | 顺其自然，不可追求，不可导引 |

**通督后的效果**（小周天）：
- 一呼真气入丹田，一吸真气入脑海
- 督脉畅通后肾气不断灌溉脑髓，元神力量得到补充
- 改善：头晕耳鸣、失眠健忘、腰酸腿软、月经不调、精神恍惚、心慌气短等
- 长期坚持，多年不愈的顽症也可康复

---

### 第五步 · 元神蓄力育生机

| 项目 | 内容 |
|------|------|
| **原则** | 原则上继续守下丹田（长期意守之处）。若头顶百会穴（上丹田）处有活动力量，也可意守头顶——「**有欲观窍，无欲观妙**」 |
| **时间** | 每日三次，每次一小时或更长。约一个月，体内各种触动现象逐渐消失 |
| **境界** | 下丹田与上丹田互相吸引的磁性力量增强，进入清清静静、心如止水的高级状态 |

**通督后的进阶四层要诀**：

| 层次 | 要领 |
|------|------|
| **因势利导运周天** | 顺自身气机自然流转，不加人为干预 |
| **静守胎息化虚空** | 呼吸渐至细微若有若无，渐入物我两忘 |
| **打破虚空现光明** | 静定功夫深厚后，眼前自然出现柔和光亮 |
| **祥光深处觅真身** | 安稳守定，各类幻象不追随不执着，元气内敛蓄积 |

> 全程原则：**有感不追、入境不慌、见幻不理、顺其自然**。

## 四、练功姿势与要求

### 4.1 四种姿势

| 姿势 | 说明 | 适用场景 |
|------|------|---------|
| **坐式（垂腿）** | 坐椅凳上，大腿面水平，小腿垂直，两脚平放，两手心向下置大腿上 | **主要姿势，最常用** |
| **盘腿坐式** | 双盘/单盘/自由盘腿，两手相合置于小腹前 | 个人习惯选择 |
| **卧式** | 右侧着床伸下腿屈上腿，右手曲肱置于枕上 | 体弱不能坐者，或作为坐功辅助 |
| **站式** | 两脚并立，两手覆于丹田（左手在内，右手在外）| 辅助功 |
| **行式** | 散步时意守鼻尖，三步一呼一步一吸 | 辅助功 |

### 4.2 五官要求

| 部位 | 要求 |
|------|------|
| **口腔** | 口唇自然闭合，上下齿相对，舌尖抵上腭（约90度），唾液分口咽下 |
| **眼睛** | 闭目内视，练哪一步就内视哪一部位 |
| **耳朵** | 留意呼吸，不使发出粗糙声音 |
| **呼吸** | 始终注意呼气，吸气任其自然。通督后外呼吸绵绵密密，若存若无 |

### 4.3 练功须知

- 环境安静，空气清新
- 情绪稳定，不过饱过饥
- 衣着宽松，身体放松
- 持之以恒，循序渐进

## 十、常见问题解答

### Q1：多长时间可以通督？
**A**：按部就班自己锻炼，约100天可沟通任督脉。在老师指导下集中时间练功，一般**百时左右**（集中100小时）即可通督。每人身体条件不同，进步速度也不同。

### Q2：心窝部在哪里？
**A**：心窝部即胃区，位于胸骨剑突下正中凹陷处（巨阙穴），是**一个部位**而非一个点。绝对不可误认为心脏部位。

### Q3：年轻人是否必须从第一步开始？
**A**：传统教学建议从第一步开始。但有经验者认为，年轻人精气充盈可直接从下丹田入手（第三步），得气更快。

### Q4：练功中出现放屁是漏气吗？
**A**：偶尔放屁属正常现象，是肠道功能恢复的表现。但如果长时间持续排气，伴有全身乏力、精神不佳，则可能属于漏气。纠正方法：站式练功，两腿微弯，十趾抓地，提肛，牙齿咬紧。

### Q5：真气运行法和站桩如何配合？
**A**：真气运行偏于静坐养气，站桩偏于立身固根。一动一静搭配最佳：白天站桩稳固身形，晚间静坐培元敛气。
