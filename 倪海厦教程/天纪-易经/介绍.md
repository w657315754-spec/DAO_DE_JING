# 天纪 · 易经

## 概述

《易经》是倪海厦《天纪》体系的核心模块，运用易经原理解释宇宙万物变化规律，揭示天人合一的哲学思想。本课程创造性地将易经64卦与阳宅风水相结合，创立了「易经阳宅学」。

## 课程信息

- **所属体系**：天纪
- **集数**：约 64 集
- **教材**：《天机道》、《地脉道》、《人间道》

## 核心内容

1. **易经基础**：卦与爻、阴阳思维、天地人三才之道
2. **64 卦详解**：逐卦讲解卦象、卦义、卦辞、爻辞
3. **天道**：每一卦在天地自然中的象征意义
4. **人道**：每一卦对应的人生哲理与处世智慧
5. **占卜**：金钱起卦法、卦象解读、事理与时机判断
6. **阳宅应用**：每一卦对应的阳宅风水位置与吉凶判断

## 64 卦学习顺序

倪海厦按照卦序系统讲解全部64卦：乾、坤、屯、蒙、需、讼、师、比、小畜、履、泰、否、同人、大有、谦、豫、随、蛊、临、观、噬嗑、贲、剥、复、无妄、大畜、颐、大过、坎、离、咸、恒、遯、大壮、晋、明夷、家人、睽、蹇、解、损、益、夬、姤、萃、升、困、井、革、鼎、震、艮、渐、归妹、丰、旅、巽、兑、涣、节、中孚、小过、既济、未济。

## 教学特色

- 「传神不传形」：不拘泥于文字表面，注重领悟卦象背后的神韵
- **动态象思维**：同一卦象在不同时间、空间、人事背景下含义不同
- **假设-验证法**：所有理论必须经过实践检验

## 适合人群

- 对易经、中国哲学感兴趣的学习者
- 希望了解天地自然规律的人
- 中医学习者（易经为中医理论的重要源头）
