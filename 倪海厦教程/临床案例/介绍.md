# 临床案例（跟诊实录）

## 概述

倪海厦临床案例系列是《人纪》教学体系中最具实战价值的组成部分，包括倪海厦在美国汉唐中医诊所的临床诊疗实录、弟子跟诊心得及详细的医案记录。这些资料展示了经方在真实临床环境中的运用全过程。

## 课程信息

- **所属体系**：人纪临床实践
- **学习顺序**：学完五部经典后
- **资料规模**：
  - 跟诊实录：100+ 案例
  - 医案汇编：358 篇（7册医案全集）
  - 跟诊心得：159 位学生的心得及倪师批注
- **配套资料**：临床案例视频 + 医案文档 + 方剂解析

## 核心内容

### 诊疗全过程
1. **望闻问切**：四诊合参的完整过程
2. **辨证论治**：从症状到证型的推理过程
3. **方剂选择**：经方选用的决策逻辑
4. **剂量调整**：因人制宜的剂量变化
5. **疗效追踪**：复诊与方剂调整

### 覆盖疾病类型
- 各类癌症（肝癌、肺癌、肾癌、胰脏癌等）
- 心脏病、高血压等心血管疾病
- 糖尿病及代谢综合征
- 肝病系列（肝炎、肝硬化、肝腹水）
- 肾病系列
- 妇科疾病
- 各类疼痛及痹证
- 皮肤病
- 精神类疾病

### 倪海厦经典药方
- 汉唐100方：倪海厦自创及改良的经验方
- 经典配方 259 个
- 汉唐中医专用药方全集

### 方剂解析
每个案例都配有详细的方剂解析，包括：
- 方义分析
- 药物配伍原理
- 剂量选择依据
- 加减变化规律

## 教学特色

- **真实案例**：全部来自临床实际诊疗
- **师徒制教学**：弟子跟诊 + 倪师批注的互动式学习
- **从诊断到处方**：完整展示辨证论治全流程

## 适合人群

- 已系统学完理论的临床实践者
- 中医师、中医学生
- 希望看到经方实战效果的学习者
