# 扶阳论坛演讲

## 概述

2009年10月，倪海厦应邀在上海中医药大学扶阳论坛担任主讲嘉宾，发表了数场重要演讲，引起中国中医界的广泛回响。这些演讲是倪海厦学术思想面向国内中医界的重要展示。

## 课程信息

- **时间**：2009年10月
- **地点**：上海中医药大学扶阳论坛
- **场次**：3 场（上、下 + 完整版）
- **配套资料**：扶阳论坛讲课文字稿、扶阳论坛资料集（第1-7届共90G）

## 核心内容

1. **扶阳理论**：阳气在人体生命活动中的核心地位
2. **经方扶阳**：如何运用伤寒金匮经方扶助人体阳气
3. **现代疾病与阳虚**：当代人普遍阳虚的原因与对策
4. **临床案例分享**：运用扶阳理论治疗重症的实战案例
5. **中西方医学比较**：扶阳理论视角下的中西医思维差异

## 教学特色

- **学术论坛形式**：面向中医界专业人士的正式演讲
- **理论与临床结合**：大量真实病例支撑理论观点
- **引发广泛讨论**：在国内中医界产生重要影响

## 适合人群

- 中医从业者和研究者
- 关注扶阳学派的学习者
- 希望了解倪海厦学术思想的入门者
