# 人纪 · 金匮要略

## 概述

《金匮要略》是东汉张仲景所著的内科杂病诊治宝典。倪海厦在《人纪》第五部中通过大量真实病案，展示如何运用经方治疗从糖尿病到肿瘤的各类疾病，是提升复杂病证处理能力的关键课程。

## 课程信息

- **所属体系**：人纪
- **学习顺序**：第 ⑤ 部（收官之作）
- **集数**：约 77 集
- **教材**：《金匮要略》（张仲景著）

## 核心内容

### 基础篇
- 脏腑经络先后病脉证
- 痉湿暍病脉证治法：桂枝附子汤、甘草附子汤

### 内科杂病
| 病证 | 代表方剂 |
|------|---------|
| 百合狐惑阴阳毒病 | 百合地黄汤、甘草泻心汤 |
| 中风历节病 | 桂枝芍药知母汤、乌头汤 |
| 血痹虚劳病 | 黄芪桂枝五物汤、小建中汤、肾气丸 |
| 肺痿肺痈咳嗽上气病 | 麦门冬汤、葶苈大枣泻肺汤 |
| 胸痹心痛短气病 | 栝楼薤白白酒汤、栝楼薤白半夏汤 |
| 腹满寒疝宿食病 | 大建中汤、大乌头煎 |
| 痰饮咳嗽病 | 苓桂术甘汤、十枣汤、木防己汤、泽泻汤 |
| 消渴小便不利淋病 | 肾气丸、五苓散 |
| 水气病 | 越婢汤、防己黄芪汤、防己茯苓汤 |
| 黄疸病 | 茵陈蒿汤、栀子大黄汤 |

### 外科及杂病
- 疮痈肠痈浸淫病：大黄牡丹汤、薏苡附子败酱散
- 趺蹶手指臂肿转筋狐疝蚘虫病

### 妇人病篇
1. **妊娠病**：桂枝茯苓丸、当归芍药散
2. **产后病**：当归生姜羊肉汤
3. **妇人杂病**：温经汤、半夏厚朴汤、甘麦大枣汤

## 临床案例
- 肺癌案例
- 肺炎案例
- 左肾癌案例

## 教学特色

- **大量临床案例**：每个病证配合真实案例分析
- **经方活用**：展示同一经方在不同疾病中的灵活运用
- **疑难杂症专题**：癌症、心脏病等重症的经方辨证思路

## 适合人群

- 已完成前四部经典学习的进阶者
- 临床中医师
- 希望提升疑难杂症处理能力的学习者
