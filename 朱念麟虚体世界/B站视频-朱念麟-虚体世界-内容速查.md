## 三、核心概念与术语

### 世界观层面

| 概念 | 定义 |
|------|------|
| **实体世界** | 由原子、分子构成的可见物质世界，即我们日常生活的三维世界 |
| **虚体世界（影态空间）** | 由非原子分子构成的不可见物质世界，与实体世界平行存在 |
| **虚体物质** | 看不见摸不着的物质，不是暗物质（暗物质尚未被发现），是朱念麟团队通过实验"发现"的另一类物质 |
| **实体物质** | 原子分子构成的常规物质 |
| **人天科学** | 朱念麟命名的学科，研究实体与虚体世界的统一理论框架 |

### 关系层面

| 概念 | 定义 |
|------|------|
| **纠缠现象** | 实体物质和对应虚体物质之间的同步对应关系——实的变虚的跟着变，虚的变实的也跟着变。朱念麟称其比量子纠缠"复杂上亿倍" |
| **虚实对应** | 每个实体物质都有对应的虚体物质；但一个虚体不一定有对应的实体 |
| **休眠与苏醒** | 绝大多数人的虚体处于休眠状态；少数苏醒且具备能量的人可以影响虚体物质 |

### 九大特性

| # | 特性名称 | 定义 | 关键实验/例子 |
|---|---------|------|-------------|
| 1 | **虚物随心生** | 虚体物质由意念产生，想要什么工具/物品就出现 | 实验中孩子"想要剪刀剪刀就来" |
| 2 | **虚物随心变** | 虚体物质的物理性质可随意改变（大小、软硬等） | 穿瓶实验：让玻璃瓶变软，纸片就穿出来了 |
| 3 | **虚生随身至** | 意念到哪里，虚体就到达哪里 | （未展开讲） |
| 4 | **虚物皆有灵（万物有灵）** | 所有虚体物质都有"灵"，能交流、有记忆 | 茶杯能告诉你生产年份和厂家；书本会"报复"不爱惜它的孩子 |
| 5 | **虚实会纠缠** | 实体与虚体之间的对应变化关系 | 五角星实验：在实体上画圈，虚体上也出现圈 |
| 6 | **虚体信息会滞留** | 过去发生的事在虚体世界留有信息，可以回看 | 功能人可以查看昨天甚至更早的信息 |
| 7 | **虚体信息自然成网状结构** | 虚体信息之间互相关联，找到一个就牵出一串 | 人民币信息追踪：从一张钱可以追溯到持有者的全部个人信息 |
| 8 | **虚体时间超前** | 虚体世界的时间比实体世界超前 | 虚体世界已发生的事，实体世界尚未发生；可用于预测 |
| 9 | **虚体工具和设备的有效性** | 虚体世界存在可用的工具和设备 | 虚体摄影、虚体医学等应用 |

## 四、关键实验

### 实验一：玻璃瓶穿纸（张宝胜·507 所）

| 项目 | 内容 |
|------|------|
| **类型** | 物理穿越 |
| **实验者** | 张宝胜（507 所功能人） |
| **方法** | 密封玻璃瓶内放折叠纸片，功能人摇手使纸片从瓶中飞出 |
| **结果** | 纸片穿出，瓶身无任何破损，玻璃材料完全一致 |
| **设备** | 高速摄像机抓拍——纸片一半在瓶内一半在瓶外的瞬间 |
| **意义** | 证明物质可以穿越固体容器 |

### 实验二：遁术滞空实验（林书煌团队）

| 项目 | 内容 |
|------|------|
| **类型** | 遁术 + 滞空 |
| **实验者** | 林书煌（北京师范学院物理系）团队 |
| **设备** | 自制仪器：指针式电子钟 × 3 + 调频发射机 + 接收机 + 果蝇 |
| **方法** | 将整套仪器遁走，在空中停留几十分钟，再收回 |
| **结果** | ①果蝇仍活着 ②三个电子钟一秒不差 ③发射机信号在消失期间中断、出现后恢复 |
| **结论** | 遁走的物质在不可见状态下一切物理/化学/生物过程正常进行 |
| **重复次数** | 团队做了 4 次，后来多人重复成功 |
| **意义** | 第一个奠基石——证明存在看不见摸不着的物质（虚体物质） |

### 实验三：钟表自动现象（朱振龙、罗鑫 → 1025 实验室）

| 项目 | 内容 |
|------|------|
| **类型** | 特异钟表自动 |
| **发现者** | 朱振龙、罗鑫（1980 年） |
| **方法** | 功能人让指针式手表/小闹钟突然走几十分钟 |
| **1025 实验室改进** | 在钟内安装传感器（类机械鼠标原理），记录指针走动的信号波形 |
| **新发现** | 火柴自动后留下刀痕、剪刀痕、钳子痕、笔迹等多种工具痕迹 |
| **意义** | 证明存在看不见的工具 |

### 实验四：指纹实验（1025 实验室）

| 项目 | 内容 |
|------|------|
| **类型** | 指纹验证 |
| **方法** | 功能人用红色印泥按指纹 → 对封闭瓶内物体做实验 → 再当面用绿色印泥按指纹 |
| **结果** | 封闭瓶内出现与当面按的完全相同的指纹（红色），孩子手上无印泥残留 |
| **结论** | 证明确实有看不见的人（功能人的虚体）在操作 |
| **意义** | 确立"看不见的人"的存在 |

### 实验五：纠缠实验（五角星）

| 项目 | 内容 |
|------|------|
| **类型** | 虚实纠缠 |
| **方法** | 在实体五角星中间画蓝色圈 → 虚体五角星中间也出现蓝色圈；切掉虚体五角星的顶 → 实体五角星也缺失 |
| **类比** | 双胞胎感应（姐姐在手术室外感受到妹妹的疼痛） |
| **意义** | 证明实体与虚体之间存在纠缠关系 |

## 五、应用技术

### 虚体摄影

| 项目 | 内容 |
|------|------|
| **原理** | 让功能人的虚体找到手机的虚体，在虚体世界拍照。因虚实纠缠，实体手机芯片中多出对应文件 |
| **掌握人数** | 至少 50 人 |
| **技术细节** | 需要打光（虚体光与感光器材灵敏度不匹配）；可"随心变"（拍冬天的树而非夏天的树） |
| **医学应用** | 不用造影剂直接拍心脏血管，可叠加患者姓名、身份证号等信息 |
| **天文应用** | 意念追上流星并拍摄特写 |

### 实病虚治

| 项目 | 内容 |
|------|------|
| **原理** | 实体器官有对应虚体器官，在虚体世界去除病灶，实体对应部位自然恢复 |
| **案例 1：脑梗** | 河北患者，三次脑梗住院 3 年；昆明功能人远程治疗三次，完全恢复 |
| **案例 2：鼻梁骨折** | 西安患者，骑车摔倒致鼻子和眼眶骨头塌陷；昆明小同学远程不到半小时复原 |
| **案例 3：七楼坠落** | 初中生腰椎断裂 + 脚三处粉碎性骨折；同学远程治疗，六个月后走路正常无残疾 |
| **案例 4：下颌骨发育不全** | 女孩先天无下巴，上下牙无法咬合；小朋友治疗半小时后下巴长出 |

### 虚体信息查阅（利用时间差）

| 项目 | 内容 |
|------|------|
| **原理** | 虚体世界时间超前于实体世界 |
| **案例：长征 22 号火箭** | 小学五年级学生查到 2049 年 10 月 1 日发射的火箭名称、形状、燃料（甲烷）——提前 27 年 |
| **其他应用** | 查找微生物学、核物理学、中医理论等专业前沿资料 |

### 虚体古籍引进

| 项目 | 内容 |
|------|------|
| **原理** | 从虚体世界引进实体世界已失传或未发现的书籍 |
| **案例** | 初中生抄回两本新医学理论书籍（涉及经络、穴位和"内经"概念）；小学生抄回中医理论书籍（脉络、全息等） |

### 经络研究

| 项目 | 内容 |
|------|------|
| **发现** | 功能人可直接看到经络和穴位 |
| **重要纠正** | 现行国家标准经络穴位图有错误——将经络全部画在皮肤上，实际胸腔腹腔内的经络不在体表 |
| **肺经重绘** | 用电脑动画重新绘制：起于大肠 → 上轴线分叉左右背 → 气管汇合 → 喉咙分开 → 手腕分叉（大拇指表皮 / 食指深层） |
| **虚体摄影经络** | 尝试中，已拍到局部经络和穴位，但完整图像仍有缺陷 |

### 学习辅助

| 项目 | 内容 |
|------|------|
| **应用** | 利用"万物有灵"特性，让书本"教"孩子；减轻学习负担同时提高成绩 |
| **推广** | 已在培训机构中大量采用 |

## 六、超常现象分类体系

演讲中归纳的四类超常现象，横跨物理学、化学、生物学、信息学四大基础学科：

| 类别 | 典型现象 | 案例 |
|------|---------|------|
| **物理类** | 物质穿越固体、物体消失/遁走 | 张宝胜玻璃瓶穿纸、遁术实验 |
| **化学类** | 选择性化学反应 | 一盒火柴只烧一根（旁边的不着） |
| **生物类** | 生物过程逆转 | 鸡蛋返生（熟鸡蛋变回生鸡蛋，蛋白质复流） |
| **信息类** | 超常规信息获取 | 功能人拍摄的照片中出现异常（太阳跑到大楼前面） |

演讲的核心论点：现代科学的三大基础学科（物理、化学、生物）在底层互不相交，但超常现象同时横跨三者，现有框架无法解释，需要新的统一理论——"人天科学"。

## 八、关键论断与金句

### 核心论断

1. **世界由实体和虚体共同组成**——不是只有原子分子
2. **虚体物质比实体多很多很多**——但只有一小部分与实体有纠缠关系
3. **改变虚体可以改变实体**——这是第二条路径（第一条是物理/化学/生物方法）
4. **绝大多数人的虚体处于休眠状态**——可以唤醒、培养
5. **超常现象横跨物理/化学/生物/信息四大学科**——现代科学框架无法解释
6. **虚体时间超前于实体时间**——可用于预测
7. **万物有灵不是迷信而是科学规律**——虚体物质都有"灵"

### 演讲者金句

- "我只是站在巨人的肩头上……是他们把我的水平抬高的，包括钱学森。"
- "光分类这个问题就弄了 20 多年，也没法弄清楚。"
- "（纠缠现象）比量子纠缠复杂上亿倍。"
- "成吨的虚体物质每天从我们身体里面穿过，我们不知道。"
- "指纹是不可能画出来的，只能用手按。"
- "我们创立这门科学是为了服务人类，不是为了改变谁的三观。"

## 九、待验证/存疑事项

以下内容在演讲中以"事实"呈现，但缺乏独立第三方验证或存在争议：

| 事项 | 疑点 |
|------|------|
| 遁术实验的可重复性 | 仅提及团队内部重复 4 次及"很多人重复"，未见独立实验室验证 |
| 鸡蛋返生 | 2021 年"熟鸡蛋返生"论文曾引发学术造假争议并被撤稿，本演讲中的版本更为激进（去壳返生） |
| 虚体摄影 | 声称手机芯片会"自动多出文件"，未提供原始数据供独立检验 |
| 实病虚治案例 | 仅展示前后对比照片，未见医学影像、诊断报告等客观证据 |
| 长征 22 号火箭预测 | 声称查到 2049 年的火箭信息，无法在当前验证 |
| 经络可视化 | 声称发现国家标准经络图有错误，但重绘结果尚未经同行评议 |
| 万物有灵 | 茶杯能"讲话"、书本会"报复"等说法缺乏可检验的实验设计 |
| 507 所相关实验 | 507 所的人体科学研究在 1990 年代末已大幅收缩，部分早期实验的严谨性受到质疑 |

## 十、相关领域与延伸阅读方向

| 方向 | 说明 |
|------|------|
| **人体科学（Somatic Science）** | 钱学森 1980 年代倡导的学科，研究人体特异功能、气功等，1990 年代末逐渐边缘化 |
| **超心理学（Parapsychology）** | 西方对应学科，研究 ESP、心灵感应、遥视等，SPR 是其先驱 |
| **量子意识 / 量子生物学** | 试图用量子力学解释意识和生物现象的前沿交叉领域 |
| **道教内丹学** | 中国传统修炼体系中的"元神"、"玄关"、"虚室生白"等概念与"虚体"有某种呼应 |
| **暗物质 / 暗能量** | 现代物理学中"不可见物质"的研究，但方法与朱念麟完全不同 |
| **全息理论（Holographic Principle）** | 物理学前沿理论，认为三维信息可编码在二维面上，与"纠缠"有概念交叉 |
