# 皇极经世总览

## 一句话定义

《皇极经世》是北宋邵雍（邵康节）毕生研究《周易》后创立的经天纬地之学，以河洛数理和先天象数为基础，构建了一套从宇宙生成到文明兴衰的宏大数理模型。

## 基本信息

| 项目 | 内容 |
|------|------|
| 全名 | 《皇极经世书》 |
| 作者 | 邵雍（1011-1077），字尧夫，号康节 |
| 成书 | 北宋中后期（约 1071 年完成），邵雍晚年隐居洛阳 |
| 卷数 | 12 卷 64 篇 |
| 性质 | 河洛数术之书 / 数理宇宙学 |
| 英文名 | *Book of Supreme World Ordering Principles* (Huangji Jingshi Shu) |
| 学术定位 | 北宋理学"象数派"核心典籍 |

## 书名释义

- **皇极**：皇者，大也；极者，至也。"皇极"即"至极之理"——宇宙间最根本、最极致的法则
- **经世**：经，经纬、经纶；世，世界、世运。"经世"即以数理经纬天地、推演世运
- 合义：**以至极之理，经纬天地世运**

## 全书结构

```
《皇极经世书》12 卷 64 篇
├── 首六卷（34 篇）：《元会运世》
│   ├── 以元经会（卷一、卷二）
│   ├── 以会经运（卷三、卷四）
│   └── 以运经世（卷五、卷六）
│   └── → 历数：日月运行之变数，宇宙时间架构
│
├── 次四卷（16 篇）：《声音律品》
│   └── → 律数：日月星辰、水火土石之变化数
│   └── → 如《易》之有上下经六十四卦
│
├── 次二卷（12 篇）：《观物内篇》
│   └── → 邵雍自著，阐述核心象数理论
│   └── → 如《易》之有《系辞》
│
└── 末二篇（2 篇）：《观物外篇》
    └── → 门人弟子记述
```

> 邵雍之子邵伯温的原话："以元经会、以会经运、以运经世六卷三十四篇者，日月运行之变数，是为**历数**也。声音律吕相唱和四卷一十六篇者，日月星辰水火土石之变化数，是为**律数**也。余二卷十二篇之文，所以畅二数之义，如《易》之有《系辞》也。"

## 核心贡献

### 1. 元会运世时间体系

邵雍将时间划分为四个嵌套层级，构建了一套宏大的宇宙历史年表：

```
1 元 = 12 会 = 129,600 年（天地从生成到毁灭的完整周期）
1 会 = 30 运 = 10,800 年（一个文明兴衰的大周期）
1 运 = 12 世 = 360 年（一个重要的变革周期）
1 世 = 30 年（一代人）
```

> 进制来源：12 和 30，源于"一年有 12 个月、一月有 30 天"的天文观察。

### 2. 先天象数学

- 继承并发展了伏羲先天八卦的数理体系
- 创制了先天圆图和先天方图
- 将六十四卦与时间周期精密对应
- 每一会、每一运、每一世都有对应卦象

### 3. 观物哲学

- "以物观物"——排除主观成见，以事物本身的数理来认识事物
- "数理即天理"——宇宙的运行法则完全可以通过数学来演绎
- "天人互参"——天地的"大命运"与个人的"小命运"全息对应

### 4. 历史年表

- 从唐尧时代开始，以"以运经世"纪年表标注历史事件
- 将朝代兴亡纳入数理框架
- 构建了中国古代最宏大的历史周期模型

### 邵雍的学术特点

- 不同于程朱理学的"性理"路线，走的是"象数"路线
- 认为数是宇宙的本源，"数生象，象生器"
- 融合《周易》、河图洛书、道家宇宙论
- 钱穆指出：庄周、邵雍为"观物派"哲学

## 与《周易》的关系

| 维度 | 《周易》 | 《皇极经世》 |
|------|----------|-------------|
| 性质 | 卜筮之书 + 哲学经典 | 数理宇宙学 |
| 核心 | 六十四卦 + 卦爻辞 | 元会运世 + 先天象数 |
| 时间观 | 无系统时间框架 | 129,600 年宇宙周期 |
| 数学性 | 隐含数理（大衍之数） | 显性数理（精确计算） |
| 目标 | 占断吉凶 | 推演宇宙与历史 |

## 历史影响

### 宋代

- 邵雍生前已是洛阳名士，"安乐窝"成为学术交流中心
- 司马光、富弼等重臣皆为其友
- 程颢评价："尧夫，内圣外王之学也"

### 后世传承

| 时代 | 传承者 | 贡献 |
|------|--------|------|
| 北宋 | 邵伯温（邵雍之子） | 整理《皇极系述》，注释父书 |
| 南宋 | 朱熹 | 在《周易本义》中引用邵雍先天图 |
| 明代 | 黄畿 | 《皇极经世传》 |
| 清代 | 王植 | 《皇极经世直解》 |
| 当代 | 唐明邦 | 当代《皇极经世》研究权威 |

### 衍生应用

- **铁板神数**：以元会运世为核心引擎的命理推算体系
- **皇极分经数**：明代宫廷御用，铁板神数条文始祖
- **先天八卦图**：邵雍重新发现的先天八卦排列，成为后世标准
- **梅花易数**：相传亦为邵雍所创（存疑）

## 版本流传

- 邵雍生前未完全定稿，后由弟子张岷、程颢等整理成书
- 经邵伯温整理后传世
- 《四库全书》收录，称其"辞约义丰"
- 当代有常秉义注释的《皇极经世导读》（2009 年，中央编译出版社）
