# 对冲基金算法总览

## 一句话定义

量化对冲基金（Quant Hedge Fund）是使用高级数学模型、统计算法和计算机程序来做出投资决策的对冲基金，通过系统化的交易策略在市场低效性中获取绝对收益。

## 发展简史

| 时间 | 里程碑 |
|------|--------|
| 1949 | Alfred Jones 创立第一只对冲基金（多空策略） |
| 1960s-70s | NYSE 日交易量暴增 240%，计算机开始进入交易后台 |
| 1970s | Charles Dow 的技术分析成为最早的系统化市场预测方法 |
| 1980s | Renaissance Technologies（1982）、D.E. Shaw（1988）成立，量化基金正式崛起 |
| 1990s | 量化基金快速成长，统计套利、高频交易等策略广泛应用 |
| 2000s | 机器学习、强化学习开始融入量化策略 |
| 2010s | 另类数据（卫星图像、社交媒体、NLP）成为新的 alpha 来源 |
| 2020s | AI 驱动策略、深度学习模型成为行业标配 |
| 2023 | 全球最大对冲基金 Field Street Capital 管理 $2,980 亿 |
| 2024 | 量化基金集体表现强劲，多家头部收益超 20% |

## 对冲基金 vs 共同基金

| 维度 | 对冲基金 | 共同基金 |
|------|----------|----------|
| 监管 | 较少监管，面向合格投资者 | 强监管，面向公众 |
| 策略自由度 | 可做空、用杠杆、衍生品 | 以做多为主 |
| 费用 | 2/20 模式（2%管理费+20%绩效） | 低管理费（0.05%-1%） |
| 目标 | 绝对收益（无论市场涨跌） | 相对收益（跑赢基准） |
| 门槛 | 高（$100万+起投） | 低（$100起投） |
| 流动性 | 锁定期长，赎回限制多 | 每日可赎回 |
| 典型规模 | 数十亿至数千亿美元 | 数千亿至数万亿美元 |

## 量化基金的核心优势

### 1. 消除情绪偏差
人类情绪在交易中往往是有害的。算法严格执行预设规则，不受恐惧和贪婪影响。

### 2. 速度与规模
计算机能在毫秒内分析海量数据并执行交易，捕捉人工无法察觉的市场低效。

### 3. 回测验证（Backtesting）
策略上线前可用历史数据严格测试其有效性，过滤掉无效策略。

### 4. 风险分散
可同时跨市场、跨资产、跨策略运行，天然分散风险。

### 5. 可复制性
成功的策略可以程序化复制，扩展到更大资金规模。

## 主要资产类别

量化基金交易的市场：
- **股票**（Equities）— 单只股票、ETF
- **外汇**（FX）— 货币对
- **固定收益**（Fixed Income）— 债券、利率衍生品
- **大宗商品**（Commodities）— 原油、金属、农产品
- **股指期货**（Index Futures）— 全球指数
- **期权**（Options）— 波动率策略
- **加密货币**（Crypto）— BTC、ETH 等

## 中国市场特色

| 特征 | 说明 |
|------|------|
| T+1 交易 | A 股无法日内反转，限制高频策略 |
| 印花税 | 卖出 0.05% 印花税 |
| 做空限制 | 融券受限，对冲工具不足 |
| 主流量化私募 | 幻方、九坤、明汯、灵均等 |
| 核心策略 | 统计套利（价量模型），预测周期日内到数天 |
| 外资高频 | 主要存在于 T+0 的期货市场 |
