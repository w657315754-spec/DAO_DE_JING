# 热力学与统计物理

> 从蒸汽机的轰鸣到原子的涨落，热力学以宏观定律描绘能量流转，统计物理以微观概率重塑其根基——二者相辅相成，构筑起连接可逆与不可逆、确定与随机的壮丽桥梁。

---

## 一、热力学四大定律

热力学四大定律是整个学科的基石。它们并非由演绎推出，而是源自对热、功与温度的实验归纳，依次回答了"何谓温度""能量如何守恒""演化朝向何方""绝对零度能否抵达"四个根本问题。

### 1.1 四大定律一览

| 定律 | 核心命题 | 关键公式 | 提出者 / 年代 |
| :--- | :--- | :--- | :--- |
| 第零定律 | 热平衡的传递性定义温度 | 若 $A\sim B,\ B\sim C$，则 $A\sim C$ | 福勒（R. Fowler），1931 |
| 第一定律 | 能量守恒，热是能量的一种传递形式 | $\Delta U = Q - W$ | 迈尔、焦耳、亥姆霍兹，1840s |
| 第二定律 | 孤立系熵不减，过程有方向 | $dS \ge \delta Q / T$ | 克劳修斯、开尔文，1850s |
| 第三定律 | 绝对零度不可有限步达及 | $\lim_{T\to 0} S \to 0$（完美晶体） | 能斯特（W. Nernst），1906 |

### 1.2 第零定律：热平衡与温度的诞生

第零定律虽位列最末命名，逻辑上却最为先行：若两系统分别与第三系统处于热平衡，则二者亦彼此热平衡。这看似平凡的传递性，正是"温度"这一态函数得以定义的依据——互为热平衡的系统具有相同温度。

### 1.3 第一定律：能量守恒的登场

内能 $U$ 是态函数，热 $Q$ 与功 $W$ 是过程量。第一定律写作

$$\Delta U = Q - W,\qquad dU = \delta Q - \delta W$$

其中 $W$ 取系统对外做功为正。它确立了"第一类永动机不可能"——能量不能无中生有。

### 1.4 第二定律：方向之矢

第二定律以两种经典表述并存：

- **克劳修斯表述**：热量不能自发地从低温物体传向高温物体。
- **开尔文表述**：不可能从单一热源吸热使之完全变为功而不产生其他影响。

二者等价，共同指向"第二类永动机不可能"。其数学形态即熵增原理：

$$dS \ge \frac{\delta Q}{T}$$

### 1.5 第三定律：绝对零度的边界

能斯特定理指出，温度趋于绝对零度时，完美晶体的熵趋于常数（可取为零）。由此推论：不可能经有限步操作使系统降至绝对零度。它为熵的绝对标定提供了基准。

### 1.6 历史与应用

卡诺（S. Carnot）于 1824 年研究热机效率，提出卡诺定理：所有工作于两恒温热源间的热机，以可逆机效率最高

$$\eta_{\max} = 1 - \frac{T_C}{T_H}$$

这一上限至今指导蒸汽轮机、内燃机与制冷机的设计——提高高温热源温度、降低低温热源温度，是提升效率的不二法门。

## 二、熵的热力学与统计诠释

熵是物理学中最富哲学意味的量。它既可由宏观热量定义，又能由微观状态数给出，二者的等价正是热力学与统计物理的接合点。

### 2.1 两种熵的对照

| 诠释 | 提出者 | 定义式 | 立足点 |
| :--- | :--- | :--- | :--- |
| 热力学熵 | 克劳修斯（1865） | $dS = \delta Q_{\text{rev}} / T$ | 宏观可逆过程 |
| 统计熵 | 玻尔兹曼（1877） | $S = k_B \ln W$ | 微观状态数 |

### 2.2 克劳修斯熵

对可逆过程，熵变为热量除以温度。熵是态函数，其变化只取决于初末态：

$$\Delta S = \int \frac{\delta Q_{\text{rev}}}{T}$$

### 2.3 玻尔兹曼熵

玻尔兹曼以墓碑上的公式 $S = k_B \ln W$ 将宏观熵与微观状态数 $W$ 相联：状态数越多、越无序，熵越大。这赋予熵以"无知"与"信息"的统计含义，为信息论埋下伏笔。

### 2.4 熵增与时间箭头

孤立系熵不减，故自发过程总是朝熵增方向演化。这是物理学中唯一显含时间不对称的定律，由此引出"时间箭头"——过去与未来在微观可逆方程中对称，唯在宏观统计中分出先后。

### 2.5 麦克斯韦妖

1867 年麦克斯韦设想一"妖"守于分隔壁小门，依分子速度择门放行，使一侧变热一侧变冷，似乎可逆地降低系统熵，挑战第二定律。直至 20 世纪，朗道尔（Landauer）与贝奈特（Bennett）指出：妖获取并擦除信息的代价至少补偿所减之熵，第二定律得以保全。此论成为信息与热力学交融的经典范例。

## 三、热力学势与自由能

对不同约束条件，应选取恰当的热力学势作"自发方向"的判据，正如力学中视约束择拉氏或哈密顿量。

### 3.1 四大热力学势

| 名称 | 符号 | 定义 | 自然变量 | 自发判据（等条件下） |
| :--- | :--- | :--- | :--- | :--- |
| 内能 | $U$ | — | $S, V$ | $dU \le 0$（等熵等容） |
| 焓 | $H$ | $H = U + pV$ | $S, p$ | $dH \le 0$（等熵等压） |
| 亥姆霍兹自由能 | $F$ | $F = U - TS$ | $T, V$ | $dF \le 0$（等温等容） |
| 吉布斯自由能 | $G$ | $G = H - TS$ | $T, p$ | $dG \le 0$（等温等压） |

### 3.2 各势的动机

- **焓**：等压过程中 $H$ 的变化等于 exchanged 热量，便于处理敞口化学反应。
- **亥姆霍兹自由能**：等温等容下，$F$ 减少部分即系统可对外输出的最大功。
- **吉布斯自由能**：等温等压——实验室与生物体最常见的条件——下，$G$ 降低者自发。

### 3.3 化学势与相平衡

多组分系统中引入化学势 $\mu_i = (\partial G / \partial n_i)_{T,p}$。相平衡条件为各相中每一组分的化学势相等：

$$\mu_i^{\alpha} = \mu_i^{\beta} = \cdots$$

由此可导出克拉珀龙方程 $\frac{dp}{dT} = \frac{\Delta S}{\Delta V}$，描述相图上相界曲线的斜率。

### 3.4 历史与应用

吉布斯（J. W. Gibbs）以深邃的几何直觉统一了这些势，其 1876 年论文奠定了化学热力学。今日判断化学反应自发性、计算电池电动势、预测相图，无不以 $\Delta G$ 为准绳：$\Delta G < 0$ 自发，$\Delta G = 0$ 平衡，$\Delta G > 0$ 需外界驱动。

## 四、玻尔兹曼分布与配分函数

统计物理的核心策略，是以概率分布替代对 $10^{23}$ 个粒子的逐一追踪。不同环境约束对应不同系综，而配分函数则是通往一切热力学量的"母函数"。

### 4.1 三大系综

| 系综 | 守恒量 | 代表系统 | 粒子数/能量 |
| :--- | :--- | :--- | :--- |
| 微正则 | $E, V, N$ | 孤立系 | 能量严格固定 |
| 正则 | $T, V, N$ | 闭系热浴 | 能量可涨落，粒子数固定 |
| 巨正则 | $T, V, \mu$ | 开系 | 能量与粒子数皆可涨落 |

### 4.2 玻尔兹曼分布与配分函数

正则系综中，系统处于能量 $E_s$ 的概率为

$$P_s = \frac{e^{-\beta E_s}}{Z},\qquad \beta = \frac{1}{k_B T}$$

其中配分函数

$$Z = \sum_s e^{-\beta E_s}$$

是对所有微观状态的玻尔兹曼因子求和。它犹如统计物理的"生成函数"，囊括了全部热力学信息。

### 4.3 从配分函数导出热力学量

$$F = -k_B T \ln Z,\qquad U = -\frac{\partial \ln Z}{\partial \beta},\qquad S = k_B\left(\ln Z + \beta\frac{\partial \ln Z}{\partial \beta}\right)$$

巨正则系综则配以巨配分函数 $\Xi = \sum_{N,s} e^{-\beta(E_s - \mu N)}$，进而 $pV = k_B T \ln \Xi$。

### 4.4 历史与应用

玻尔兹曼与吉布斯分别从气体分子论与普遍系综理论奠定其基础。今日由配分函数出发，可计算固体比热、黑体辐射谱、顺磁磁化强度等；量子统计只需将求和换作对量子态的求和或积分，玻色—爱因斯坦与费米—狄拉克分布自然从中浮现。

## 五、相变与统计模型

相变是统计物理最瑰丽的篇章：无数微观粒子的协同作用，竟能在宏观上骤然催生全新的有序相。

### 5.1 相变的级

| 类型 | 特征 | 熵变 | 典型例子 |
| :--- | :--- | :--- | :--- |
| 一级相变 | 有潜热、体积突变、两相共存 | $\Delta S \ne 0$ | 冰融、水沸腾 |
| 连续相变 | 无潜热、比热等导数奇异 | $\Delta S = 0$ | 铁磁居里点、超流转变 |

### 5.2 临界现象与标度律

连续相变在临界点附近出现普适的幂律行为，以临界指数刻画：$\xi \sim |T-T_c|^{-\nu}$（关联长度）、$M \sim |T-T_c|^{\beta}$（序参量）。不同系统按维数与对称性归入同一"普适类"，临界指数相同。标度律与超标度关系进一步约束各指数间的联系，揭示深刻的普适性。

### 5.3 伊辛模型与重整化群

伊辛模型以自旋 $\sigma_i=\pm1$ 格点及最近邻作用 $-J\sum \sigma_i\sigma_j$ 捕捉铁磁相变。一维无相变，二维由昂萨格（L. Onsager）1944 年精确求解，展示比热对数奇异性。

更深刻的突破来自威尔逊（K. Wilson）的重整化群（RG）：不断"粗粒化"并重标度，追踪耦合常数在标度变换下的流向。临界点即 RG 的不动点，临界指数由其线性化本征值决定。这一框架统一了相变、场论与多体物理。

### 5.4 对称性破缺

对称性破缺是相变的灵魂：高温相具有完整对称性，低温有序相则自发选取某一对称破缺方向。序参量（如磁化强度）为零处对称未破，非零处对称已破。朗道以自由能对序参量的展开 $F = F_0 + a(T-T_c)M^2 + bM^4 + \cdots$ 唯象地刻画了这一机制。

## 六、非平衡态热力学

平衡态是死亡的寂静，真实世界充满流动与耗散。非平衡态热力学致力于将第二定律推广到开放、流动、持续耗散的过程之中。

### 6.1 熵产生与流

系统熵变分为熵流与熵产生：

$$dS = dS_e + dS_i,\qquad dS_i \ge 0$$

其中 $dS_e$ 源自与外界交换，$dS_i$ 为内部不可逆过程所生，恒非负。

### 6.2 昂萨格倒易关系

近平衡区，力 $X_j$ 与流 $J_i$ 呈线性耦合 $J_i = \sum_j L_{ij}X_j$。昂萨格（L. Onsager）由微观可逆性证明

$$L_{ij} = L_{ji}$$

即交叉耦合系数对称。这是线性不可逆热力学的基石，亦为其赢得 1968 年诺贝尔化学奖。

### 6.3 最小熵产生原理

在线性区且定态约束下，系统的熵产生率随时间递减，至定态取极小：

$$\frac{d}{dt}\left(\frac{dS_i}{dt}\right) \le 0$$

这赋予非平衡定态以稳定性，是平衡态最小自由能原理在近平衡区的延伸。

### 6.4 耗散结构

远离平衡时，线性理论失效。普利高津（I. Prigogine）指出：开放系统在远离平衡、且存在非线性反馈时，可自发形成时空有序结构——贝纳德对流、化学振荡（B-Z 反应）皆是。此类"耗散结构"靠持续消耗能量与物质维持，于 1977 年获诺贝尔化学奖。

### 6.5 生命与熵

薛定谔（E. Schrödinger）在《生命是什么》（1944）中提出"生命以负熵为食"：生物体以摄入低熵（有序）食物、排出高熵废热的方式维持自身有序，整体仍遵从第二定律。这一洞见将生命现象纳入热力学框架，启迪了生物物理与信息生物学的发展。

### 6.6 历史脉络

| 人物 | 贡献 | 年代 |
| :--- | :--- | :--- |
| 昂萨格 | 倒易关系 | 1931 |
| 普利高津 | 最小熵产生、耗散结构 | 1945–1969 |

> 热力学以四定律立其骨，统计物理以概率与配分函数充其血肉；从卡诺的蒸汽机到普利高津的耗散结构，从玻尔兹曼的墓碑到薛定谔的生命之问——这是一部关于"时间为何只朝一方流"的宏大叙事。
