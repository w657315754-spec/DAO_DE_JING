## 核心脉络

```
经典力学 ── 确定性的世界图景
电磁学 ── 场论的诞生，光即电磁波
热力学 ── 统计性与时间箭头
量子力学 ── 概率性取代确定性
光学 ── 波粒二象性的舞台
粒子物理 ── 标准模型：三种力的统一框架
```

物理学的发展是一条从"确定性"走向"概率性"、从"粒子"走向"场"再走向"对称性"的路线。本目录沿此线索展开，每篇独立可读，篇间交叉引用。
