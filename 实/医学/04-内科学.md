# 内科学

> 内科学乃临床医学之根基，以系统为纲，以病理为目，循证而行，辨病而治。本文按六大系统梳理常见疾病之定义、机制、诊断与治疗框架，力求结构清晰、术语精准，以备研习与查阅。

---

## 一、心血管系统疾病

### 1.1 原发性高血压

原发性高血压是以体循环动脉血压持续升高为主要表现的慢性疾病，占高血压人群的90%以上，其发病与遗传、环境、肾素-血管紧张素-醛固酮系统（RAAS）激活及内皮功能紊乱密切相关。

**血压分级标准（JNC-7 / 中国指南）**

| 分级 | 收缩压（mmHg） | 舒张压（mmHg） |
|------|----------------|----------------|
| 正常血压 | <120 | <80 |
| 高血压前期 | 120–139 | 80–89 |
| 1级高血压（轻度） | 140–159 | 90–99 |
| 2级高血压（中度） | 160–179 | 100–109 |
| 3级高血压（重度） | ≥180 | ≥110 |
| 单纯收缩期高血压 | ≥140 | <90 |

**靶器官损害**
- **心脏**：左心室肥厚、冠状动脉粥样硬化、心力衰竭
- **脑**：脑卒中、短暂性脑缺血发作、认知障碍
- **肾脏**：微量白蛋白尿、肾硬化、慢性肾病
- **血管**：动脉硬化、主动脉夹层
- **眼底**：视网膜动脉硬化、出血、渗出（Keith-Wagener分级）

**治疗原则**：非药物干预（低盐、减重、运动）为基石；药物包括ACEI/ARB、钙通道阻滞剂（CCB）、利尿剂、β受体阻滞剂，目标血压一般<140/90 mmHg，糖尿病或肾病患者<130/80 mmHg。

### 1.2 冠状动脉粥样硬化性心脏病（冠心病）

冠心病系冠状动脉粥样硬化致管腔狭窄或闭塞，引起心肌缺血、缺氧或坏死的心脏病，可分为慢性心肌缺血综合征与急性冠脉综合征（ACS）。

**稳定型心绞痛**
- 特征：劳力诱发的胸骨后压榨性疼痛，持续数分钟，休息或含服硝酸甘油可缓解
- 病理：固定斑块致管腔狭窄，氧供不能随需求增加

**急性冠脉综合征（ACS）**

| 类型 | 病理基础 | 心电图 | 心肌标志物 |
|------|----------|--------|------------|
| 不稳定性心绞痛（UA） | 斑块破裂、非闭塞血栓 | ST段压低/T波倒置 | 阴性 |
| 非ST段抬高心肌梗死（NSTEMI） | 斑块破裂、非完全闭塞血栓 | ST段压低 | 阳性 |
| ST段抬高心肌梗死（STEMI） | 斑块破裂、完全闭塞血栓 | ST段抬高、病理性Q波 | 阳性 |

**鉴别要点**：UA与NSTEMI的区别在于心肌损伤标志物是否升高；STEMI需立即再灌注治疗。

**治疗原则**：抗血小板（阿司匹林+P2Y12抑制剂）、抗凝、他汀、β阻滞剂、ACEI；STEMI首选直接经皮冠状动脉介入（PCI），无法及时PCI则静脉溶栓。

### 1.3 心力衰竭

心力衰竭是各种心脏结构或功能性疾病导致心室充盈或射血能力受损的复杂临床综合征。

**NYHA功能分级**

| 分级 | 表现 |
|------|------|
| I级 | 体力活动不受限 |
| II级 | 活动轻度受限，日常活动即引起症状 |
| III级 | 活动明显受限，轻于日常活动即引起症状 |
| IV级 | 静息状态下即出现症状 |

**射血分数分型**

| 类型 | 射血分数（EF） | 特点 |
|------|----------------|------|
| 射血分数降低型心衰（HFrEF） | ≤40% | 收缩功能障碍 |
| 射血分数中间型心衰（HFmrEF） | 41–49% | 轻度收缩功能受损 |
| 射血分数保留型心衰（HFpEF） | ≥50% | 舒张功能障碍 |

**治疗框架**：
- HFrEF：ACEI/ARNI、β阻滞剂、醛固酮受体拮抗剂、SGLT2抑制剂为"四联基石"
- HFpEF：控制血压、心率、利尿减轻充血，尚无明确降低死亡率的药物
- 急性失代偿：利尿、扩血管、正性肌力药物

### 1.4 心律失常

**心房颤动（房颤）**
- 表现：心悸、脉搏短绌、不规则心律
- 分类：阵发性、持续性、长程持续性、永久性
- 栓塞风险评估：CHA₂DS₂-VASc评分（心衰、高血压、年龄≥75岁[2分]、糖尿病、卒中史[2分]、血管病变、年龄65–74岁、女性）
- 治疗：抗凝（华法林或新型口服抗凝药）、心率控制（β阻滞剂、地高辛）、节律控制（抗心律失常药、导管消融）

**室性心动过速（室速）**
- 心电图：连续3个以上宽大畸形QRS波，频率>100次/分
- 临床意义：多见于器质性心脏病，可恶化为室颤，需电复律

**房室传导阻滞**

| 分度 | 心电图特征 | 处理 |
|------|------------|------|
| 一度 | PR间期>0.20秒，均下传 | 一般无需治疗 |
| 二度I型 | PR间期逐渐延长至脱落 | 病因治疗 |
| 二度II型 | PR恒定，QRS脱落 | 可能需起搏器 |
| 三度 | 房室完全分离 | 永久起搏器植入 |

## 二、呼吸系统疾病

### 2.1 慢性阻塞性肺疾病（COPD）

COPD是以持续气流受限为特征、呈进行性发展的疾病，与有害气体或颗粒的异常炎症反应有关。

**病理改变**
- **慢性支气管炎**：黏液腺增生、杯状细胞增多、气道壁炎症细胞浸润
- **肺气肿**：终末细支气管远端肺泡异常持久扩大，壁破坏，可分为小叶中央型（吸烟相关）与全小叶型（α₁-抗胰蛋白酶缺乏）

**GOLD分级（基于FEV₁占预计值百分比）**

| GOLD分级 | FEV₁/FVC | FEV₁%预计值 | 严重程度 |
|----------|----------|-------------|----------|
| 1级 | <0.70 | ≥80% | 轻度 |
| 2级 | <0.70 | 50–79% | 中度 |
| 3级 | <0.70 | 30–49% | 重度 |
| 4级 | <0.70 | <30% | 极重度 |

**治疗原则**：戒烟为首要；支气管扩张剂（LAMA、LABA）为核心，吸入糖皮质激素用于反复急性加重者；长期氧疗改善预后；肺康复训练。

### 2.2 支气管哮喘

哮喘是由多种细胞（嗜酸性粒细胞、肥大细胞、T淋巴细胞等）参与的气道慢性炎症性疾病，以可逆性气流受限与气道高反应性为特征。

**诊断要点**：反复喘息、气促、胸闷；肺功能示可逆性气流受限（支气管舒张试验FEV₁改善≥12%且≥200ml）；峰值呼气流速（PEF）变异率>10%。

**GINA分级阶梯治疗**

| 阶梯 | 治疗方案 |
|------|----------|
| 第1级 | 按需短效β₂激动剂（SABA） |
| 第2级 | 低剂量吸入糖皮质激素（ICS）+ 按需SABA |
| 第3级 | 低剂量ICS/LABA |
| 第4级 | 中高剂量ICS/LABA |
| 第5级 | 高剂量ICS/LABA + 生物靶向治疗（抗IgE/抗IL-5） |

**气道高反应性机制**：炎症致上皮损伤、神经调控失衡、平滑肌收缩阈值降低，对多种刺激呈过度收缩反应。

### 2.3 肺炎

肺炎指终末气道、肺泡及肺间质的炎症，以感染最常见。

**社区获得性肺炎（CAP）病原体分类**

| 类型 | 常见病原体 | 特点 |
|------|------------|------|
| 典型肺炎 | 肺炎链球菌、流感嗜血杆菌 | 起病急、高热、脓痰、肺实变 |
| 非典型肺炎 | 肺炎支原体、衣原体、军团菌 | 起病隐匿、干咳、肺外症状多 |

**病情评估**：CURB-65评分（意识障碍、尿素氮>7 mmol/L、呼吸频率≥30次/分、收缩压<90/舒张压≤60、年龄≥65岁），≥3分需住院。

**治疗原则**：经验性抗生素覆盖（青霉素类/大环内酯类/呼吸喹诺酮），依据病原学调整，疗程一般5–7天。

### 2.4 肺栓塞

肺栓塞是以各种栓子阻塞肺动脉系统为发病原因的疾病或综合征，以肺血栓栓塞症最常见。

**Wells评分**

| 指标 | 分值 |
|------|------|
| 深静脉血栓临床表现 | 3 |
| PE为最可能诊断 | 3 |
| 心率>100次/分 | 1.5 |
| 制动≥3周或4周内手术 | 1.5 |
| 既往DVT/PE史 | 1.5 |
| 咯血 | 1 |
| 恶性肿瘤 | 1 |

评分≤4分为低危，>4分为高危，结合D-二聚体与影像（CTPA）确诊。

**治疗原则**：抗凝为基石（低分子肝素→华法林或新型口服抗凝药）；大面积肺栓塞伴血流动力学不稳定者予溶栓；必要时导管或手术取栓。

### 2.5 肺癌

肺癌是起源于支气管或肺泡上皮的恶性肿瘤，发病与吸烟、职业暴露、空气污染密切相关。

**病理分类与分期**

| 类型 | 生长特征 | 治疗 | 预后 |
|------|----------|------|------|
| 小细胞肺癌（SCLC） | 进展快、早期转移 | 化疗+放疗，局限期可手术 | 差 |
| 非小细胞肺癌（NSCLC） | 相对缓慢 | 手术、放疗、靶向、免疫治疗 | 较好 |

**TNM分期简表**

| 期别 | 描述 | 5年生存率 |
|------|------|-----------|
| I期 | 肿瘤局限，无淋巴结转移 | >60% |
| II期 | 同侧肺门淋巴结转移 | 30–50% |
| III期 | 纵隔淋巴结转移 | 10–30% |
| IV期 | 远处转移 | <5% |

**治疗原则**：早期NSCLC手术切除为根治手段；晚期根据驱动基因（EGFR、ALK等）选用靶向药；PD-1/PD-L1抑制剂免疫治疗开辟新格局。

## 三、消化系统疾病

### 3.1 消化性溃疡

消化性溃疡主要发生于胃和十二指肠，以慢性、周期性、节律性上腹痛为特征，黏膜防御与侵袭因素失衡为其发病基础。

**幽门螺杆菌（Hp）感染机制**
- Hp分泌尿素酶分解尿素产氨，破坏黏液-碳酸氢盐屏障
- 引起黏液层变薄、上皮炎症，削弱黏膜防御
- 刺激胃泌素分泌增加，胃酸增多，加重侵袭

**根除治疗方案**
- **三联疗法**：质子泵抑制剂（PPI）+ 阿莫西林 + 克拉霉素，疗程14天
- **四联疗法**：PPI + 铋剂 + 阿莫西林 + 克拉霉素/甲硝唑，适用于耐药率高的地区，疗程14天

**治疗原则**：抑制胃酸（PPI为首选）、根除Hp、保护黏膜（硫糖铝、铋剂）；停用非甾体抗炎药；并发症（出血、穿孔、幽门梗阻）需内镜或外科处理。

### 3.2 炎症性肠病（IBD）

IBD是一组病因不明的慢性非特异性肠道炎症性疾病，包括溃疡性结肠炎与克罗恩病。

**溃疡性结肠炎 vs 克罗恩病**

| 要点 | 溃疡性结肠炎（UC） | 克罗恩病（CD） |
|------|---------------------|----------------|
| 病变部位 | 直肠逆行向上，仅累及结肠 | 全消化道，末段回肠最常见 |
| 病变特点 | 连续性、弥漫性 | 节段性、跳跃性 |
| 炎症深度 | 黏膜及黏膜下层 | 全壁透壁性 |
| 并发症 | 中毒性巨结肠、癌变 | 瘘管、狭窄、肛周病变 |
| 内镜表现 | 弥漫糜烂、浅溃疡 | 铺路石样、纵行溃疡 |
| 活检 | 隐窝脓肿 | 非干酪样肉芽肿 |

**治疗原则**：氨基水杨酸制剂（5-ASA）为轻中度一线；中重度使用糖皮质激素、免疫抑制剂（硫唑嘌呤）、生物制剂（抗TNF-α单抗）；营养支持与手术处理并发症。

### 3.3 肝硬化

肝硬化是以肝组织弥漫性纤维化、假小叶形成为特征的慢性肝病，终末期失代偿表现为门脉高压与肝功能减退。

**Child-Pugh分级**

| 指标 | 1分 | 2分 | 3分 |
|------|------|------|------|
| 肝性脑病 | 无 | I–II级 | III–IV级 |
| 腹水 | 无 | 少量 | 中–大量 |
| 总胆红素（μmol/L） | <34 | 34–51 | >51 |
| 白蛋白（g/L） | >35 | 28–35 | <28 |
| 凝血酶原时间延长（秒） | <4 | 4–6 | >6 |

A级（5–6分）预后较好，C级（10–15分）预后差，1年生存率约50%。

**门脉高压并发症**
- **食管胃底静脉曲张**：破裂出血为致命急症，内镜套扎或硬化剂注射预防与治疗，生长抑素降低门脉压
- **腹水**：限钠、利尿（螺内酯+呋塞米），难治性腹水行腹腔穿刺放液或经颈静脉肝内门体分流术（TIPS）
- **肝性脑病**：去除诱因（出血、感染、便秘）、乳果糖酸灌肠、支链氨基酸

### 3.4 消化道肿瘤

**胃癌**
- 危险因素：Hp感染、慢性萎缩性胃炎、高盐饮食、烟酒、家族史
- 筛查：胃镜+活检为金标准，高危人群（40岁以上、Hp阳性、胃癌家族史）定期内镜随访
- 早期表现隐匿，中晚期可呈恶病质、上腹包块、黑便

**结直肠癌**
- 危险因素：高脂低纤维饮食、结直肠腺瘤、炎症性肠病、家族性腺瘤性息肉病、年龄≥50岁
- 筛查：粪便潜血试验、结肠镜（50岁起每10年一次，高危人群提前）
- 治疗以手术为主，辅以化疗、靶向治疗（抗EGFR、抗VEGF）

## 四、内分泌代谢疾病

### 4.1 糖尿病

糖尿病是一组以慢性高血糖为特征的代谢性疾病，由胰岛素分泌缺陷或作用障碍所致。

**1型 vs 2型糖尿病**

| 要点 | 1型糖尿病 | 2型糖尿病 |
|------|-----------|-----------|
| 发病机制 | 胰岛β细胞自身免疫破坏 | 胰岛素抵抗+相对分泌不足 |
| 发病年龄 | 青少年多见 | 中老年多见 |
| 体型 | 多消瘦 | 多肥胖 |
| 起病 | 急、症状明显 | 缓慢、隐匿 |
| 酮症倾向 | 高 | 较低 |
| 自身抗体 | 阳性（GAD、ICA） | 阴性 |
| 治疗 | 胰岛素依赖 | 生活方式+口服药/胰岛素 |

**诊断标准**

| 指标 | 糖尿病诊断切点 |
|------|----------------|
| 空腹血糖（FPG） | ≥7.0 mmol/L |
| OGTT 2小时血糖 | ≥11.1 mmol/L |
| 糖化血红蛋白（HbA1c） | ≥6.5% |
| 随机血糖（伴症状） | ≥11.1 mmol/L |

**急症：糖尿病酮症酸中毒（DKA）与高渗高血糖状态（HHS）**

| 要点 | DKA | HHS |
|------|-----|-----|
| 血糖 | 多13.9–33.3 mmol/L | 多≥33.3 mmol/L |
| 血酮 | 显著升高 | 轻度升高或正常 |
| pH | <7.30 | 正常或轻度降低 |
| 渗透压 | 轻度升高 | 显著升高（>320 mOsm/L） |
| 意识 | 不同程度障碍 | 深度脱水、神经系统体征 |

处理原则：补液（首选生理盐水）、小剂量胰岛素静滴（0.1 U/kg/h）、纠正电解质（补钾）、消除诱因。

### 4.2 甲状腺疾病

**甲状腺功能亢进（甲亢）——Graves病**
- 机制：TSH受体抗体（TRAb）持续刺激甲状腺滤泡细胞，致甲状腺激素过度合成
- 表现：代谢增快（怕热、多汗、消瘦）、神经兴奋（心悸、手颤）、突眼、甲状腺弥漫性肿大
- 实验室：TSH↓，FT₃/FT₄↑，TRAb阳性
- 治疗：抗甲状腺药物（甲巯咪唑、丙硫氧嘧啶）、¹³¹碘治疗、手术

**甲状腺功能减退（甲减）——Hashimoto甲状腺炎**
- 机制：自身免疫性甲状腺破坏，TPOAb阳性
- 表现：代谢减慢（怕冷、乏力、便秘）、黏液性水肿
- 实验室：TSH↑，FT₃/FT₄↓
- 治疗：左甲状腺素钠（L-T₄）替代，终身用药

**甲状腺结节评估**
- 超声评估形态、回声、钙化、边界
- TI-RADS分级指导穿刺：4级及以上行细针穿刺活检（FNA）
- 结合甲状腺功能，除外高功能腺瘤

### 4.3 代谢综合征

代谢综合征是以糖代谢紊乱、血脂异常、高血压、腹型肥胖为聚集表现的临床综合征，其核心为胰岛素抵抗。

**诊断标准（中华医学会标准，具备3项即可）**
- 腹型肥胖：腰围男性≥90 cm，女性≥85 cm
- 血甘油三酯≥1.70 mmol/L
- 血HDL-C：男性<1.04、女性<1.30 mmol/L
- 血压≥130/85 mmHg
- 空腹血糖≥6.10 mmol/L

**胰岛素抵抗机制**：靶组织对胰岛素生物学效应降低，代偿性高胰岛素血症，继发糖耐量异常、血脂紊乱、血管内皮损伤，最终致动脉粥样硬化与2型糖尿病。

**治疗原则**：生活方式干预为基础（减重、运动、饮食结构优化），针对各组分用药（二甲双胍、他汀、降压药）。

### 4.4 骨质疏松症

骨质疏松以骨量减少、骨微结构破坏、骨脆性增加及骨折风险升高为特征。

**T值标准（双能X线吸收法DEXA）**

| T值 | 分类 |
|-----|------|
| ≥-1.0 | 正常 |
| -1.0 ~ -2.5 | 骨量减少 |
| ≤-2.5 | 骨质疏松 |
| ≤-2.5 + 脆性骨折 | 严重骨质疏松 |

**骨折风险评估（FRAX）**：整合年龄、性别、体重指数、既往骨折史、家族史、吸烟、糖皮质激素使用、饮酒、继发性骨质疏松及类风湿等因素，计算10年主要骨质疏松性骨折与髋部骨折概率，指导干预启动。

**治疗原则**：基础措施（钙剂+维生素D）；抗骨吸收药物（双膦酸盐、地诺单抗、降钙素）；促骨形成药（特立帕肽）；生活方式干预（防跌倒、适度负重运动）。

## 五、神经系统疾病

### 5.1 脑卒中

脑卒中为急性脑血管病引起的局灶性神经功能障碍，分为缺血性与出血性两大类，具有高发病率、高致残率、高死亡率特点。

**缺血性 vs 出血性卒中鉴别**

| 要点 | 缺血性卒中 | 出血性卒中 |
|------|-----------|-----------|
| 病因 | 血栓或栓子致脑血管闭塞 | 脑实质或蛛网膜下腔出血 |
| 头颅CT | 早期正常，24h后低密度灶 | 高密度灶 |
| 发病形式 | 多较缓，无头痛或轻头痛 | 急骤，头痛明显、呕吐 |
| 血压 | 多正常或轻度升高 | 常显著升高 |

**NIHSS评分**：15项神经功能检查评估卒中严重程度，总分42分，分数越高神经损伤越重，≥6分提示中重度，指导再灌注治疗决策。

**溶栓时间窗与rt-PA**
- 时间窗：发病4.5小时内静脉溶栓
- 药物：重组组织型纤溶酶原激活剂（rt-PA，阿替普酶），剂量0.9 mg/kg（最大90 mg），10%首剂静推，余量60分钟泵入

**rt-PA适应症与禁忌**
- 适应症：年龄≥18岁、明确缺血性卒中、发病4.5小时内、NIHSS评估
- 禁忌：颅内出血史、近期颅内手术或严重外伤、活动性出血、血小板<100×10⁹/L、血压>185/110 mmHg（降压后方可）、近期消化道出血

**出血性卒中治疗**：控制血压、降低颅内压（甘露醇）、防治再出血与血管痉挛；蛛网膜下腔出血者尽早处理动脉瘤（夹闭或介入栓塞）。

### 5.2 癫痫

癫痫是脑神经元异常过度同步放电所致的反复发作性脑功能障碍，具有发作性、短暂性、重复性、刻板性的特点。

**分类**

| 大类 | 亚类 | 代表类型 |
|------|------|----------|
| 部分性发作 | 单纯部分性 | 运动性、感觉性、自主神经性 |
| | 复杂部分性 | 伴意识障碍，颞叶癫痫多见 |
| | 部分继发全身性 | 局灶起源→全面发作 |
| 全身性发作 | —— | 强直-阵挛、失神、肌阵挛、失张力 |

**癫痫持续状态**
- 定义：一次发作持续>5分钟，或两次发作间意识未恢复
- 处理流程：
  1. 维持气道、呼吸、循环稳定
  2. 首选苯二氮䓬类（地西泮或劳拉西泮静推）
  3. 次选苯妥英钠或丙戊酸钠负荷
  4. 难治性持续状态：咪达唑仑、丙泊酚等麻醉剂，气管插管

**治疗原则**：根据发作类型与综合征选药；全面强直阵挛首选丙戊酸钠；部分发作首选卡马西平/奥卡西平；坚持单药、长程、规律服药，不可擅自停药。

### 5.3 帕金森病

帕金森病是中老年常见的神经系统变性疾病，以黑质多巴胺能神经元变性、纹状体多巴胺递质减少为病理基础。

**运动症状**
- 静止性震颤：节律性4–6 Hz，"搓丸样"动作
- 肌强直：铅管样或齿轮样肌张力增高
- 运动迟缓：起动困难、动作缓慢、表情呆滞（"面具脸"）
- 姿势平衡障碍：起步与转身困难、前冲步态

**非运动症状**
- 自主神经功能障碍：便秘、排尿障碍、体位性低血压
- 感觉异常：嗅觉减退、肢体麻木疼痛
- 精神与认知：抑郁焦虑、痴呆、快速眼动期睡眠行为障碍
- 睡眠障碍：日间嗜睡、不宁腿综合征

**治疗**
- **左旋多巴**：多巴胺前体，通过血脑屏障后转化为多巴胺补充递质，是最有效的症状治疗药物；常与外周脱羧酶抑制剂（卡比多巴）合用，减少外周副作用
- 其他药物：多巴胺受体激动剂（普拉克索）、MAO-B抑制剂（司来吉兰）、COMT抑制剂（恩他卡朋）
- **深部脑刺激（DBS）**：高频电刺激苍白球或丘脑底核，适用于药物难治性、运动并发症严重者，可显著改善震颤、强直与运动波动

### 5.4 阿尔茨海默病

阿尔茨海默病是最常见的老年性痴呆，以进行性认知功能减退与精神行为异常为主要表现。

**病理改变**
- **淀粉样蛋白（Aβ）沉积**：老年斑的核心成分，Aβ级联假说认为其异常聚集启动神经毒性
- **tau蛋白异常磷酸化**：神经纤维缠结的主要成分，致微管功能紊乱、轴突运输障碍、突触丧失
- 脑宏观改变：弥漫性脑萎缩，以颞叶、顶叶及海马最显著

**临床表现**
- 早期：近记忆减退、学习新事物困难
- 中期：定向障碍、语言障碍、失用、人格改变
- 晚期：生活不能自理、失语、卧床、并发感染

**治疗**
- **胆碱酯酶抑制剂**：多奈哌齐、卡巴拉汀、加兰他敏，通过抑制乙酰胆碱降解改善认知，适用于轻中度
- NMDA受体拮抗剂（美金刚）：用于中重度，减少谷氨酸神经毒性
- 非药物干预：认知训练、生活照料、精神行为症状的对症处理

## 六、肾脏与血液系统疾病

### 6.1 慢性肾脏病（CKD）

CKD指各种原因致肾脏结构或功能异常超过3个月，伴或不伴肾小球滤过率下降。

**CKD分期（基于eGFR，单位mL/min/1.73m²）**

| 分期 | eGFR | 描述 |
|------|------|------|
| G1 | ≥90 | 肾功能正常（伴肾损伤标志） |
| G2 | 60–89 | 肾功能轻度下降 |
| G3a | 45–59 | 肾功能轻-中度下降 |
| G3b | 30–44 | 肾功能中-重度下降 |
| G4 | 15–29 | 肾功能重度下降 |
| G5 | <15 | 肾衰竭 |

eGFR常用CKD-EPI或MDRD公式由血肌酐、年龄、性别推算。

**透析指征**
- eGFR<10 mL/min（糖尿病肾病患者<15）
- 难以纠正的容量超负荷、高钾血症、代谢性酸中毒
- 尿毒症性心包炎、脑病、严重营养不良
- 透析方式：血液透析、腹膜透析

**治疗原则**：延缓进展（控制血压、蛋白尿）、防治并发症（肾性贫血用促红细胞生成素、矿物质骨代谢异常用磷结合剂与活性维生素D、代谢性酸中毒用碳酸氢钠）、低蛋白饮食、血管通路保护。

### 6.2 肾病综合征与肾炎综合征

**肾病综合征**
- "三高一低"：大量蛋白尿（>3.5 g/d）、低白蛋白血症（<30 g/L）、高度水肿、高脂血症
- 常见病理：微小病变型、膜性肾病、局灶节段性肾小球硬化、膜增生性肾炎
- 治疗：糖皮质激素为多数原发性肾病的一线，免疫抑制剂用于激素依赖或抵抗者，ACEI/ARB减少尿蛋白

**肾炎综合征**
- 表现：血尿、蛋白尿、水肿、高血压，可伴肾功能减退
- 急性肾炎多见于链球菌感染后，电镜见上皮下"驼峰"样沉积
- 急进性肾炎以新月体形成为特征，病情凶险，需血浆置换、免疫抑制

### 6.3 贫血分类

贫血指外周血红细胞容量减少，低于正常下限，以血红蛋白浓度衡量最为常用。

**基于平均红细胞体积（MCV）的分类**

| 类型 | MCV（fL） | 常见病因 | 鉴别要点 |
|------|-----------|----------|----------|
| 小细胞低色素性 | <80 | 缺铁性贫血、地中海贫血、慢性病性贫血、铁粒幼细胞贫血 | 血清铁/铁蛋白、铁饱和度 |
| 正细胞性 | 80–100 | 急性失血、溶血性贫血、再障、慢性肾病贫血 | 网织红细胞计数、骨髓象 |
| 大细胞性 | >100 | 巨幼细胞性贫血（维生素B₁₂/叶酸缺乏）、肝病、酒精中毒、MDS | 血清B₁₂/叶酸、外周血大卵圆细胞 |

**治疗原则**：病因治疗为根本；缺铁性贫血补铁（口服硫酸亚铁为首选，吸收利用最佳）；巨幼细胞性贫血补充B₁₂或叶酸；再障用免疫抑制或造血干细胞移植；肾性贫血用促红细胞生成素。

### 6.4 白血病简述

白血病是一类造血干细胞的恶性克隆性疾病，克隆性白血病细胞增殖失控、分化障碍、凋亡受阻，停滞于细胞发育不同阶段，并浸润骨髓及各组织器官。

**急性 vs 慢性**

| 要点 | 急性白血病 | 慢性白血病 |
|------|-----------|-----------|
| 细胞分化 | 停滞于原始及早幼阶段 | 以较成熟细胞为主 |
| 起病 | 急骤、进展快 | 隐匿、进展慢 |
| 临床表现 | 贫血、出血、感染、浸润 | 脾大、白细胞显著升高、症状轻 |
| 骨髓象 | 原始细胞≥20% | 原始细胞<10% |
| 治疗 | 化疗、造血干细胞移植 | 靶向药物为主（如TKI） |

**髓系 vs 淋巴系**

| 系统 | 急性 | 慢性 |
|------|------|------|
| 髓系 | 急性髓系白血病（AML） | 慢性髓系白血病（CML） |
| 淋巴系 | 急性淋巴细胞白血病（ALL） | 慢性淋巴细胞白血病（CLL） |

- **AML**：FAB分型M0–M7，临床表现贫血、出血、感染，可伴绿色瘤、牙龈增生；治疗以"7+3"方案（阿糖胞苷+蒽环类）为诱导缓解标准
- **ALL**：儿童多见，预后相对较好，诱导缓解后行中枢神经系统白血病预防
- **CML**：Ph染色体与BCR-ABL融合基因为标志分子，酪氨酸激酶抑制剂（伊马替尼）显著改善预后，为靶向治疗典范
- **CLL**：老年多见，早期可观察等待，进展期用化疗联合抗CD20单抗

**治疗原则**：综合评估年龄、体能、遗传学危险分层，个体化选择化疗、靶向治疗、免疫治疗与造血干细胞移植，支持治疗贯穿全程（抗感染、输血、造血生长因子）。
