| 文件 | 主题 | 简述 |
|------|------|------|

## 核心脉络

```
解剖与生理 ── 正常结构与功能的基础
病理与免疫 ── 疾病机制与防御体系
药理 ── 治疗的化学语言
内科 ── 临床实践的主干
中医 ── 另一种认识人体的智慧
医学前沿 ── 正在发生的未来
```

医学是科学中最特殊的一门：它既是严谨的自然科学，又是最具人文关怀的实践。本目录从基础到临床、从西医到中医、从经典到前沿，每篇独立可读，篇间交叉引用。
