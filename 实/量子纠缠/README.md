## 核心概念速览

```
量子纠缠 = 两个粒子共享量子态，测量一个立刻确定另一个的状态
与距离无关 — 即使相隔数光年
爱因斯坦称之为"鬼魅般的超距作用"（spooky action at a distance）
2022 年诺贝尔物理学奖 → Aspect / Clauser / Zeilinger
```

## 与「量子计算」目录的关系

量子纠缠是量子计算的三大核心资源之一（叠加 + 纠缠 + 干涉）。本目录聚焦纠缠本身的物理本质和实验验证，量子计算目录侧重计算应用和产业格局。
