# 数据结构

> "算法 + 数据结构 = 程序。" —— 尼古拉斯·沃斯（Niklaus Wirth）

数据结构是组织、存储与检索数据的方式。选对结构，算法自然简洁高效；选错结构，再精巧的算法也难逃低效之苦。本章依线性、树形、散列、图形、高级之序，逐层展开。

## 一、数组与链表

### 1.1 动态数组与静态数组

**静态数组**在编译期确定大小，内存于栈区连续分配；**动态数组**大小可变，内存于堆区分配，按需扩容。

| 特性 | 静态数组 | 动态数组 |
|------|----------|----------|
| 大小 | 编译期固定 | 运行期可变 |
| 内存 | 栈区 | 堆区 |
| 扩容 | 不支持 | 支持 |
| 访问 | $O(1)$ | $O(1)$ |
| 典型实现 | C `int a[100]` | C++ `vector`、Python `list` |

### 1.2 扩容策略与均摊分析

动态数组满时，需分配更大空间并迁移元素。常见策略为**倍增容量**。

**均摊分析**：连续 $n$ 次 `push_back`，总迁移代价为 $1 + 2 + 4 + \cdots + n/2 + n < 2n$，均摊至每次为 $O(1)$。

```cpp
// C++ vector 扩容示意
void push_back(int x) {
    if (size == capacity) {
        capacity = (capacity == 0) ? 1 : capacity * 2;
        int* tmp = new int[capacity];
        for (int i = 0; i < size; i++) tmp[i] = data[i];
        delete[] data;
        data = tmp;
    }
    data[size++] = x;
}
```

### 1.3 链表家族

链表以**节点**为单元，通过指针串联，内存不连续。

- **单向链表**：每节点含 `data` 与 `next`，只能单向遍历。
- **双向链表**：增 `prev` 指针，可双向遍历，删除已知节点 $O(1)$。
- **循环链表**：尾节点指向头，形成环；可与双向结合。

```python
# Python 双向链表节点
class Node:
    def __init__(self, val):
        self.val = val
        self.prev = None
        self.next = None
```

### 1.4 数组与链表对比

| 维度 | 数组 | 链表 |
|------|------|------|
| 随机访问 | $O(1)$，按下标直达 | $O(n)$，须顺序遍历 |
| 头部插入/删除 | $O(n)$，需搬移 | $O(1)$，改指针 |
| 已知位置插入/删除 | $O(n)$ | $O(1)$（双向链表） |
| 内存连续性 | 连续，缓存友好 | 离散，缓存不友好 |
| 额外空间 | 几乎无 | 每节点存指针 |
| 适用场景 | 频繁查询、少增删 | 频繁增删、少查询 |

### 1.5 跳表 Skip List

跳表以**多层索引链表**实现有序集合的 $O(\log n)$ 查询，是平衡树的概率替代品。每节点以概率 $p$（常取 $1/2$）向上一层提升，期望层高 $O(\log n)$。

| 操作 | 平均复杂度 | 最坏复杂度 |
|------|------------|------------|
| 查找 | $O(\log n)$ | $O(n)$ |
| 插入 | $O(\log n)$ | $O(n)$ |
| 删除 | $O(\log n)$ | $O(n)$ |

Redis 的有序集合 `zset` 即以跳表为核心实现。

### 1.6 历史背景与应用

- **历史**：数组与链表是最古老的结构，根植于早期内存模型；跳表由 William Pugh 于 1989 年提出。
- **应用**：数组支撑连续存储与随机访问；链表用于 LRU 缓存、多项式表示；跳表用于 Redis、LevelDB。

## 二、栈与队列

### 2.1 栈 LIFO

栈遵循**后进先出**（LIFO）原则，仅允许在栈顶操作。

| 操作 | 复杂度 |
|------|--------|
| `push` | $O(1)$ |
| `pop` | $O(1)$ |
| `peek` | $O(1)$ |
| 查找 | $O(n)$ |

**典型应用**：函数调用栈（保存返回地址与局部变量）、括号匹配、表达式求值（中缀转后缀）。

```python
# 括号匹配
def is_valid(s: str) -> bool:
    stack, pair = [], {')': '(', ']': '[', '}': '{'}
    for c in s:
        if c in '([{':
            stack.append(c)
        elif not stack or stack.pop() != pair[c]:
            return False
    return not stack
```

### 2.2 队列 FIFO

队列遵循**先进先出**（FIFO）原则，队尾入、队头出。

| 操作 | 复杂度 |
|------|--------|
| `enqueue` | $O(1)$ |
| `dequeue` | $O(1)$ |
| `front` | $O(1)$ |

**典型应用**：广度优先搜索 BFS、任务调度（先到先服务）、消息缓冲区。

### 2.3 双端队列 Deque

双端队列两端皆可进出，兼具栈与队列之长。C++ `std::deque`、Python `collections.deque` 均支持 $O(1)$ 的头尾操作。

### 2.4 优先队列与二叉堆

优先队列按**优先级**出队，常以**二叉堆**实现。

- **最大堆**：父节点 $\ge$ 子节点，堆顶为最大值。
- **最小堆**：父节点 $\le$ 子节点，堆顶为最小值。

| 操作 | 复杂度 |
|------|--------|
| 插入 | $O(\log n)$ |
| 取顶/删除顶 | $O(\log n)$ |
| 建堆（自底向下） | $O(n)$ |
| 查找任意元素 | $O(n)$ |

```python
# Python 最小堆
import heapq
h = [3, 1, 4, 1, 5, 9]
heapq.heapify(h)          # O(n) 建堆
heapq.heappush(h, 2)      # 插入
print(heapq.heappop(h))   # -> 1，取最小
```

**建堆 $O(n)$ 之直觉**：自底向上调整，下层节点多但调整路径短，上层节点少但路径长，求和后以等比收敛于 $O(n)$。

### 2.5 单调栈与单调队列

- **单调栈**：栈内元素保持单调，用于求"下一个更大/更小元素"，$O(n)$。
- **单调队列**：双端队列维护单调性，配合滑动窗口求最值，$O(n)$。

```python
# 单调栈：求每个元素右侧第一个更大值
def next_greater(nums):
    res = [-1] * len(nums)
    stack = []
    for i, x in enumerate(nums):
        while stack and nums[stack[-1]] < x:
            res[stack.pop()] = x
        stack.append(i)
    return res
```

### 2.6 历史背景与应用

- **历史**：栈与队列概念随早期计算机体系结构自然产生；堆结构由 J. W. J. Williams 于 1964 年引入用于堆排序。
- **应用**：栈用于编译器语法分析、浏览器后退；队列用于 BFS、操作系统调度；堆用于 Dijkstra、Top-K 问题；单调结构用于滑动窗口最值与直方图最大矩形。

## 三、树

### 3.1 二叉树与遍历

二叉树每节点至多两子。四种遍历方式：

| 遍历 | 顺序 | 应用 |
|------|------|------|
| 前序 | 根→左→右 | 复制树、表达式前缀 |
| 中序 | 左→根→右 | BST 升序输出 |
| 后序 | 左→右→根 | 释放树、表达式后缀 |
| 层序 | 逐层自上而下 | BFS、最短深度 |

```python
# 中序遍历（递归）
def inorder(node):
    if not node: return
    inorder(node.left)
    print(node.val)
    inorder(node.right)
```

### 3.2 二叉搜索树与 AVL

**二叉搜索树（BST）**：左子树值 $<$ 根 $<$ 右子树值。中序遍历得升序。最坏退化为链表，操作 $O(n)$。

**AVL 树**：自平衡 BST，任一节点左右子树高度差 $\le 1$。失衡时经**旋转**恢复平衡。

| 旋转类型 | 触发条件 |
|----------|----------|
| LL（右旋） | 左子树的左子树插入 |
| RR（左旋） | 右子树的右子树插入 |
| LR（先左后右） | 左子树的右子树插入 |
| RL（先右后左） | 右子树的左子树插入 |

| 操作 | BST 平均 | BST 最坏 | AVL |
|------|----------|----------|-----|
| 查找 | $O(\log n)$ | $O(n)$ | $O(\log n)$ |
| 插入 | $O(\log n)$ | $O(n)$ | $O(\log n)$ |
| 删除 | $O(\log n)$ | $O(n)$ | $O(\log n)$ |

### 3.3 红黑树 Red-Black Tree

红黑树是弱平衡 BST，以颜色约束维持近似平衡，五条性质：

1. 节点为红或黑。
2. 根为黑。
3. 叶（NIL）为黑。
4. 红节点的子必黑（无连续红）。
5. 任一节点到叶的各路径含相同数目黑节点。

最长路径至多为最短的 2 倍，高度 $O(\log n)$。旋转与变色次数少于 AVL，适合频繁增删场景。C++ `std::map`、Linux 调度器 `CFS`、Java `TreeMap` 均以红黑树实现。

### 3.4 B 树与 B+ 树

B 树是**多路平衡搜索树**，每节点含多个键与多个子指针，专为磁盘 I/O 优化。

| 特性 | B 树 | B+ 树 |
|------|------|-------|
| 数据存储 | 内部节点与叶皆存数据 | 仅叶节点存数据 |
| 叶节点链接 | 无 | 叶节点以链表相连 |
| 范围查询 | 需中序遍历 | 顺叶链扫描，高效 |
| 典型应用 | 文件系统 | 数据库索引（MySQL InnoDB） |

阶为 $m$ 的 B 树每节点至多 $m$ 个子、至少 $\lceil m/2 \rceil$ 个子。查找/插入/删除均为 $O(\log_m n)$。

### 3.5 Trie 字典树与 AC 自动机

**Trie**：以字符串公共前缀为边的树，查询单词 $O(L)$（$L$ 为词长），与字典规模无关。

```python
# Trie 插入与查找
class Trie:
    def __init__(self): self.ch = {}
    def insert(self, w):
        node = self
        for c in w: node = node.ch.setdefault(c, Trie())
        node.end = True
    def search(self, w):
        node = self
        for c in w:
            if c not in node.ch: return False
            node = node.ch[c]
        return getattr(node, 'end', False)
```

**AC 自动机**：Trie + 失配指针，可在文本中一次扫描匹配多模式串，复杂度 $O(|\text{text}| + \text{匹配数})$，广泛用于敏感词过滤。

### 3.6 线段树与树状数组

两者皆支持区间查询与单点更新，$O(\log n)$。

| 结构 | 功能 | 空间 | 特点 |
|------|------|------|------|
| 线段树 | 区间和/最值/任意可合并操作 | $4n$ | 灵活，支持懒标记区间修改 |
| 树状数组 (BIT) | 前缀和、逆序对 | $n$ | 常数小，实现简洁 |

```python
# 树状数组：单点更新与前缀查询
class BIT:
    def __init__(self, n): self.t = [0] * (n + 1)
    def update(self, i, v):           # i 从 1 开始
        while i < len(self.t):
            self.t[i] += v; i += i & -i
    def query(self, i):               # 前缀和 [1, i]
        s = 0
        while i > 0:
            s += self.t[i]; i -= i & -i
        return s
```

### 3.7 最近公共祖先 LCA

求树上两节点 $u, v$ 的最近公共祖先，常见三法：

| 算法 | 预处理 | 单次查询 | 适用 |
|------|--------|----------|------|
| Tarjan（离线） | — | 近 $O(1)$ 均摊 | 离线批量查询 |
| 倍增 | $O(n \log n)$ | $O(\log n)$ | 在线通用 |
| 欧拉序 + RMQ | $O(n \log n)$ | $O(1)$ | 在线、查询密集 |

### 3.8 历史背景与应用

- **历史**：BST 由 Adelson-Velsky 与 Landis（1962，AVL）开平衡之先；红黑树由 Bayer（1972）与 Guibas-Sedgewick（1978）定型；B 树由 Bayer 与 McCreight（1972）提出；Trie 源于 Edward Fredkin（1960）。
- **应用**：平衡树用于映射与调度；B+ 树为数据库索引核心；Trie 用于搜索补全与路由；线段树用于区间统计与 ORM。

## 四、哈希表

### 4.1 哈希函数设计原则

好的哈希函数应满足：

- **均匀性**：将键均匀映射至桶，降低冲突。
- **确定性**：同一键每次哈希结果相同。
- **雪崩效应**：输入微小变化致输出剧烈变化。
- **高效性**：计算 $O(1)$。

常见函数：除留余数法 $h(k) = k \bmod m$（$m$ 取素数）、乘法法、MurmurHash、xxHash。

### 4.2 冲突解决：链地址法 vs 开放寻址法

| 维度 | 链地址法 | 开放寻址法 |
|------|----------|------------|
| 存储 | 每桶挂链表 | 全存表内，探查空位 |
| 探查方式 | — | 线性/二次/双重哈希 |
| 装填因子 | 可 $>1$ | 须 $<1$ |
| 缓存友好 | 差（链表跳转） | 好（连续内存） |
| 删除 | 简单 | 需懒删除标记 |
| 典型实现 | Java `HashMap` | Python `dict`、C++ `unordered_map` |

### 4.3 负载因子与 rehash

**负载因子** $\alpha = \frac{\text{元素数}}{\text{桶数}}$。当 $\alpha$ 超过阈值（如 0.75）时触发 **rehash**：扩容桶数组并重新哈希所有元素，均摊 $O(1)$。

### 4.4 一致性哈希 Consistent Hashing

在分布式缓存中，普通取模哈希在节点增删时致大量数据迁移。一致性哈希将键与节点映射至同一环空间，节点变化仅影响相邻区间。引入**虚拟节点**使分布均匀。

### 4.5 布隆过滤器 Bloom Filter

位数组 + $k$ 个哈希函数，用于判重。

- 插入：$k$ 个位置置 1。
- 查询：若 $k$ 个位置皆 1，则**可能存在**；若有任一为 0，则**必不存在**。

**误判率** $p \approx \left(1 - e^{-kn/m}\right)^k$，其中 $n$ 为元素数、$m$ 为位数。应用于垃圾邮件过滤、缓存穿透防护、海量 URL 去重。

### 4.6 哈希表 vs BST 对比

| 维度 | 哈希表 | BST（平衡） |
|------|--------|-------------|
| 平均查找 | $O(1)$ | $O(\log n)$ |
| 最坏查找 | $O(n)$ | $O(\log n)$ |
| 有序遍历 | 不支持 | $O(n)$ 升序 |
| 范围查询 | 不支持 | $O(\log n + k)$ |
| 内存 | 额外桶开销 | 节点指针开销 |

### 4.7 历史背景与应用

- **历史**：哈希思想由 H. P. Luhn（1953）于 IBM 提出；一致性哈希由 Karger 等（1997）给出；布隆过滤器由 Burton Bloom（1970）提出。
- **应用**：哈希表为语言内置字典基石；一致性哈希用于 Memcached、Cassandra；布隆过滤器用于 HBase、爬虫 URL 去重。

## 五、图

### 5.1 图的表示

设 $n$ 顶点、$m$ 边。

| 表示 | 空间 | 查询边 | 遍历邻接 | 适用 |
|------|------|--------|-----------|------|
| 邻接矩阵 | $O(n^2)$ | $O(1)$ | $O(n)$ | 稠密图 |
| 邻接表 | $O(n + m)$ | $O(\deg)$ | $O(\deg)$ | 稀疏图 |

### 5.2 图的分类

- **有向图 vs 无向图**：边是否带方向。
- **加权图**：边带权值，用于最短路、最小生成树。
- **连通/强连通**：无向图中可达即连通；有向图中双向可达称强连通。

### 5.3 图的遍历：BFS 与 DFS

| 算法 | 数据结构 | 特点 | 复杂度 |
|------|----------|------|--------|
| BFS | 队列 | 逐层扩展，求无权最短路 | $O(n + m)$ |
| DFS | 栈/递归 | 深入到底回溯，用于连通性、拓扑序 | $O(n + m)$ |

```python
# BFS 求无权图最短跳数
from collections import deque
def bfs(start, graph):
    dist = {start: 0}
    q = deque([start])
    while q:
        u = q.popleft()
        for v in graph[u]:
            if v not in dist:
                dist[v] = dist[u] + 1
                q.append(v)
    return dist
```

### 5.4 连通分量与并查集

**并查集（Union-Find）**维护不相交集合，支持高效合并与查询同集。

| 操作 | 朴素 | 路径压缩 + 按秩合并 |
|------|------|----------------------|
| `find` | $O(n)$ | 近 $O(1)$ 均摊 |
| `union` | $O(n)$ | 近 $O(1)$ 均摊 |

- **路径压缩**：`find` 时将沿途节点直接挂到根。
- **按秩合并**：矮树挂高树，控制高度增长。

```python
class DSU:
    def __init__(self, n):
        self.p = list(range(n)); self.r = [0] * n
    def find(self, x):
        while self.p[x] != x:
            self.p[x] = self.p[self.p[x]]   # 路径压缩
            x = self.p[x]
        return x
    def union(self, a, b):
        ra, rb = self.find(a), self.find(b)
        if ra == rb: return False
        if self.r[ra] < self.r[rb]: ra, rb = rb, ra
        self.p[rb] = ra                       # 按秩合并
        if self.r[ra] == self.r[rb]: self.r[ra] += 1
        return True
```

### 5.5 拓扑排序 Topological Sort

对有向无环图（DAG）排成线性序，使所有有向边由前向后。两法：

| 算法 | 方法 | 复杂度 |
|------|------|--------|
| Kahn | 反复删除入度为 0 的节点 | $O(n + m)$ |
| DFS 逆后序 | DFS 完成时入栈，最终栈序即拓扑序 | $O(n + m)$ |

```python
# Kahn 算法
from collections import deque
def topo(n, edges):
    g, indeg = [[] for _ in range(n)], [0] * n
    for u, v in edges: g[u].append(v); indeg[v] += 1
    q = deque(i for i in range(n) if indeg[i] == 0)
    order = []
    while q:
        u = q.popleft(); order.append(u)
        for v in g[u]:
            indeg[v] -= 1
            if indeg[v] == 0: q.append(v)
    return order if len(order) == n else []   # 空 => 有环
```

### 5.6 历史背景与应用

- **历史**：DFS/BFS 源于 19 世纪图论（Königsberg 七桥），计算机时代由 Tarjan 等系统化；并查集由 Galler 与 Fischer（1964）提出；Kahn 算法见于 Kahn（1962）。
- **应用**：BFS 用于最短路与社交关系；并查集用于 Kruskal 最小生成树、连通判定；拓扑排序用于编译依赖、课程安排与任务编排。

## 六、高级数据结构

### 6.1 并查集详解

并查集的高级变体：

- **带权并查集**：边带权，`find` 时累计路径权值，用于食物链、差分约束判环。
- **可撤销并查集**：用栈记录修改，支持回滚，用于线段树分治。
- **种类并查集**：维护关系种类（同类/敌对），用于关押罪犯问题。

### 6.2 后缀数组与后缀自动机

| 结构 | 功能 | 构造 |
|------|------|------|
| 后缀数组 SA | 将所有后缀按字典序排列，支持子串统计 | $O(n)$ 或 $O(n \log n)$ |
| LCP 数组 | 相邻后缀最长公共前缀 | 由 SA 在 $O(n)$ 内求得 |
| 后缀自动机 SAM | 接受原串所有子串的最小 DFA | $O(n)$ 在线构造 |

### 6.3 LCP 数组与后缀数组的应用

- **本质不同子串数**：$\frac{n(n+1)}{2} - \sum \text{LCP}_i$。
- **最长重复子串**：LCP 数组最大值对应后缀。
- **多模式匹配**：在 SA 上二分，$O(|P| \log n)$。

### 6.4 树链剖分 Heavy-Light Decomposition

将树剖为若干重链，使任一路径跨越 $O(\log n)$ 条链，配合线段树实现路径/子树修改查询 $O(\log^2 n)$。

- **重儿子**：子树最大的儿子。
- **重链**：由重儿子串联的路径。
- 维护 `top`（链顶）、`dfn`（DFS 序）后将路径操作转为区间操作。

### 6.5 可持久化数据结构与主席树

**可持久化**：每次修改保留历史版本，共享未变子树。**主席树**即可持久化线段树，支持区间第 $k$ 小查询。

| 操作 | 复杂度 |
|------|--------|
| 单点修改（新建版本） | $O(\log n)$ |
| 区间第 $k$ 小 | $O(\log n)$ |
| 空间（$q$ 次修改） | $O((n + q) \log n)$ |

### 6.6 平衡树综述

| 结构 | 平衡方式 | 特点 |
|------|----------|------|
| Treap | 随机优先级 + 堆 | 实现简单，期望 $O(\log n)$ |
| Splay | 访问后旋至根 | 自适应热点，均摊 $O(\log n)$ |
| 替罪羊树 | 重量因子 $\alpha$，重构失衡子树 | 实现简单，最坏 $O(\log n)$ |
| SBT（Size Balanced Tree） | 以子树大小为约束 | 严格 $O(\log n)$，竞赛常用 |

### 6.7 历史背景与应用

- **历史**：后缀数组由 Manber 与 Myers（1990）推广；SAM 由 Ukkonen（1995）给出线性构造；树链剖分由 Tarjan（1982）系统化；主席树得名于黄嘉泰（HH），广泛流传于 OI 圈。
- **应用**：后缀数组用于生物序列比对与压缩；树链剖分用于树状网络流与查询；主席树用于离线区间统计；平衡树用于动态维护有序集与 LRU/Opt 替换策略。
