# 排序与搜索算法

> "算法 + 数据结构 = 程序。" 排序将无序数据组织为有序序列，搜索在集合中定位目标。从冒泡到快排，从二分到 B 树，其演化折射出对时间、空间与结构 trade-off 的不断追求。

---

## 一、比较排序
比较排序通过元素两两比较决定次序，理论下界 Ω(n log n)。
### 1.1 冒泡排序
相邻元素两两比较，逆序则交换，每轮将最大值"冒泡"到末尾。最好 O(n)（提前退出），平均/最坏 O(n²)；空间 O(1)；稳定。适用教学示范、极小或基本有序数据。
```python
def bubble_sort(a):
    for i in range(len(a) - 1):
        swapped = False
        for j in range(len(a) - 1 - i):
            if a[j] > a[j + 1]:
                a[j], a[j + 1] = a[j + 1], a[j]; swapped = True
        if not swapped: break
```
### 1.2 选择排序
每轮在未排序区选出最小值与首元素交换。最好/平均/最坏 O(n²)；空间 O(1)；**不稳定**。适用交换代价高的场景。
```python
def selection_sort(a):
    for i in range(len(a) - 1):
        k = i
        for j in range(i + 1, len(a)):
            if a[j] < a[k]: k = j
        a[i], a[k] = a[k], a[i]
```
### 1.3 插入排序
将每个新元素插入已序区正确位置，类似整理扑克牌。最好 O(n)，平均/最坏 O(n²)；空间 O(1)；稳定。适用小规模或近序数据、混合排序的短子序列。
```python
def insertion_sort(a):
    for i in range(1, len(a)):
        key, j = a[i], i - 1
        while j >= 0 and a[j] > key: a[j + 1] = a[j]; j -= 1
        a[j + 1] = key
```
### 1.4 希尔排序 Shell Sort
按步长 gap 分组做插入排序，逐步缩小 gap 至 1。大步长先消除远距离逆序对，使数据趋于有序。依赖 gap 序列：Hibbard O(n^1.5)，Sedgewick O(n^(4/3))；空间 O(1)；**不稳定**。适用中等规模、内存受限环境。
```python
def shell_sort(a):
    gap = len(a) // 2
    while gap > 0:
        for i in range(gap, len(a)):
            tmp, j = a[i], i
            while j >= gap and a[j - gap] > tmp: a[j] = a[j - gap]; j -= gap
            a[j] = tmp
        gap //= 2
```
### 1.5 归并排序 Merge Sort（分治思想）
分治三步：对半切分 → 递归排序 → 线性归并两个有序段。最好/平均/最坏 O(n log n)；空间 O(n)；稳定。适用稳定排序需求、链表排序、外部排序基础。
```python
def merge_sort(a):
    if len(a) <= 1: return a
    mid = len(a) // 2
    L, R = merge_sort(a[:mid]), merge_sort(a[mid:])
    res, i, j = [], 0, 0
    while i < len(L) and j < len(R):
        if L[i] <= R[j]: res.append(L[i]); i += 1
        else: res.append(R[j]); j += 1
    return res + L[i:] + R[j:]
```
### 1.6 快速排序 Quick Sort
选基准 pivot，小于 pivot 置左、大于置右，递归排序两侧。最好/平均 O(n log n)，最坏 O(n²)；空间 O(log n)；**不稳定**。通用内部排序首选，缓存友好。
**partition 方式对比：**

| 方式 | 思路 | 特点 |
|------|------|------|
| Lomuto | 取末元素为 pivot，单指针维护 ≤pivot 边界 | 实现简单，交换较多 |
| Hoare | 双指针从两端向中间扫描，相遇即分区 | 交换更少、实际更快，实现易错 |
| 三路划分 | 分为 <pivot、=pivot、>pivot 三段 | 对大量重复元素高效 |
```python
def partition3(a, lo, hi):
    pivot = a[lo]; lt, i, gt = lo, lo, hi
    while i <= gt:
        if a[i] < pivot: a[lt], a[i] = a[i], a[lt]; lt += 1; i += 1
        elif a[i] > pivot: a[gt], a[i] = a[i], a[gt]; gt -= 1
        else: i += 1
    return lt, gt
def quick_sort(a, lo, hi):
    if lo >= hi: return
    lt, gt = partition3(a, lo, hi)
    quick_sort(a, lo, lt - 1); quick_sort(a, gt + 1, hi)
```
### 1.7 堆排序 Heap Sort
先建大顶堆，反复将堆顶（最大值）与末尾交换并下沉堆顶。建堆 O(n)，排序 O(n log n)；空间 O(1)；**不稳定**。适用原地排序且需最坏保证、Top-K 问题。
```python
def sift_down(a, i, n):
    while 2 * i + 1 < n:
        c = 2 * i + 1
        if c + 1 < n and a[c + 1] > a[c]: c += 1
        if a[i] >= a[c]: break
        a[i], a[c] = a[c], a[i]; i = c
def heap_sort(a):
    n = len(a)
    for i in range(n // 2 - 1, -1, -1): sift_down(a, i, n)
    for i in range(n - 1, 0, -1): a[0], a[i] = a[i], a[0]; sift_down(a, 0, i)
```
### 比较排序算法对比表

| 算法 | 最好 | 平均 | 最坏 | 空间 | 稳定 | 特点 |
|------|------|------|------|------|------|------|
| 冒泡排序 | O(n) | O(n²) | O(n²) | O(1) | ✓ | 简单，可提前退出 |
| 选择排序 | O(n²) | O(n²) | O(n²) | O(1) | ✗ | 交换最少 |
| 插入排序 | O(n) | O(n²) | O(n²) | O(1) | ✓ | 近序高效 |
| 希尔排序 | O(n log n) | O(n^1.3) | O(n²) | O(1) | ✗ | gap 序列敏感 |
| 归并排序 | O(n log n) | O(n log n) | O(n log n) | O(n) | ✓ | 稳定且最坏最优 |
| 快速排序 | O(n log n) | O(n log n) | O(n²) | O(log n) | ✗ | 平均最快 |
| 堆排序 | O(n log n) | O(n log n) | O(n log n) | O(1) | ✗ | 原地且最坏保证 |

## 二、非比较排序与线性排序
利用键值特殊性质（如整数范围），突破比较排序下界，可达线性时间。
### 2.1 计数排序 Counting Sort
统计每个键出现次数，前缀和确定位置，输出有序序列。时间 O(n + k)，k 为值域；空间 O(n + k)；稳定（逆序填充）。适用键为小范围整数、基数排序子例程。
```python
def counting_sort(a, k):
    cnt = [0] * k
    for x in a: cnt[x] += 1
    for i in range(1, k): cnt[i] += cnt[i - 1]
    out = [0] * len(a)
    for x in reversed(a): cnt[x] -= 1; out[cnt[x]] = x
    return out
```
### 2.2 基数排序 Radix Sort（LSD/MSD）
按位分发：从低位到高位（LSD）或高位到低位（MSD），逐位用稳定排序。时间 O(d·(n + k))，d 为位数；空间 O(n + k)；稳定。适用定长整数、字符串字典序、超大数排序。
```python
def radix_lsd(a):
    exp = 1
    while max(a) // exp > 0:
        cnt = [0] * 10
        for x in a: cnt[(x // exp) % 10] += 1
        for i in range(1, 10): cnt[i] += cnt[i - 1]
        out = [0] * len(a)
        for x in reversed(a):
            d = (x // exp) % 10; cnt[d] -= 1; out[cnt[d]] = x
        a = out; exp *= 10
    return a
```
### 2.3 桶排序 Bucket Sort
将数据按值域分到若干桶，桶内排序后顺序拼接。平均 O(n + n²/k)，k 桶；最坏 O(n²)；空间 O(n + k)；稳定。适用均匀分布的浮点数、区间数据。
```python
def bucket_sort(a, k=10):
    lo, hi = min(a), max(a)
    buckets = [[] for _ in range(k)]
    for x in a: buckets[int((x - lo) / (hi - lo + 1) * k)].append(x)
    return [x for b in buckets for x in sorted(b)]
```
### 2.4 线性排序的适用条件与限制

| 条件 | 说明 |
|------|------|
| 键可索引 | 计数/基数要求键为整数或可映射为整数 |
| 值域受限 | k 不能远大于 n，否则空间与时间退化 |
| 分布均匀 | 桶排序依赖均匀分布假设 |
| 额外空间 | 通常需 O(n + k) 辅助空间，非原地 |
| 通用性弱 | 无法处理任意可比较对象 |
### 2.5 排序的下界：比较排序 Ω(n log n) 的决策树证明
比较排序建模为**决策树**：每个内节点是一次比较，叶节点对应一种排列。n 个元素有 n! 种排列，故树叶数 ≥ n!。树高 h 满足 2^h ≥ n!，由 Stirling 公式 n! ≈ (n/e)^n√(2πn)，得 h ≥ log₂(n!) = Ω(n log n)。因此任意比较排序最坏时间下界为 **Ω(n log n)**，非比较排序利用键的结构信息可突破此下界。

## 三、搜索算法
搜索定位目标元素或确定其不存在，复杂度由数据结构与有序性决定。
### 3.1 线性搜索 O(n)
逐个扫描直至找到或遍历结束。无需有序，适用任意可迭代结构。
```python
def linear_search(a, t):
    for i, x in enumerate(a):
        if x == t: return i
    return -1
```
### 3.2 二分搜索 Binary Search O(log n)
有序数组中比较中点，据大小舍弃一半区间。要求有序且随机访问。涵盖标准查找、左边界（第一个 ≥ t）、右边界及旋转数组搜索等变体。
```python
def binary_search(a, t):  # 标准
    lo, hi = 0, len(a) - 1
    while lo <= hi:
        mid = (lo + hi) // 2
        if a[mid] == t: return mid
        lo, hi = (mid + 1, hi) if a[mid] < t else (lo, mid - 1)
    return -1
def lower_bound(a, t):  # 左边界：第一个 >= t
    lo, hi = 0, len(a)
    while lo < hi:
        mid = (lo + hi) // 2
        lo, hi = (mid + 1, hi) if a[mid] < t else (lo, mid)
    return lo
def search_rotated(a, t):  # 旋转数组（无重复）
    lo, hi = 0, len(a) - 1
    while lo <= hi:
        mid = (lo + hi) // 2
        if a[mid] == t: return mid
        if a[lo] <= a[mid]:
            if a[lo] <= t < a[mid]: hi = mid - 1
            else: lo = mid + 1
        else:
            if a[mid] < t <= a[hi]: lo = mid + 1
            else: hi = mid - 1
    return -1
```
### 3.3 三分搜索 Ternary Search（单峰函数）
在单峰区间上取两个三等分点，缩小到极值所在子区间。复杂度 O(log₃ n)。
```python
def ternary_search(f, lo, hi, eps=1e-9):
    while hi - lo > eps:
        m1, m2 = lo + (hi - lo) / 3, hi - (hi - lo) / 3
        if f(m1) < f(m2): lo = m1
        else: hi = m2
    return (lo + hi) / 2
```
### 3.4 插值搜索 Interpolation Search
按目标值在值域中的比例估计位置，而非取中点。平均 O(log log n)（均匀分布），最坏 O(n)。适用均匀分布的大规模有序数据。
```python
def interpolation_search(a, t):
    lo, hi = 0, len(a) - 1
    while lo <= hi and a[lo] <= t <= a[hi]:
        pos = lo + (t - a[lo]) * (hi - lo) // (a[hi] - a[lo])
        if a[pos] == t: return pos
        lo, hi = (pos + 1, hi) if a[pos] < t else (lo, pos - 1)
    return -1
```
### 3.5 指数搜索 Exponential Search
先倍增定位含目标的区间 `[2^i, 2^(i+1)]`，再二分。O(log n)，对无限/极长序列友好。
```python
def exponential_search(a, t):
    i = 1
    while i < len(a) and a[i] <= t: i *= 2
    lo, hi = i // 2, min(i, len(a) - 1)
    while lo <= hi:
        mid = (lo + hi) // 2
        if a[mid] == t: return mid
        lo, hi = (mid + 1, hi) if a[mid] < t else (lo, mid - 1)
    return -1
```
### 3.6 跳表搜索 Skip List Search
多层链表：高层为稀疏索引，逐层下降逼近目标。期望 O(log n)，空间 O(n)。适用需有序且频繁增删的并发场景（如 Redis ZSet）。
```python
class SkipNode:
    def __init__(self, val, level):
        self.val = val; self.next = [None] * level
def skip_search(head, t, max_lvl):
    cur = head
    for lvl in range(max_lvl - 1, -1, -1):
        while cur.next[lvl] and cur.next[lvl].val < t: cur = cur.next[lvl]
    cur = cur.next[0]
    return cur and cur.val == t
```

## 四、字符串搜索
在文本 T（长 n）中定位模式 P（长 m）的出现位置。
### 4.1 朴素匹配 O(nm)
对每个对齐位置逐字符比较。最坏 O(nm)，实现极简。适用短模式、一次性匹配。
```python
def naive_match(T, P):
    for i in range(len(T) - len(P) + 1):
        if T[i:i + len(P)] == P: return i
    return -1
```
### 4.2 KMP 算法
预处理模式求 lps 数组（最长真前后缀），失配时利用已知信息跳过重复比较。失败函数 `lps[i]` 表示 P[0..i] 最长既是真前缀又是后缀的长度。预处理 O(m)，匹配 O(n)，共 O(n + m)；空间 O(m)。
```python
def kmp_lps(P):
    lps, k = [0] * len(P), 0
    for i in range(1, len(P)):
        while k > 0 and P[i] != P[k]: k = lps[k - 1]
        if P[i] == P[k]: k += 1
        lps[i] = k
    return lps
def kmp_search(T, P):
    lps, k = kmp_lps(P), 0
    for i in range(len(T)):
        while k > 0 and T[i] != P[k]: k = lps[k - 1]
        if T[i] == P[k]: k += 1
        if k == len(P): return i - k + 1
    return -1
```
### 4.3 Rabin-Karp 哈希匹配
滚动哈希快速筛选，哈希命中再逐字校验。平均 O(n + m)，最坏 O(nm)（冲突频繁）。适用多模式同长、二维匹配、plagiarism 检测。
```python
def rabin_karp(T, P, base=256, mod=10**9 + 7):
    n, m = len(T), len(P)
    if m > n: return -1
    hp = ht = 0; h = pow(base, m - 1, mod)
    for i in range(m):
        hp = (hp * base + ord(P[i])) % mod
        ht = (ht * base + ord(T[i])) % mod
    for i in range(n - m + 1):
        if hp == ht and T[i:i + m] == P: return i
        if i < n - m:
            ht = ((ht - ord(T[i]) * h) * base + ord(T[i + m])) % mod
    return -1
```
### 4.4 Boyer-Moore 算法
从模式末尾向前比较，利用坏字符与好后缀规则跳过不可能匹配的位置。最好 O(n/m)，最坏 O(nm)。适用大字母表、长模式。
| 规则 | 原理 | 移动量 |
|------|------|--------|
| 坏字符 | 失配字符在模式中最后出现位置 | `max(1, j - bc[c])` |
| 好后缀 | 已匹配后缀在模式中另一出现位置 | 按好后缀表查 |
```python
def boyer_moore(T, P):
    n, m = len(T), len(P)
    bc = {c: m for c in set(T + P)}
    for i in range(m): bc[P[i]] = m - 1 - i
    i = 0
    while i <= n - m:
        j = m - 1
        while j >= 0 and P[j] == T[i + j]: j -= 1
        if j < 0: return i
        i += max(1, bc.get(T[i + j], m) - (m - 1 - j))
    return -1
```
### 4.5 Sunday 算法
BM 的简化：对齐后看文本中模式后一字符，按其在模式中最右出现位置移动。平均 O(n)，实现简单，工程常用。
```python
def sunday(T, P):
    n, m = len(T), len(P)
    shift = {c: m + 1 for c in set(T + P)}
    for i in range(m): shift[P[i]] = m - i
    i = 0
    while i <= n - m:
        if T[i:i + m] == P: return i
        if i + m >= n: break
        i += shift.get(T[i + m], m + 1)
    return -1
```
### 4.6 AC 自动机 Aho-Corasick 多模式匹配
在 Trie 上构建失败指针（类似 KMP 的 lps），一次扫描文本匹配所有模式。Trie 组织模式集；BFS 为每节点求 fail 指针指向其最长真后缀节点；扫描时沿 fail 链报告命中。预处理 O(Σ|Pᵢ|·|Σ|)，匹配 O(n + 命中数)。适用敏感词过滤、多关键词高亮、入侵检测。
```python
from collections import deque
class ACNode:
    def __init__(self): self.children = {}; self.fail = None; self.output = []

def ac_build(patterns):
    root = ACNode()
    for p in patterns:
        cur = root
        for c in p: cur = cur.children.setdefault(c, ACNode())
        cur.output.append(p)
    q = deque()
    for ch in root.children.values(): ch.fail = root; q.append(ch)
    while q:
        u = q.popleft()
        for c, v in u.children.items():
            v.fail = u.fail
            while v.fail and c not in v.fail.children: v.fail = v.fail.fail
            v.fail = v.fail.children[c] if v.fail and c in v.fail.children else root
            v.output += v.fail.output; q.append(v)
    return root
def ac_search(T, root):
    cur, hits = root, []
    for i, c in enumerate(T):
        while cur is not root and c not in cur.children: cur = cur.fail
        if c in cur.children: cur = cur.children[c]
        for p in cur.output: hits.append((i - len(p) + 1, p))
    return hits
```
### 4.7 后缀数组匹配
后缀数组 `sa[i]` 为第 i 小后缀的起始位置，配合 LCP 与二分支持模式匹配。构造 O(n log² n)，匹配 O(m log n)。适用重复子串、最长公共子串、生物序列分析。
```python
def build_sa(s):
    n = len(s); sa, rk = list(range(n)), [ord(c) for c in s]
    k = 1
    while k < n:
        sa.sort(key=lambda i: (rk[i], rk[i + k] if i + k < n else -1))
        tmp, cnt = [0] * n, 0
        for i in range(1, n):
            p, c = sa[i - 1], sa[i]
            if (rk[p], rk[p + k] if p + k < n else -1) != \
               (rk[c], rk[c + k] if c + k < n else -1): cnt += 1
            tmp[c] = cnt
        rk, k = tmp, k * 2
        if cnt == n - 1: break
    return sa
```

## 五、搜索树与平衡
树形结构支持动态插入、删除、范围查询，平衡条件决定性能。
### 5.1 二叉搜索树 BST
左子树值 < 节点值 < 右子树值，中序遍历得有序序列。操作 O(h)，随机数据期望 O(log n)，最坏 O(n)（退化为链）。动态有序集合的基础。
```python
class Node:
    def __init__(self, val): self.val = val; self.left = self.right = None
def bst_insert(root, val):
    if root is None: return Node(val)
    if val < root.val: root.left = bst_insert(root.left, val)
    else: root.right = bst_insert(root.right, val)
    return root
def bst_search(root, val):
    while root:
        if val == root.val: return root
        root = root.left if val < root.val else root.right
    return None
```
### 5.2 AVL 树
严格平衡：任意节点左右子树高度差 ≤ 1，失衡时通过旋转恢复。插入/删除/查找 O(log n)，高度 ≤ 1.44 log n。适用查询密集场景。
| 旋转 | 触发条件 | 操作 |
|------|----------|------|
| LL | 左子左插 | 右旋 |
| RR | 右子右插 | 左旋 |
| LR | 左子右插 | 先左旋左子再右旋 |
| RL | 右子左插 | 先右旋右子再左旋 |
```python
def height(n): return n.h if n else 0
def rotate_left(n):
    r = n.right; n.right = r.left; r.left = n
    n.h = 1 + max(height(n.left), height(n.right))
    r.h = 1 + max(height(r.left), height(r.right)); return r
def rotate_right(n):
    l = n.left; n.left = l.right; l.right = n
    n.h = 1 + max(height(n.left), height(n.right))
    l.h = 1 + max(height(l.left), height(l.right)); return l
```
### 5.3 红黑树
弱平衡 BST，节点带颜色，满足五条性质以保证高度 O(log n)。插入/删除/查找 O(log n)，高度 ≤ 2 log(n+1)；旋转次数少（插入≤2，删除≤3）。适用增删频繁、工程系统核心（C++ map、Linux CFS、Java TreeMap）。

**红黑性质：** ①每个节点非红即黑；②根为黑；③叶（NIL）为黑；④红节点的子节点必为黑（红不相连）；⑤任一节点到叶的所有路径含相同数目黑节点（黑高相同）。
```python
def rb_insert_fixup(root, z):
    while z.parent and z.parent.color == 'R':
        g = z.parent.parent
        if z.parent is g.left:
            u = g.right
            if u and u.color == 'R':  # 叔红，变色上溯
                z.parent.color = u.color = 'B'; g.color = 'R'; z = g
            else:
                if z is z.parent.right: z = z.parent; root = rotate_left(z)  # LR
                z.parent.color = 'B'; g.color = 'R'; root = rotate_right(g)  # LL
        # 对称情况省略
    root.color = 'B'; return root
```
### 5.4 B 树与 B+ 树搜索（磁盘 IO 优化）
多路平衡查找树，节点大、高度低，匹配磁盘块以减少 IO。O(log_m n)，m 为阶；IO 次数 ≈ ⌈log_m n⌉。适用数据库索引、文件系统。

| 特性 | B 树 | B+ 树 |
|------|------|-------|
| 关键字存储 | 内节点与叶均存 | 仅叶存，内节点仅索引 |
| 叶链表 | 无 | 有，支持范围顺序遍历 |
| 查找位置 | 可在任意节点命中 | 必到叶节点 |
| 范围查询 | 需中序遍历 | 顺叶链表高效 |
```python
def btree_search(node, key):
    i = 0
    while i < len(node.keys) and key > node.keys[i]: i += 1
    if i < len(node.keys) and key == node.keys[i]: return node
    if node.leaf: return None
    return btree_search(node.children[i], key)
```
### 5.5 跳表 Skip List 的概率平衡原理
多层链表，节点以概率 p（常取 1/2）向更高层提升，期望层高 log_{1/p} n。不靠旋转，靠随机层数维持平衡。查找/插入/删除期望 O(log n)；空间 O(n)。适用并发友好、有序集合（Redis ZSet、LevelDB MemTable）。
```python
import random
def random_level(p=0.5, max_lvl=32):
    lvl = 1
    while random.random() < p and lvl < max_lvl: lvl += 1
    return lvl
def skip_insert(head, val, max_lvl):
    update = [None] * max_lvl; cur = head
    for lvl in range(max_lvl - 1, -1, -1):
        while cur.next[lvl] and cur.next[lvl].val < val: cur = cur.next[lvl]
        update[lvl] = cur
    lvl = random_level(max_lvl=max_lvl); node = SkipNode(val, lvl)
    for i in range(lvl): node.next[i] = update[i].next[i]; update[i].next[i] = node
```

## 六、外部排序与并行排序
数据量超出内存时，需借助外存与并行以降低 IO 成本。
### 6.1 外部归并排序 External Merge Sort
分两阶段：①内存分段读入、内部排序后写回，形成初始归并段；②多路归并直至单一有序文件。IO 次数 O((n/M)·log_{k}(n/M))，M 为内存容量，k 为归并路数。适用数据库排序、大数据落盘。
### 6.2 败者树 Loser Tree
完全二叉树，叶为各路当前元素，内节点记录"败者"（较大者），根旁记录"胜者"（最小者）。建树 O(k)；每次取最小 + 调整 O(log k)，常数小于堆。适用多路归并 k 较大时。
```python
def loser_adjust(ls, k, s, leaves):
    p = (s + k) // 2
    while p > 0:
        if leaves[s] > leaves[ls[p]]: s, ls[p] = ls[p], s
        p //= 2
    ls[0] = s
```
### 6.3 多路归并
k 路归并可用堆或败者树选当前最小，配合缓冲区 IO。增大 k 减少 IO 趟数，但单次比较成本 O(log k) 上升，需平衡 k 与内存。
### 6.4 置换-选择排序 Replacement-Selection 与初始归并段
内存中维护堆，输出当前最小；新元素若 ≥ 刚输出值则入当前段，否则标记入下一段，生成更长（平均 2M）的初始归并段，减少归并趟数。
```python
import heapq
def replacement_selection(stream, M):
    heap = []
    for _ in range(M):
        x = next(stream, None)
        if x is not None: heapq.heappush(heap, (x, False))
    last, run = float('-inf'), []
    while heap:
        val, frz = heapq.heappop(heap); run.append(val); last = val
        x = next(stream, None)
        if x is not None: heapq.heappush(heap, (x, x < last))
        if all(f for _, f in heap):
            yield run; run = []
            heap = [(v, False) for v, _ in heap]; heapq.heapify(heap)
    if run: yield run
```
### 6.5 败者树 vs 堆在多路归并中的对比

| 维度 | 败者树 | 堆 |
|------|--------|------|
| 调整比较次数 | ⌈log₂ k⌉ | 2⌈log₂ k⌉ |
| 建树成本 | O(k) | O(k) |
| 实现复杂度 | 较高 | 简单 |
| k 较大时 | 更优 | 比较次数翻倍 |
| 适用场景 | 大规模多路归并 | 通用、小 k |
### 6.6 并行排序
利用多核加速：并行归并——分块各核排序后归并；并行快排——partition 后左右递归分发到不同线程。理想 O(n log n / p)，通信与负载均衡为瓶颈。
```python
from concurrent.futures import ThreadPoolExecutor
def parallel_quick(a, lo, hi, depth=0):
    if lo >= hi: return
    pivot = a[(lo + hi) // 2]; i, j = lo, hi
    while i <= j:
        while a[i] < pivot: i += 1
        while a[j] > pivot: j -= 1
        if i <= j: a[i], a[j] = a[j], a[i]; i += 1; j -= 1
    if depth < 3:
        with ThreadPoolExecutor(2) as ex:
            list(ex.submit(parallel_quick, a, lo, j, depth + 1) for _ in [0])
            list(ex.submit(parallel_quick, a, i, hi, depth + 1) for _ in [0])
    else:
        parallel_quick(a, lo, j, depth + 1); parallel_quick(a, i, hi, depth + 1)
```
### 6.7 排序网络 Sorting Network 与 Bitonic Sort
排序网络是数据无关的比较网络：固定连接的"比较器"序列，输入任意数据均输出有序。Bitonic Sort 利用双调序列的递归比较交换，天然适合 SIMD/GPU。比较器数 O(n log²n)，深度 O(log²n)。适用 GPU/硬件并行排序、固定数据宽度流水线。
```python
def bitonic_merge(a, lo, n, up):
    if n <= 1: return
    m = n // 2
    for i in range(lo, lo + m):
        if (a[i] > a[i + m]) == up: a[i], a[i + m] = a[i + m], a[i]
    bitonic_merge(a, lo, m, up); bitonic_merge(a, lo + m, m, up)
def bitonic_sort(a, lo, n, up):
    if n <= 1: return
    m = n // 2
    bitonic_sort(a, lo, m, True); bitonic_sort(a, lo + m, m, False)
    bitonic_merge(a, lo, n, up)
```
