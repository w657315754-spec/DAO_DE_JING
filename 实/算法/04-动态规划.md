## 一、动态规划的基本思想

### 概念动机

动态规划（Dynamic Programming, DP）由理查德·贝尔曼（Richard Bellman）于 1950 年代提出。"Programming"在此并非"编程"，而是"规划/表格法"之意。其精髓在于：**将多阶段决策过程的最优化问题，拆解为相互嵌套的子问题，并以表格记录中间答案，避免重复计算**。它介于分治与贪心之间——既享受分治的递归结构，又通过记忆化避免指数级重复。

### 最优子结构 Optimal Substructure

若一个问题的最优解，可以由其子问题的最优解组合而成，则称该问题具有**最优子结构**。这是 DP 可行的第一条铁律。

以最短路为例：节点 $s$ 到 $t$ 的最短路径若经过中间节点 $k$，则 $s\to k$ 段与 $k\to t$ 段也必为最短路径。这一性质正是 Dijkstra、Floyd 的基石。但需警惕：**最短路有最优子结构，最长路一般没有**（含负环或路径不可叠加时失效）。

判定要点：

| 检验步骤 | 内容 |
|----------|------|
| 1. 划分子问题 | 能否将原解表述为"选择 + 子问题"的形式 |
| 2. 反证法验证 | 假设子问题解非最优，能否构造出更优的原问题解导出矛盾 |
| 3. 独立性 | 子问题之间不应相互影响（否则需增加状态维度） |

### 重叠子问题 Overlapping Subproblems

分治要求子问题**互不相交**；DP 则恰恰相反，它受益于子问题的**大量重叠**。朴素递归会对同一子问题反复求解（如斐波那契的指数爆炸），而 DP 用一张表把每个子问题只算一次——这正是时间从指数降到多项式的根源。

### 自顶向下记忆化 vs 自底向上 Tabulation

| 维度 | 记忆化搜索 Memoization（自顶向下） | 递推填表 Tabulation（自底向上） |
|------|-----------------------------------|-------------------------------|
| 方向 | 从原问题出发，递归 + 缓存 | 从基础状态出发，迭代填表 |
| 实现 | 递归 + 哈希/数组缓存 | 循环 + 数组 |
| 计算量 | 仅计算实际到达的状态 | 逐个填满所有状态 |
| 空间 | 递归栈 + 缓存 | 通常可滚动压缩 |
| 适用 | 状态稀疏/难以确定填表顺序 | 状态稠密/需要严格顺序 |
| 易错点 | 栈溢出、缓存键设计 | 填表顺序、边界初始化 |

### 递推关系与状态转移方程

状态转移方程是 DP 的"灵魂公式"。它刻画了**状态如何由更小的状态演化而来**。设计步骤：

1. **定义状态** `dp[...]`：明确其语义（如"前 $i$ 个物品、容量 $j$ 时的最大价值"）
2. **确定答案位置**：`dp[n]` 或 `max(dp[...])`
3. **写出转移**：`dp[i] = opt{ dp[j] + cost(j, i) }`
4. **确立边界与填表顺序**

```python
# 状态转移方程的抽象模板
# dp[i] = min/max { dp[j] + w(j, i) }   0 <= j < i
def abstract_dp(n, w):
    INF = float('inf')
    dp = [INF] * (n + 1)
    dp[0] = 0                       # 边界：空问题的解
    for i in range(1, n + 1):
        for j in range(i):
            dp[i] = min(dp[i], dp[j] + w(j, i))   # 转移：枚举上一步决策 j
    return dp[n]
```

### 空间优化：滚动数组与原地压缩

当 `dp[i]` 只依赖有限个前驱状态时，可把高维数组压低：

- **滚动数组**：用 `% 2` 在两行间交替，把 $O(n)$ 空间降到 $O(1)$
- **原地一维压缩**：01背包逆序遍历容量，保证每个物品只用一次
- **变量滚动**：斐波那契只需两个变量 `a, b = b, a+b`

```python
# 空间优化示例：01背包一维压缩（逆序保证每物品仅用一次）
def knapsack_1d(n, W, wt, val):
    dp = [0] * (W + 1)
    for i in range(n):                     # 枚举物品
        for j in range(W, wt[i] - 1, -1):  # 逆序枚举容量
            dp[j] = max(dp[j], dp[j - wt[i]] + val[i])
    return dp[W]
```

### DP vs 分治 vs 贪心

| 范式 | 子问题关系 | 是否记忆 | 决策回溯 | 典型问题 |
|------|-----------|---------|---------|---------|
| 分治 Divide & Conquer | 互不相交 | 否 | 无 | 归并排序、快速排序 |
| 贪心 Greedy | 无显式划分 | 否 | 不回溯 | Huffman 编码、区间调度 |
| 动态规划 DP | 重叠、嵌套 | 是 | 枚举所有决策 | 背包、LCS、编辑距离 |

贪心是"只走一条路"的 DP，DP 是"走完所有路再选最优"的贪心——是否具备最优子结构与能否贪心，决定二者的分野。

## 二、一维 DP

### 概念动机

一维 DP 是入门 DP 的最佳训练场。它用单一指标 `dp[i]` 刻画"前缀最优"，状态维度低、转移直观，却能涵盖从数列递推到序列选优的丰富模型。

### 斐波那契数列：四种实现

斐波那契是 DP 的"Hello World"，其转移 $F(n)=F(n-1)+F(n-2)$ 演化出四种实现：

```python
from functools import lru_cache

# 1. 朴素递归：O(2^n) —— 重叠子问题导致指数爆炸
def fib_rec(n):
    return n if n < 2 else fib_rec(n-1) + fib_rec(n-2)

# 2. 记忆化搜索：O(n) 自顶向下
@lru_cache(maxsize=None)
def fib_memo(n):
    return n if n < 2 else fib_memo(n-1) + fib_memo(n-2)

# 3. 迭代填表：O(n) 自底向上 + O(1) 空间
def fib_iter(n):
    a, b = 0, 1
    for _ in range(n):
        a, b = b, a + b
    return a

# 4. 矩阵快速幂：O(log n) —— 加速线性递推
def mat_mul(A, B):
    return [[sum(A[i][k]*B[k][j] for k in range(2)) for j in range(2)] for i in range(2)]

def fib_matrix(n):
    if n == 0: return 0
    res, base = [[1,0],[0,1]], [[1,1],[1,0]]   # 单位阵与转移阵
    n -= 1
    while n:
        if n & 1: res = mat_mul(res, base)
        base = mat_mul(base, base)
        n >>= 1
    return res[0][0]
```

| 实现 | 时间 | 空间 | 关键思想 |
|------|------|------|---------|
| 朴素递归 | $O(2^n)$ | $O(n)$ 栈 | 体现重叠子问题的"病态" |
| 记忆化 | $O(n)$ | $O(n)$ | 自顶向下 + 缓存 |
| 迭代 | $O(n)$ | $O(1)$ | 自底向上 + 滚动变量 |
| 矩阵快速幂 | $O(\log n)$ | $O(\log n)$ | 把线性递推转为矩阵幂 |

### 爬楼梯问题

每次可跨 1 或 2 阶，问爬到第 $n$ 阶有多少种方法。状态 `dp[i]` = 到达第 $i$ 阶的方案数，转移 $dp[i]=dp[i-1]+dp[i-2]$，边界 $dp[0]=dp[1]=1$。本质即斐波那契数列的位移。

### 打家劫舍 House Robber 系列

**线性版**：不能偷相邻两间，求最大收益。状态 `dp[i]` = 前 $i$ 间能偷到的最大金额：

$$dp[i]=\max(dp[i-1],\ dp[i-2]+nums[i])$$

**环形版**：首尾相邻，故分别对 `nums[1:]` 与 `nums[:-1]` 跑线性版取最大值。

**树形版**：树上的最大独立集，见第四节树形 DP。

```python
def rob(nums):
    prev, curr = 0, 0          # dp[i-2], dp[i-1]
    for x in nums:
        prev, curr = curr, max(curr, prev + x)
    return curr
```

### 最长递增子序列 LIS：两种复杂度

**O(n²) DP**：`dp[i]` = 以 `nums[i]` 结尾的 LIS 长度，转移 $dp[i]=\max_{j<i,\ nums[j]<nums[i]}(dp[j]+1)$。

**O(n log n) 贪心 + 二分**：维护一个"尾元素数组"，对每个数二分查找其位置并替换。该数组长度即 LIS 长度。

```python
import bisect

def length_of_LIS(nums):
    tails = []                          # tails[k] = 长度为 k+1 的所有上升子序列的最小尾
    for x in nums:
        i = bisect.bisect_left(tails, x)  # 严格上升用 bisect_left；非降用 bisect_right
        if i == len(tails):
            tails.append(x)
        else:
            tails[i] = x
    return len(tails)
```

| 方法 | 时间 | 空间 | 能否还原序列 |
|------|------|------|-------------|
| DP | $O(n^2)$ | $O(n)$ | 是 |
| 贪心+二分 | $O(n\log n)$ | $O(n)$ | 需额外记录前驱 |

### 最大子数组和：Kadane 算法

`dp[i]` = 以 `nums[i]` 结尾的最大子数组和，转移 $dp[i]=\max(nums[i],\ dp[i-1]+nums[i])$。答案为 $\max_i dp[i]$。可压缩为单变量滚动。

```python
def max_sub_array(nums):
    best = cur = nums[0]
    for x in nums[1:]:
        cur = max(x, cur + x)   # 要么延续，要么从 x 重新开始
        best = max(best, cur)
    return best
```

### DP 中的状态定义技巧

- **以谁结尾**：LIS、Kadane 都用"以 `i` 结尾"定义，便于拼接前驱
- **前缀最优**：打家劫舍用"前 `i` 项"定义，便于决策第 `i` 项是否取
- **加维度消歧义**：股票买卖引入"持有/不持有"状态消除后效性
- **状态机视角**：将有限状态间转移画成图，DP 即在图上求最长路

经典题目：LeetCode 70 爬楼梯、198 打家劫舍、213 打家劫舍 II、300 LIS、53 最大子数组和、152 乘积最大子数组、746 最小代价爬楼梯。

## 三、背包问题系列

### 概念动机

背包问题是 DP 最经典的问题族，几乎所有"在容量约束下选物品求最优"的模型都可视作其变体。其状态设计 `dp[i][j]` —— 前 $i$ 件物品、容量 $j$ 时的最优值——成为 DP 教学的范式。

### 01 背包：二维到一维

每件物品最多选一次。状态 `dp[i][j]` = 前 $i$ 件物品、容量 $j$ 的最大价值：

$$dp[i][j]=\max\big(dp[i-1][j],\ dp[i-1][j-w_i]+v_i\big)$$

空间优化为一维时，**必须逆序枚举容量**，否则同一物品会被多次取用，退化为完全背包。

```python
def knapsack01(n, W, wt, val):
    dp = [0] * (W + 1)
    for i in range(n):
        for j in range(W, wt[i] - 1, -1):   # 逆序：保证每物品只用一次
            dp[j] = max(dp[j], dp[j - wt[i]] + val[i])
    return dp[W]
```

### 完全背包 Unbounded Knapsack

每件物品可选无限次。转移改为"在同一 $i$ 层内顺序转移"：

$$dp[i][j]=\max\big(dp[i-1][j],\ dp[i][j-w_i]+v_i\big)$$

一维实现只需将 01 背包的逆序改为**顺序**枚举容量。零钱兑换、完全平方数等皆为其变体。

### 多重背包：二进制与单调队列优化

第 $i$ 种物品有 $c_i$ 件。朴素拆分 $O(nW\sum c_i)$。

- **二进制优化**：把 $c_i$ 拆成 $1,2,4,\dots,2^k,r$ 的若干包，转化为 01 背包，复杂度 $O(nW\sum \log c_i)$
- **单调队列优化**：对同余的容量类使用单调队列滑动窗口求最大，复杂度 $O(nW)$

```python
def multi_knapsack_binary(n, W, wt, val, c):
    dp = [0] * (W + 1)
    for i in range(n):
        cnt = c[i]
        k = 1
        while k < cnt:                       # 二进制拆包
            w, v = k * wt[i], k * val[i]
            for j in range(W, w - 1, -1):
                dp[j] = max(dp[j], dp[j - w] + v)
            cnt -= k
            k <<= 1
        if cnt:                              # 处理余数
            w, v = cnt * wt[i], cnt * val[i]
            for j in range(W, w - 1, -1):
                dp[j] = max(dp[j], dp[j - w] + v)
    return dp[W]
```

### 分组背包

物品分为若干组，每组至多选一件。转移时对每组做"选一件或不选"的决策：

```python
def group_knapsack(W, groups):
    dp = [0] * (W + 1)
    for group in groups:                     # 组间
        for j in range(W, -1, -1):           # 容量逆序
            for w, v in group:               # 组内至多选一件
                if j >= w:
                    dp[j] = max(dp[j], dp[j - w] + v)
    return dp[W]
```

### 背包问题的变体

| 变体 | 模型映射 | 关键差异 |
|------|---------|---------|
| 分割等和子集（LC 416） | 01背包，价值=重量，目标恰为 $sum/2$ | 求可行性而非最大值 |
| 零钱兑换（LC 322） | 完全背包求最少硬币数 | 求 $\min$，初始化为 $\infty$ |
| 零钱兑换 II（LC 518） | 完全背包求组合数 | 求计数，初始化 `dp[0]=1` |
| 最后一块石头重量 II（LC 1049） | 01背包尽量装满一半 | 转化为"两堆差最小" |

### 背包问题对比表

| 类型 | 物品数 | 转移方向 | 一维枚举顺序 | 复杂度 |
|------|--------|---------|-------------|--------|
| 01 背包 | 至多 1 次 | $i-1 \to i$ | 逆序 | $O(nW)$ |
| 完全背包 | 无限 | $i$ 层内自转 | 顺序 | $O(nW)$ |
| 多重背包 | $c_i$ 件 | 二进制/单调队列 | 逆序 | $O(nW)$ 或 $O(nW\log c)$ |
| 分组背包 | 组内至多 1 | 组间 + 组内枚举 | 逆序 | $O(\sum|g_k|\cdot W)$ |

经典题目：LC 416、322、518、1049、494 目标和、279 完全平方数、139 单词拆分。

## 四、区间 DP 与树形 DP

### 概念动机

当问题的最优结构落在"一段连续区间"或"一棵子树"上时，DP 的状态天然变为二维 `dp[i][j]`（区间端点）或以节点为下标的树形结构。两者共同点：**由小尺度合并到大尺度**。

### 区间 DP：状态设计与断点枚举

通用模板：`dp[i][j]` = 处理区间 $[i,j]$ 的最优值，枚举断点 $k$ 将区间分为 $[i,k]$ 与 $[k+1,j]$（或 $[i,k]$、$[k,j]$）两段合并：

$$dp[i][j]=\min_{i\le k<j}\big(dp[i][k]+dp[k+1][j]\big)+\text{cost}(i,j)$$

按**区间长度**从小到大填表，保证子区间已算好。

```python
# 区间 DP 通用框架（以最小代价为例）
def interval_dp(n, cost):
    dp = [[0]*n for _ in range(n)]
    for length in range(2, n+1):              # 枚举区间长度
        for i in range(n - length + 1):       # 枚举左端点
            j = i + length - 1
            dp[i][j] = float('inf')
            for k in range(i, j):             # 枚举断点
                dp[i][j] = min(dp[i][j], dp[i][k] + dp[k+1][j] + cost(i, j))
    return dp[0][n-1]
```

### 经典区间 DP

| 问题 | 状态语义 | 转移要点 | 复杂度 |
|------|---------|---------|--------|
| 矩阵链乘法 MCM | `dp[i][j]` = 合并 $M_i\dots M_j$ 的最少乘法次数 | 枚举最后相乘的断点 $k$ | $O(n^3)$ |
| 石子合并 | `dp[i][j]` = 合并 $[i,j]$ 的最小代价 | 枚举最后合并的断点，加前缀和 | $O(n^3)$ |
| 戳气球 Burst Balloons | `dp[i][j]` = 戳掉 $(i,j)$ 内气球的最大收益 | 枚举最后戳的 $k$，依赖边界 $i,j$ | $O(n^3)$ |
| 最长回文子序列 LPS | `dp[i][j]` = $[i,j]$ 内最长回文子序列 | 两端相等则 $+2$，否则取两侧 | $O(n^2)$ |

戳气球的状态设计是经典"逆向思维"：不先戳谁，而**最后戳谁**——这样子问题边界 $i,j$ 始终由原始边界充当，避免状态依赖被打乱的戳序。

### 树形 DP：后序遍历模式

树形 DP 的状态以节点为下标，依赖关系沿"子节点 → 父节点"方向，因此天然对应**后序遍历**：先递归子树，再用子树结果更新父节点。

**没有上司的舞会 / 树的最大独立集**：每个节点选或不选，不能父子同选。

$$f[u][0]=\sum_v \max(f[v][0],f[v][1]),\qquad f[u][1]=w_u+\sum_v f[v][0]$$

其中 $v$ 遍历 $u$ 的子节点。

```python
def tree_dp(start, n, w, children):
    # f[u][0] = 不选 u 的最优; f[u][1] = 选 u 的最优
    f = [[0, 0] for _ in range(n)]
    def dfs(u, fa):
        f[u][1] = w[u]
        for v in children[u]:
            if v == fa: continue
            dfs(v, u)
            f[u][0] += max(f[v][0], f[v][1])   # 子节点随意
            f[u][1] += f[v][0]                 # 选 u 则子必不选
    dfs(start, -1)
    return max(f[start][0], f[start][1])
```

### 泛化：图上 DP 与环状结构

- **树的最大权独立集**：无根树版最大独立集，任选根后序 DP
- **树的重心**：DP 统计每个子树大小，最大子树最小者即为重心
- **DAG 上 DP**：拓扑序即填表序，最长路/最短路皆可
- **环状结构**：破环为链，分别强制两端"选/不选"跑两遍 DP 取最优（如打家劫舍 II 的环形版本）

经典题目：LC 312 戳气球、516 最长回文子序列、132 分割回文串 II、337 打家劫舍 III、洛谷 P2014 选课、P1352 没有上司的舞会。

## 五、状态压缩 DP

### 概念动机

当问题规模虽小但状态天然是"集合"时，可用整数二进制位表示集合元素的有无，把指数级的状态空间压进一个整数下标——这就是状压 DP。其适用门槛严格：**$N\le 20$**，因为 $2^{20}\approx 10^6$。

### 位运算基础

| 操作 | 表达式 | 含义 |
|------|--------|------|
| 元素 $i$ 在集合中 | `(s >> i) & 1` | 检查第 $i$ 位 |
| 加入元素 $i$ | `s \| (1 << i)` | 置第 $i$ 位为 1 |
| 删除元素 $i$ | `s & ~(1 << i)` | 置第 $i$ 位为 0 |
| 枚举子集 | `sub = s; while sub: ...; sub = (sub-1) & s` | 遍历 $s$ 的所有非空子集 |
| 元素个数 | `bin(s).count('1')` 或 `popcount(s)` | 集合大小 |

**子集枚举**是状压 DP 的高频操作，枚举 $s$ 的所有子集总耗时 $O(3^N)$（由 $\sum_k \binom{N}{k}2^k=3^N$ 给出）。**SOS DP**（Sum Over Subsets）则用 $O(N2^N)$ 预处理每个状态的子集之和：

```python
# SOS DP：f[mask] = sum of g[sub] for all sub ⊆ mask
def sos_dp(g, n):
    f = g[:]
    for i in range(n):               # 逐位纳入
        for mask in range(1 << n):
            if mask & (1 << i):
                f[mask] += f[mask ^ (1 << i)]
    return f
```

### 旅行商问题 TSP

给定完全图，求经过所有点恰一次再回到起点的最短回路。状态 `dp[mask][i]` = 已访问集合为 `mask`、当前位于 $i$ 的最短路径：

$$dp[mask][i]=\min_{j\in mask,\ j\ne i}\big(dp[mask\setminus\{i\}][j]+d[j][i]\big)$$

```python
def tsp(d, n):
    INF = float('inf')
    dp = [[INF]*n for _ in range(1 << n)]
    dp[1][0] = 0                          # 从 0 出发
    for mask in range(1 << n):
        for i in range(n):
            if not (mask >> i) & 1 or dp[mask][i] == INF: continue
            for j in range(n):
                if (mask >> j) & 1: continue   # 未访问 j
                nxt = mask | (1 << j)
                dp[nxt][j] = min(dp[nxt][j], dp[mask][i] + d[i][j])
    # 回到起点
    return min(dp[(1<<n)-1][i] + d[i][0] for i in range(1, n))
```

复杂度 $O(2^n n^2)$，$n\le 20$ 可解。

### 棋盘类状压：玉米田与炮兵阵地

逐行转移，用一行的二进制串表示该行放置方案，需满足：

- 行内不冲突（相邻位不同时为 1，或受攻击范围约束）
- 与前若干行不冲突

```python
# 玉米田（Mondrian's 简化版）：相邻格子不能同时种
def corn_field(board, m, n):     # board[r] 标记第 r 行的障碍位
    states = [s for s in range(1 << n) if (s & (s << 1)) == 0]  # 行内合法
    # dp[r][s] = 前 r 行、第 r 行状态为 s 的方案数
    dp = {s: 1 for s in states if (s & board[0]) == 0}
    for r in range(1, m):
        ndp = {}
        for s in states:
            if s & board[r]: continue
            cnt = sum(dp.get(s2, 0) for s2 in states
                      if (s & s2) == 0)             # 与上一行不冲突
            if cnt: ndp[s] = cnt % 100000000
        dp = ndp
    return sum(dp.values()) % 100000000
```

炮兵阵地引入"前两行"约束，状态维度升至 `dp[r][s1][s2]`，但思路一致。

### 状压 DP 的适用条件与进阶

| 适用条件 | 说明 |
|----------|------|
| $N\le 20$ | $2^N$ 状态数可控 |
| 状态可二进制编码 | 集合/选/不选天然适配 |
| 转移依赖有限前驱 | 逐行/逐列可滚动 |

**与 meet-in-the-middle 结合**：当 $N$ 达 40 时，把集合拆成两半各 $2^{20}$，分别求子集答案再双指针/哈希合并，可把 $O(2^N)$ 降到 $O(2^{N/2})$。

**插头 DP / 轮廓线 DP**：处理网格上的连通性/回路计数问题（如多米诺铺砖、Hamilton 回路计数）。它以"轮廓线"上的连通性为状态，用进制编码或括号表示法压缩，是状压 DP 的高阶形态，典型复杂度 $O(nm\cdot C^m)$，$m$ 较小。

经典题目：LC 943 最短超级串、洛谷 P1896 互不侵犯（玉米田炮兵类）、P2704 炮兵阵地、P4774 状压 DP 综合题。

## 六、DP 优化技巧

### 概念动机

朴素 DP 常达 $O(n^2)$ 甚至更高。当状态转移呈现特殊结构时——单调性、决策单调性、线性递推、凸性——可借助数据结构与数学工具把复杂度降阶，这是竞赛与工程中的进阶主题。

### 单调队列优化

适用形如 $dp[i]=\min_{j\in[i-L,\,i-R]}\{dp[j]+w(j,i)\}$ 的滑动窗口最值。维护一个单调队列，使每次取最值为 $O(1)$，整体降到 $O(n)$。

**滑动窗口最大值 / 跳房子 Jump Game IV**：在长度受限的窗口内维护最值，是单调队列的直接应用，也是多重背包 $O(nW)$ 优化的核心。

```python
from collections import deque

def max_sliding_window(nums, k):
    q = deque()        # 存下标，对应值单调递减
    res = []
    for i, x in enumerate(nums):
        while q and nums[q[-1]] <= x:   # 维护单调递减
            q.pop()
        q.append(i)
        if q[0] <= i - k:               # 队首出窗
            q.popleft()
        if i >= k - 1:
            res.append(nums[q[0]])
    return res
```

### 斜率优化 / Convex Hull Trick

适用形如 $dp[i]=\min_{j<i}\{dp[j]+a_i\cdot x_j+y_j\}$ 的转移。把每个 $j$ 视为直线 $y = x_j\cdot a + y_j$，查询斜率 $a_i$ 处的最小值，用**凸包**维护候选直线，使每次查询 $O(\log n)$ 或均摊 $O(1)$，把 $O(n^2)$ 降到 $O(n\log n)$。

适用前提：$x_j$（决策点横坐标）单调、$a_i$（查询斜率）单调时可达 $O(n)$。经典题目如洛谷 P3195 玩具装箱。

### 矩阵快速幂加速线性递推

若递推是**线性**的（如斐波那契、常系数齐次递推），可构造 $k\times k$ 转移矩阵 $M$，则 $\text{state}_n = M^n\cdot \text{state}_0$，用快速幂在 $O(k^3\log n)$ 内求第 $n$ 项。结合 Cayley-Hamilton 还可降到 $O(k^2\log n)$。这是从 $O(n)$ 到 $O(\log n)$ 的飞跃，常用于 $n$ 极大（如 $10^{18}$）的计数题。

### 决策单调性优化

若最优决策点 $opt(i)$ 随 $i$ 单调不减，即 $opt(i)\le opt(i+1)$，则可大幅减少枚举：

| 优化 | 适用 | 复杂度 | 思路 |
|------|------|--------|------|
| Knuth Optimization | 转移满足四边形不等式且 $\text{cost}$ 满足包含关系 | $O(n^2)$ → $O(n^2)$ 实际常数/区间 DP 降到 $O(n^2)$ | 调整 $k$ 的枚举范围 $s[i][j-1]\le k\le s[i+1][j]$ |
| Divide & Conquer DP | 决策单调且可离线 | $O(n^2)$ → $O(n\log n)$ | 分治中先算中点最优决策，再约束两侧范围 |

**四边形不等式**：$\text{cost}(a,d)+\text{cost}(b,c)\ge \text{cost}(a,c)+\text{cost}(b,d)$，$a\le b\le c\le d$，是 Knuth 优化的判据。石子合并满足此式。

### CDQ 分治与数据结构优化

- **CDQ 分治**：处理带"时间/偏序"的 DP，先递归左半，再用左半更新右半（类似归并排序思想），把二维偏序降为一维，常用于三维 LIS 等问题
- **树状数组/线段树优化**：当转移为 $dp[i]=\max_{j<i,\ x_j\le x_i}\{dp[j]\}+1$ 形式时，用数据结构按权值维护最值，把 $O(n^2)$ 降到 $O(n\log n)$（LIS 的 $O(n\log n)$ 即此思想的简化）
- **李超树**：斜率优化的在线通用版，支持任意顺序插入直线、查询最值

| 题目 | 状态定义 | 转移方程 | 复杂度 |
|------|---------|---------|--------|
| 爬楼梯 LC 70 | $dp[i]$：到第 $i$ 阶方案数 | $dp[i]=dp[i-1]+dp[i-2]$ | $O(n)$ |
| 打家劫舍 LC 198 | $dp[i]$：前 $i$ 间最大收益 | $dp[i]=\max(dp[i-1],dp[i-2]+nums[i])$ | $O(n)$ |
| 零钱兑换 LC 322 | $dp[j]$：凑 $j$ 的最少硬币 | $dp[j]=\min(dp[j],dp[j-c]+1)$ | $O(nW)$ |
| 编辑距离 LC 72 | $dp[i][j]$：$A_{1..i}\to B_{1..j}$ 最少操作 | 见下 | $O(nm)$ |
| 最长公共子序列 LCS | $dp[i][j]$：$A_{1..i},B_{1..j}$ 的 LCS | $dp[i][j]=dp[i-1][j-1]+1$（相等）/$\max(dp[i-1][j],dp[i][j-1])$ | $O(nm)$ |
| 最长递增子序列 LIS | $dp[i]$：以 $i$ 结尾的 LIS | $dp[i]=\max_{j<i}(dp[j]+1)$ | $O(n^2)$/ $O(n\log n)$ |

编辑距离转移：

$$dp[i][j]=\begin{cases}dp[i-1][j-1],& A_i=B_j\\1+\min(dp[i-1][j],dp[i][j-1],dp[i-1][j-1]),& A_i\ne B_j\end{cases}$$

**股票买卖状态机**：用三维 $dp[i][k][0/1]$（天/交易次数/是否持有）统一建模，121/122/188/309/714 仅在 $k$ 上限、是否含冷冻期、是否含手续费上变化——同一状态机不同参数。

经典题目：LC 72 编辑距离、1143 LCS、300 LIS、62/63 不同路径、121/122/123/188/309/714 股票系列、72/97 字符串 DP、10 正则表达式匹配。
