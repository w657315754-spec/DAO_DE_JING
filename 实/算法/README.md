# 算法研究目录

> "算法 + 数据结构 = 程序。" —— 尼古拉斯·沃斯

## 目录结构

| 文件 | 主题 | 简述 |
|------|------|------|
| `01-数据结构.md` | Data Structures | 数组、链表、树、图、哈希表 |
| `02-排序与搜索.md` | Sorting & Searching | 从冒泡到快排，从二分到B树 |
| `03-图算法.md` | Graph Algorithms | BFS/DFS、最短路、最小生成树、网络流 |
| `04-动态规划.md` | Dynamic Programming | 最优子结构与重叠子问题 |
| `05-贪心与回溯.md` | Greedy & Backtracking | 局部最优与穷尽搜索 |
| `06-计算复杂性理论.md` | Complexity Theory | P vs NP、NP-完全、可计算性 |

## 核心脉络

```
数据结构 ── 算法的载体
排序搜索 ── 最基本的算法 primitives
图算法 ── 关系与连通的计算
动态规划 ── 自底向上的最优解
贪心回溯 ── 自顶向下的策略
复杂性理论 ── 什么能算，什么算不了
```
