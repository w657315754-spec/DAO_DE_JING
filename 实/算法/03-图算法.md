# 图算法

> "图是关系的语言，算法是思考的脚注。" 图论始于柯尼斯堡七桥问题，如今已是社交网络、路由规划、推荐系统与神经网络的共同基石。从 BFS 的层层推进，到最大流的瓶颈消解，再到 PageRank 的随机游走，图算法揭示了"连接"本身的计算规律。

---

## 一、图的基本概念与遍历

### 1.1 图的分类

图 $G=(V,E)$ 由顶点集 $V$ 与边集 $E$ 构成。依据边的性质可作如下分类：

| 分类维度 | 类型 | 说明 |
|----------|------|------|
| 方向 | 有向图 / 无向图 | 边是否有方向 |
| 权重 | 加权图 / 无权图 | 边是否带权值 |
| 环 | 有环图 / 无环图（DAG） | 是否存在回路 |
| 稠密度 | 稠密图 / 稀疏图 | $E$ 接近 $V^2$ 或 $V$ |
| 多重性 | 简单图 / 多重图 / 伪图 | 是否有重边或自环 |

存储方式：邻接矩阵 $O(V^2)$ 适合稠密图；邻接表 $O(V+E)$ 适合稀疏图。

### 1.2 度数与连通性

- 度数：无向图中顶点关联的边数；有向图分入度与出度。
- 连通性：无向图中任意两点可达即为连通图；极大连通子图为连通分量。
- 强连通：有向图中任意两点互相可达，极大连通子图为强连通分量（SCC）。

### 1.3 广度优先搜索 BFS

BFS 以队列驱动，按层次向外扩展，可求无权图的最短边数路径。

```python
from collections import deque, defaultdict

def bfs(graph, start):
    visited = {start}
    queue = deque([(start, 0)])
    order, dist = [], {start: 0}
    while queue:
        u, d = queue.popleft()
        order.append(u)
        for v in graph[u]:
            if v not in visited:
                visited.add(v)
                dist[v] = d + 1
                queue.append((v, d + 1))
    return order, dist
```

复杂度：邻接表 $O(V+E)$，邻接矩阵 $O(V^2)$。

### 1.4 深度优先搜索 DFS

DFS 沿一条路径深入到底再回溯，可记录时间戳并对边分类。

```python
def dfs(graph):
    time = [0]
    dfn, low, visited, finished = {}, {}, set(), {}
    tree, back, forward, cross = [], [], [], []

    def visit(u):
        time[0] += 1
        dfn[u] = low[u] = time[0]
        visited.add(u)
        for v in graph[u]:
            if v not in visited:
                tree.append((u, v))
                visit(v)
            elif v not in finished:
                back.append((u, v))
            elif dfn[v] > dfn[u]:
                forward.append((u, v))
            else:
                cross.append((u, v))
        time[0] += 1
        finished[u] = time[0]

    for n in graph:
        if n not in visited:
            visit(n)
    return dfn, finished
```

边分类：树边（探索新顶点）、前向边（指向后代非树边）、后向边（指向祖先，用于检测环）、交叉边（其余，多见于有向图）。

### 1.5 DFS 的应用

| 应用 | 原理 |
|------|------|
| 连通分量 | 每次 DFS 调用覆盖一个分量 |
| 环检测 | 出现后向边即有环 |
| 拓扑排序 | DAG 逆后序排列即为合法拓扑序 |

```python
def topological_sort(graph, n):
    visited, stack = set(), []
    def visit(u):
        visited.add(u)
        for v in graph[u]:
            if v not in visited:
                visit(v)
        stack.append(u)
    for u in range(n):
        if u not in visited:
            visit(u)
    return stack[::-1]
```

## 二、最短路径算法

### 2.1 Dijkstra 算法

贪心策略：每次从未确定顶点中取距离最小者松弛邻居，适合非负权图。优先队列优化复杂度为 $O((V+E)\log V)$。

```python
import heapq

def dijkstra(graph, start):
    dist = {v: float('inf') for v in graph}
    dist[start] = 0
    pq = [(0, start)]
    while pq:
        d, u = heapq.heappop(pq)
        if d > dist[u]:
            continue
        for v, w in graph[u]:
            nd = d + w
            if nd < dist[v]:
                dist[v] = nd
                heapq.heappush(pq, (nd, v))
    return dist
```

### 2.2 Bellman-Ford 算法

对所有边进行 $V-1$ 轮松弛，可处理负权边；第 $V$ 轮仍能松弛则存在负环。复杂度 $O(VE)$。

```python
def bellman_ford(edges, n, start):
    dist = [float('inf')] * n
    dist[start] = 0
    for i in range(n):
        updated = False
        for u, v, w in edges:
            if dist[u] + w < dist[v]:
                dist[v] = dist[u] + w
                updated = True
        if not updated:
            break
        if i == n - 1 and updated:
            return None  # 检测到负环
    return dist
```

### 2.3 SPFA 算法

队列优化的 Bellman-Ford：仅对距离发生变化的顶点的出边进行松弛。平均 $O(kE)$，最坏 $O(VE)$。

```python
from collections import deque

def spfa(graph, start, n):
    dist = [float('inf')] * n
    dist[start] = 0
    in_queue = [False] * n
    cnt = [0] * n  # 入队次数用于判负环
    dq = deque([start])
    in_queue[start] = True
    while dq:
        u = dq.popleft()
        in_queue[u] = False
        for v, w in graph[u]:
            if dist[u] + w < dist[v]:
                dist[v] = dist[u] + w
                cnt[v] = cnt[u] + 1
                if cnt[v] >= n:
                    return None  # 负环
                if not in_queue[v]:
                    dq.append(v)
                    in_queue[v] = True
    return dist
```

### 2.4 Floyd-Warshall 算法

全源最短路，动态规划：$d_{ij}^{(k)}=\min(d_{ij}^{(k-1)},\ d_{ik}^{(k-1)}+d_{kj}^{(k-1)})$。复杂度 $O(V^3)$，适合稠密小图。

```python
def floyd(dist):
    n = len(dist)
    for k in range(n):
        for i in range(n):
            for j in range(n):
                if dist[i][k] + dist[k][j] < dist[i][j]:
                    dist[i][j] = dist[i][k] + dist[k][j]
    return dist
```

### 2.5 Johnson 算法

全源最短路，适合稀疏图。先加虚拟点用 Bellman-Ford 重标号消除负权，再对各点跑 Dijkstra。复杂度 $O(V^2\log V+VE)$。

### 2.6 A* 算法

启发式搜索：$f(n)=g(n)+h(n)$，其中 $g$ 为已花费代价，$h$ 为到目标的启发估计（如曼哈顿距离或欧几里得距离）。$h$ 可估且不超过真实代价时可保证最优。

```python
import heapq

def astar(grid, start, goal):
    rows, cols = len(grid), len(grid[0])
    def h(a, b):
        return abs(a[0]-b[0]) + abs(a[1]-b[1])  # 曼哈顿
    open_set = [(h(start, goal), 0, start)]
    g_score = {start: 0}
    while open_set:
        _, g, cur = heapq.heappop(open_set)
        if cur == goal:
            return g
        for dx, dy in [(0,1),(0,-1),(1,0),(-1,0)]:
            nx, ny = cur[0]+dx, cur[1]+dy
            nb = (nx, ny)
            if 0 <= nx < rows and 0 <= ny < cols and grid[nx][ny] == 0:
                ng = g + 1
                if ng < g_score.get(nb, float('inf')):
                    g_score[nb] = ng
                    heapq.heappush(open_set, (ng + h(nb, goal), ng, nb))
    return -1
```

### 2.7 最短路径算法对比

| 算法 | 适用 | 负权 | 复杂度 | 备注 |
|------|------|------|--------|------|
| Dijkstra | 单源非负 | 否 | $O((V+E)\log V)$ | 优先队列 |
| Bellman-Ford | 单源 | 是 | $O(VE)$ | 可判负环 |
| SPFA | 单源 | 是 | 均摊 $O(kE)$ | 队列优化 |
| Floyd-Warshall | 全源 | 是 | $O(V^3)$ | 稠密小图 |
| Johnson | 全源稀疏 | 是 | $O(V^2\log V+VE)$ | 重标号+Dijkstra |
| A* | 单目标 | 视 | 依赖启发 | 路径规划 |

## 三、最小生成树

最小生成树（MST）是连通无向图中边权之和最小的生成树，含 $V-1$ 条边。

### 3.1 Prim 算法

贪心：从一个点出发，每次选最小权横切边加入。优先队列优化 $O(E+V\log V)$，适合稠密图。

```python
import heapq

def prim(graph, start):
    visited = set([start])
    edges = [(w, start, v) for v, w in graph[start]]
    heapq.heapify(edges)
    mst, total = [], 0
    while edges and len(visited) < len(graph):
        w, u, v = heapq.heappop(edges)
        if v in visited:
            continue
        visited.add(v)
        mst.append((u, v, w))
        total += w
        for nv, nw in graph[v]:
            if nv not in visited:
                heapq.heappush(edges, (nw, v, nv))
    return mst, total
```

### 3.2 Kruskal 算法

按边权排序，借助并查集依次加入不构成环的边。复杂度 $O(E\log E)$，适合稀疏图。

```python
class DSU:
    def __init__(self, n):
        self.p = list(range(n))
    def find(self, x):
        while self.p[x] != x:
            self.p[x] = self.p[self.p[x]]
            x = self.p[x]
        return x
    def union(self, a, b):
        ra, rb = self.find(a), self.find(b)
        if ra == rb:
            return False
        self.p[ra] = rb
        return True

def kruskal(edges, n):
    edges.sort(key=lambda e: e[2])
    dsu = DSU(n)
    mst, total = [], 0
    for u, v, w in edges:
        if dsu.union(u, v):
            mst.append((u, v, w))
            total += w
    return mst, total
```

### 3.3 Prim 与 Kruskal 对比

| 维度 | Prim | Kruskal |
|------|------|---------|
| 策略 | 顶点扩展 | 边排序选择 |
| 复杂度 | $O(E+V\log V)$ | $O(E\log E)$ |
| 适合 | 稠密图 | 稀疏图 |
| 数据结构 | 优先队列 | 并查集 |

### 3.4 Borůvka 与 Sollin 算法

Borůvka 算法分阶段进行：每一轮每个连通块各自选最小出边，合并后进入下一轮，直到只剩一个块。Sollin 算法是其等价变体。复杂度 $O(E\log V)$，天然适合并行分布式计算。

### 3.5 MST 的性质与应用

- 切割性质：对任意切割，最小横切边必属于某棵 MST。
- 环性质：环上最大权边不属于 MST。
- 唯一性：若所有边权互异，则 MST 唯一。
- 应用：网络设计（布线、管网）、聚类（删除前 $k-1$ 条最大 MST 边得 $k$ 类）、近似算法。

## 四、网络流

### 4.1 最大流问题

给定容量网络，求源点 $s$ 到汇点 $t$ 的最大流量。残量网络中找增广路并增流，直至不存在增广路，即 Ford-Fulkerson 方法。

### 4.2 Edmonds-Karp 算法

用 BFS 寻找最短增广路，避免退化。复杂度 $O(VE^2)$。

```python
from collections import deque

def edmonds_karp(cap, s, t, n):
    flow = [[0]*n for _ in range(n)]
    total = 0
    while True:
        parent = [-1]*n
        parent[s] = s
        q = deque([s])
        while q:
            u = q.popleft()
            for v in range(n):
                if parent[v] == -1 and cap[u][v] - flow[u][v] > 0:
                    parent[v] = u
                    q.append(v)
        if parent[t] == -1:
            return total
        bottleneck = float('inf')
        v = t
        while v != s:
            u = parent[v]
            bottleneck = min(bottleneck, cap[u][v] - flow[u][v])
            v = u
        v = t
        while v != s:
            u = parent[v]
            flow[u][v] += bottleneck
            flow[v][u] -= bottleneck
            v = u
        total += bottleneck
```

### 4.3 Dinic 算法

构建分层图（BFS），在分层图上用 DFS 求阻塞流，反复分层直至汇点不可达。复杂度 $O(V^2E)$，单位容量图可达 $O(E\sqrt{V})$。

### 4.4 Push-Relabel 推重贴标算法

维护顶点高度与余流，通过 push 推送余流、relabel 抬高高度。复杂度 $O(V^3)$，实际常较快。

### 4.5 最小割最大流定理

$s$-$t$ 最大流等于 $s$-$t$ 最小割容量。可用于求解最小割、项目选择、图像分割等问题。

### 4.6 二分图匹配

二分图最大匹配可转化为网络流（源连左、右连汇、边容量 1）。匈牙利算法基于交替路增广 $O(VE)$；Hopcroft-Karp 用 BFS 找多条最短增广路 $O(E\sqrt{V})$。

```python
def hungarian(graph, n_left, n_right):
    match_r = [-1] * n_right
    def dfs(u, visited):
        for v in graph[u]:
            if v in visited:
                continue
            visited.add(v)
            if match_r[v] == -1 or dfs(match_r[v], visited):
                match_r[v] = u
                return True
        return False
    result = 0
    for u in range(n_left):
        if dfs(u, set()):
            result += 1
    return result, match_r
```

### 4.7 最小费用最大流

在最大流基础上要求费用最小。每次用 SPFA（或 Bellman-Ford）沿最小费用增广路增流，即 MCMF 算法。

## 五、强连通分量与双连通分量

### 5.1 Tarjan 算法

DFS 中维护 `dfn`（时间戳）与 `low`（可达最小时间戳），当 `dfn[u]==low[u]` 时弹栈得到一个 SCC。复杂度 $O(V+E)$。

```python
def tarjan_scc(graph, n):
    dfn, low, on_stack, stack = {}, {}, set(), []
    sccs, timer = [], [0]
    def dfs(u):
        timer[0] += 1
        dfn[u] = low[u] = timer[0]
        stack.append(u); on_stack.add(u)
        for v in graph[u]:
            if v not in dfn:
                dfs(v)
                low[u] = min(low[u], low[v])
            elif v in on_stack:
                low[u] = min(low[u], dfn[v])
        if dfn[u] == low[u]:
            comp = []
            while True:
                v = stack.pop(); on_stack.discard(v)
                comp.append(v)
                if v == u:
                    break
            sccs.append(comp)
    for u in range(n):
        if u not in dfn:
            dfs(u)
    return sccs
```

### 5.2 Kosaraju 算法

两次 DFS：第一次在原图求逆后序；第二次在反图按逆后序访问，每次 DFS 树即一个 SCC。复杂度 $O(V+E)$。

### 5.3 Gabow 算法

用双栈替代 `low` 数组，同样一次 DFS 完成 SCC 求解，实现稍简洁。

### 5.4 割点与桥

无向图中，若根有多个子树或某子树 `low[v] >= dfn[u]`，则 $u$ 为割点；若 `low[v] > dfn[u]`，则边 $(u,v)$ 为桥。基于 Tarjan 思想 $O(V+E)$。

```python
def bridges(graph, n):
    dfn, low, res, timer = {}, {}, [], [0]
    def dfs(u, parent):
        timer[0] += 1
        dfn[u] = low[u] = timer[0]
        for v in graph[u]:
            if v not in dfn:
                dfs(v, u)
                low[u] = min(low[u], low[v])
                if low[v] > dfn[u]:
                    res.append((u, v))
            elif v != parent:
                low[u] = min(low[u], dfn[v])
    for u in range(n):
        if u not in dfn:
            dfs(u, -1)
    return res
```

### 5.5 双连通分量

- 边双连通分量：删任意一边仍连通，即桥之间分隔的块。
- 点双连通分量：删任意一点仍连通，以割点为枢纽分块。

### 5.6 缩点与 2-SAT

将每个 SCC 缩为一点得到 DAG，可用于求有向图最长路、传递闭包等。2-SAT 问题构造蕴含图 $x\to\neg x$ 的对称边，若同一变量与其否定在同一 SCC 则无解；否则按 SCC 拓扑逆序赋值。

## 六、高级图算法

### 6.1 欧拉路径与哈密顿路径

- 欧拉路径：经过每条边恰好一次。存在条件：连通且恰有 0 或 2 个奇度点；Hierholzer 算法 $O(V+E)$。
- 哈密顿路径：经过每个顶点恰好一次，判定为 NP-完全问题。

```python
def hierholzer(graph, start):
    stack, path = [start], []
    while stack:
        u = stack[-1]
        if graph[u]:
            v = graph[u].pop()
            stack.append(v)
        else:
            path.append(stack.pop())
    return path[::-1]
```

### 6.2 NP-Hard 图问题

| 问题 | 描述 | 复杂度 |
|------|------|--------|
| 旅行商 TSP | 经过所有点回到起点最短路 | NP-难 |
| 最大团 | 最大两两相邻顶点子集 | NP-完全 |
| 图着色 | 最少颜色使相邻异色 | NP-难 |

### 6.3 近似算法与贪心

TSP 的 2-近似（度量情形）：先求 MST，再 DFS 先序遍历得回路，长度不超过最优的 2 倍。贪心图着色按某序对每点选最小可用色，虽非最优但简单实用。

### 6.4 图同构与 GI 问题

判断两图是否顶点一一对应且边关系相同。GI 既未被证明属于 P 也未被证明 NP-完全，属特殊复杂性类；quasipolynomial 算法已被提出。

### 6.5 PageRank 算法

模拟随机游走：$PR(p)=\dfrac{1-d}{N}+d\sum_{q\in M(p)}\dfrac{PR(q)}{L(q)}$，其中 $d$ 为阻尼因子（常取 0.85），$M(p)$ 为指向 $p$ 的页面，$L(q)$ 为 $q$ 的出度。等价于转移矩阵的稳态分布。

```python
def pagerank(graph, n, iters=100, d=0.85):
    pr = [1/n] * n
    for _ in range(iters):
        new = [(1-d)/n] * n
        for u in range(n):
            outs = graph[u]
            if outs:
                share = d * pr[u] / len(outs)
                for v in outs:
                    new[v] += share
            else:
                for v in range(n):
                    new[v] += d * pr[u] / n
        pr = new
    return pr
```

### 6.6 社区检测

- Louvain：贪心最大化模块度 $Q=\frac{1}{2m}\sum_{ij}(A_{ij}-\frac{k_ik_j}{2m})\delta(c_i,c_j)$，分层聚合，大规模高效。
- Girvan-Newman：逐步删除介数中心性最高的边，得到层次化社区结构。

### 6.7 图神经网络基础

GNN 核心是消息传递：$h_v^{(k)}=\mathrm{Update}\bigl(h_v^{(k-1)},\mathrm{Aggregate}(\{h_u^{(k-1)}:u\in N(v)\})\bigr)$。通过邻域聚合与非线性变换逐层更新节点表示，广泛用于节点分类、链路预测与图表分类。

## 总结

| 范畴 | 代表算法 | 核心思想 |
|------|----------|----------|
| 遍历 | BFS / DFS | 层次扩展 / 深入回溯 |
| 最短路 | Dijkstra / Floyd / A* | 贪心松弛 / 动规 / 启发式 |
| 生成树 | Prim / Kruskal | 横切边 / 并查集 |
| 网络流 | Dinic / 匈牙利 | 增广路 / 交替路 |
| 连通性 | Tarjan / Kosaraju | low-dfn / 两次 DFS |
| 高级 | PageRank / GNN | 随机游走 / 消息传递 |

图算法的统一脉络在于"状态在图上的传播"：BFS 传播层次，Dijkstra 传播距离，PageRank 传播权重，GNN 传播特征。掌握这一视角，便能在新问题上构造合适的图模型与算法。
