# 贪心与回溯：局部最优与穷尽搜索

> "贪心是赌徒的直觉，回溯是侦探的耐心；前者追求一击致命，后者宁可行遍万路。" —— 算法哲学札记

## 一、贪心算法基础

### 1.1 贪心选择性质

贪心算法（Greedy Algorithm）在每一步决策时都选择当前看似最优的选项，期望通过一系列局部最优解组合成全局最优解。其成立的核心前提是 **贪心选择性质（Greedy Choice Property）**：全局最优解可以通过局部最优选择逐步构造，且一旦做出选择便无需反悔。

与动态规划不同，贪心一旦做出选择即不可撤回，因此通常只需 **单次扫描**，效率极高。

### 1.2 贪心 vs 动态规划

| 对比维度 | 贪心算法 | 动态规划 |
|---------|---------|---------|
| 决策方式 | 当下取最优，不回头 | 枚举所有子问题状态 |
| 前提条件 | 贪心选择性质 + 最优子结构 | 最优子结构 + 重叠子问题 |
| 子依赖 | 仅依赖当前选择 | 依赖子问题的最优解 |
| 可撤销性 | 不可撤回 | 可比较多种选择 |
| 时间复杂度 | 通常 O(n log n) | O(n²) ~ O(n³) 居多 |
| 正确性 | 需严格证明，易出错 | 状态设计正确即正确 |
| 典型问题 | 活动选择、Huffman、Dijkstra | 0-1背包、LCS、矩阵链乘 |

### 1.3 贪心正确性证明

证明贪心正确性的三种主流方法：

| 方法 | 思路 | 适用场景 |
|------|------|---------|
| **交换论证（Exchange Argument）** | 假设最优解与贪心解不同，逐步将最优解交换为贪心解而不变差 | 活动选择、调度问题 |
| **贪心交换（Greedy Stays Ahead）** | 证明每一步贪心选择都"领先"任何其他选择 | Huffman、区间覆盖 |
| **归纳法（Induction）** | 对步数归纳：第 k 步贪心选择后存在包含该选择的最优解 | 最小生成树、Dijkstra |

**交换论证模板**：设 OPT 为某最优解，GRD 为贪心解。若 OPT 的第一个选择与 GRD 不同，则可用 GRD 的选择替换 OPT 的对应元素，所得解仍最优且不劣于 OPT，反复替换可得 GRD 即最优。

### 1.4 贪心失效的反例：0-1背包

0-1 背包中物品不可分割，按"单位价值最高优先"的贪心策略未必最优：

```
背包容量 W = 50
物品A: w=10, v=60, 单位价值 6.0
物品B: w=20, v=100, 单位价值 5.0
物品C: w=30, v=120, 单位价值 4.0

贪心(按单位价值): 选A + B = 160（剩余容量20装不下C）
最优解:           选B + C = 220
```

此例说明：当选择具有"不可撤回 + 互相挤占"特性时，贪心短视会错失全局最优，须改用动态规划或回溯。

### 1.5 常见贪心策略总结

| 策略 | 思想 | 典型问题 |
|------|------|---------|
| 按结束时间排序 | 尽早腾出后续空间 | 活动选择、区间调度 |
| 按单位价值降序 | 优先高性价比 | 分数背包 |
| 按开始/截止排序 | 避免冲突或违约 | 任务调度、会议室 |
| Huffman 合并最小 | 频率低的深度大 | 最优前缀编码 |
| Kruskal 按边权升序 | 最小边不形成环则取 | 最小生成树 |
| Dijkstra 取最近未访问 | 贪心扩展最短距离 | 单源最短路 |

## 二、经典贪心问题

### 2.1 活动选择问题

给定 n 个活动区间 `[s_i, f_i)`，选出最多互不重叠的活动。贪心策略：**按结束时间升序排序**，每次选最早结束且与已选不冲突的活动。

```python
def activity_selection(activities):
    # activities: [(start, finish), ...]
    activities.sort(key=lambda x: x[1])  # 按结束时间排序
    selected = [activities[0]]
    for s, f in activities[1:]:
        if s >= selected[-1][1]:  # 不与上一个冲突
            selected.append((s, f))
    return selected
```

- **时间复杂度**：O(n log n)（排序）+ O(n)（扫描）= O(n log n)
- **正确性**：交换论证——任何最优解的首个活动都可替换为最早结束者而不减少可选活动数。

### 2.2 区间调度与区间图着色

| 问题 | 描述 | 贪心策略 |
|------|------|---------|
| 最大不重叠区间数 | 选最多互不冲突区间 | 按结束时间排序 |
| 最少会议室数 | 覆盖所有区间需多少资源 | 差分时间线 + 堆/扫描 |
| 区间图着色 | 给冲突区间染色使相邻不同色 | 按起点排序，用最小可用颜色 |

**最少会议室**模板：

```python
import heapq
def min_meeting_rooms(intervals):
    intervals.sort()  # 按开始时间
    heap = []  # 存各会议室的结束时间
    for s, e in intervals:
        if heap and heap[0] <= s:
            heapq.heapreplace(heap, e)  # 复用会议室
        else:
            heapq.heappush(heap, e)
    return len(heap)
```

### 2.3 Huffman 编码

构造最优前缀码使加权路径长度最短。每次合并频率最低的两棵子树。

```python
import heapq
def huffman(freq):
    heap = [[f, [ch, ""]] for ch, f in freq.items()]
    heapq.heapify(heap)
    while len(heap) > 1:
        lo = heapq.heappop(heap)
        hi = heapq.heappop(heap)
        for node in lo[1:]:
            node[1] = '0' + node[1]
        for node in hi[1:]:
            node[1] = '1' + node[1]
        heapq.heappush(heap, [lo[0] + hi[0]] + lo[1:] + hi[1:])
    return sorted(heapq.heappop(heap)[1:], key=lambda x: x[0])
```

- **复杂度**：O(n log n)。正确性由交换论证 + 贪心保持领先证明。

### 2.4 Dijkstra 最短路

贪心地从未确定最近点中选距离最小者扩展，松弛其邻边。

```python
import heapq
def dijkstra(graph, src):
    dist = {v: float('inf') for v in graph}
    dist[src] = 0
    heap = [(0, src)]
    while heap:
        d, u = heapq.heappop(heap)
        if d > dist[u]:
            continue
        for v, w in graph[u]:
            if dist[u] + w < dist[v]:
                dist[v] = dist[u] + w
                heapq.heappush(heap, (dist[v], v))
    return dist
```

- **复杂度**：O((V+E) log V)（堆优化）。**限制**：边权非负。

### 2.5 Kruskal / Prim 最小生成树

| 算法 | 策略 | 数据结构 | 复杂度 |
|------|------|---------|--------|
| Kruskal | 按边权升序，不构成环则加入 | 并查集 | O(E log E) |
| Prim | 从任一点起，贪心加入最近点 | 优先队列 | O(E log V) |

```python
# Kruskal
def kruskal(n, edges):
    edges.sort(key=lambda x: x[2])
    parent = list(range(n))
    def find(x):
        while parent[x] != x:
            parent[x] = parent[parent[x]]
            x = parent[x]
        return x
    mst, total = [], 0
    for u, v, w in edges:
        ru, rv = find(u), find(v)
        if ru != rv:
            parent[ru] = rv
            mst.append((u, v, w))
            total += w
    return mst, total
```

### 2.6 任务调度：SJF / EDF

| 策略 | 含义 | 优化目标 |
|------|------|---------|
| SJF（最短作业优先） | 选剩余时间最短的任务 | 最小化平均等待时间 |
| EDF（最早截止优先） | 选截止时间最早的任务 | 可调度性最大化（单机实时） |

### 2.7 分数背包问题

物品可分割，按单位价值降序装入直至满载。

```python
def fractional_knapsack(capacity, items):
    # items: [(value, weight), ...]
    items.sort(key=lambda x: x[0]/x[1], reverse=True)
    total = 0.0
    for v, w in items:
        if capacity >= w:
            total += v
            capacity -= w
        else:
            total += v * (capacity / w)
            break
    return total
```

- **复杂度**：O(n log n)。分数背包贪心最优；0-1背包贪心失效。

## 三、回溯法 Backtracking

### 3.1 回溯 = DFS + 剪枝

回溯法以深度优先方式系统枚举解空间，在搜索过程中对不可能产生解的分支提前剪除（剪枝 pruning），以避免无效穷举。本质是带约束的 DFS，能找到所有可行解或最优解。

### 3.2 解空间树

| 树类型 | 结构 | 每层含义 | 典型问题 |
|--------|------|---------|---------|
| 子集树 | 二叉，深度 n | 第 i 层决定是否选第 i 元素 | 子集、0-1背包 |
| 排列树 | n 叉，深度 n | 第 i 层选第 i 位置的元素 | 全排列、N皇后 |
| 组合树 | 分支递减 | 第 i 层选下一个组合元素 | 组合、组合总和 |

### 3.3 回溯模板框架

```python
def backtrack(path, choices):
    if satisfy(path):          # 满足结束条件
        result.append(path[:])
        return
    for choice in choices:
        if not valid(choice):  # 剪枝
            continue
        path.append(choice)    # 做选择
        backtrack(path, next_choices(path))
        path.pop()             # 撤销选择
```

- **时间复杂度**：最坏 O(2^n)（子集）或 O(n!)（排列），剪枝后大幅降低。
- **空间复杂度**：O(depth) 递归栈。

### 3.4 经典问题

#### N 皇后 N-Queens

在 n×n 棋盘放 n 个皇后互不攻击。用列、主对角、副对角三个集合剪枝。

```python
def solve_n_queens(n):
    res = []
    cols, diag1, diag2 = set(), set(), set()
    def backtrack(row, path):
        if row == n:
            res.append(path[:]); return
        for c in range(n):
            if c in cols or (row-c) in diag1 or (row+c) in diag2:
                continue  # 剪枝：冲突
            cols.add(c); diag1.add(row-c); diag2.add(row+c)
            path.append(c)
            backtrack(row+1, path)
            path.pop()
            cols.remove(c); diag1.remove(row-c); diag2.remove(row+c)
    backtrack(0, [])
    return res
```

#### 全排列 Permutations

```python
def permute(nums):
    res = []
    def backtrack(path, used):
        if len(path) == len(nums):
            res.append(path[:]); return
        for i in range(len(nums)):
            if used[i]: continue
            used[i] = True; path.append(nums[i])
            backtrack(path, used)
            path.pop(); used[i] = False
    backtrack([], [False]*len(nums))
    return res
```

#### 子集 Subsets

```python
def subsets(nums):
    res = []
    def backtrack(start, path):
        res.append(path[:])
        for i in range(start, len(nums)):
            path.append(nums[i])
            backtrack(i+1, path)
            path.pop()
    backtrack(0, [])
    return res
```

#### 组合总和 Combination Sum

```python
def combination_sum(candidates, target):
    res = []
    def backtrack(start, path, remaining):
        if remaining == 0:
            res.append(path[:]); return
        if remaining < 0:
            return  # 剪枝
        for i in range(start, len(candidates)):
            path.append(candidates[i])
            backtrack(i, path, remaining - candidates[i])  # 允许重复
            path.pop()
    backtrack(0, [], target)
    return res
```

#### 数独求解 Sudoku Solver

```python
def solve_sudoku(board):
    def valid(r, c, ch):
        for i in range(9):
            if board[r][i] == ch or board[i][c] == ch: return False
        br, bc = (r//3)*3, (c//3)*3
        for i in range(3):
            for j in range(3):
                if board[br+i][bc+j] == ch: return False
        return True
    def backtrack():
        for r in range(9):
            for c in range(9):
                if board[r][c] == '.':
                    for ch in '123456789':
                        if valid(r, c, ch):
                            board[r][c] = ch
                            if backtrack(): return True
                            board[r][c] = '.'
                    return False  # 九数皆不行，回溯
        return True  # 全部填完
    backtrack()
```

### 3.5 剪枝策略

| 策略 | 做法 | 适用 |
|------|------|------|
| 排序剪枝 | 先排序使早期暴露无解 | 组合总和、子集和 |
| 哈希剪枝 | 用集合 O(1) 判冲突 | N皇后、数独 |
| 对称性剪枝 | 去除等价对称分支 | N皇后旋转/全排列去重 |
| 上下界剪枝 | 剩余价值上界 < 当前最优则剪 | 0-1背包回溯 |
| 可行性剪枝 | 提前判不可行 | 数独、图着色 |

## 四、分支限界 Branch and Bound

### 4.1 BFS式分支限界 vs DFS式回溯

| 对比维度 | 分支限界（BFS/LC） | 回溯（DFS） |
|---------|-------------------|------------|
| 搜索方式 | 广度/优先队列/队列 | 深度优先 |
| 节点扩展 | 逐层或按代价最小 | 一条路走到底 |
| 空间 | O(b^d) 较大 | O(d) 较小 |
| 最优解 | 较快锁定最优 | 需遍历更多 |
| 内存压力 | 高 | 低 |
| 适用 | 求最优解、可设计强界 | 求所有解、约束满足 |

### 4.2 下界与上界函数设计

- **下界函数（lower bound）**：当前部分解 + 剩余部分最优估计的最小可能代价。节点下界 ≥ 已知最优上界则剪。
- **上界函数（upper bound）**：当前可行解的代价，用于更新全局最优。初始可用贪心快速得到一个上界。

界函数越紧，剪枝越有效，但计算开销也越大，需权衡。

### 4.3 LC 分支限界（Least Cost）

LC-Branch-and-Bound 每次从活节点表中选**代价下界最小**的节点扩展，类似 A* 之于 BFS。用优先队列实现。

### 4.4 优先队列式分支限界

```python
import heapq
def branch_and_bound(root):
    best = None
    heap = [(lower_bound(root), root)]
    while heap:
        lb, node = heapq.heappop(heap)
        if best is not None and lb >= best.cost:
            continue  # 剪枝：下界不优于当前最优
        if is_leaf(node):
            if best is None or node.cost < best.cost:
                best = node
            continue
        for child in expand(node):
            heapq.heappush(heap, (lower_bound(child), child))
    return best
```

### 4.5 TSP 的分支限界

用归约矩阵（每行每列减去最小元素）计算下界，选使下界增加最小的边分支。对每条边 (i,j) 分"包含"与"不包含"两支，优先扩展下界小者。

### 4.6 0-1背包的分支限界

节点状态记录已选物品、当前重量与价值。上界 = 当前价值 + 剩余物品按单位价值贪心装入的分数价值。若上界 ≤ 最优价值则剪。

```python
import heapq
def knapsack_bb(w, v, W):
    n = len(w)
    items = sorted(range(n), key=lambda i: v[i]/w[i], reverse=True)
    best = 0
    # 状态: (-上界, 价值, 重量, 索引)
    def bound(val, wt, idx):
        for i in range(idx, n):
            k = items[i]
            if wt + w[k] <= W:
                val += v[k]; wt += w[k]
            else:
                return val + v[k] * (W - wt) / w[k]
        return val
    heap = [(-bound(0, 0, 0), 0, 0, 0)]
    while heap:
        _, val, wt, idx = heapq.heappop(heap)
        if idx == n or -bound(val, wt, idx) <= best:
            continue
        k = items[idx]
        # 选第 idx 个
        if wt + w[k] <= W:
            best = max(best, val + v[k])
            heapq.heappush(heap, (-(bound(val+v[k], wt+w[k], idx+1)), val+v[k], wt+w[k], idx+1))
        # 不选第 idx 个
        heapq.heappush(heap, (-(bound(val, wt, idx+1)), val, wt, idx+1))
    return best
```

### 4.7 与回溯的效率对比

| 指标 | 回溯 | 分支限界 |
|------|------|---------|
| 平均扩展节点 | 多 | 少（界函数引导） |
| 内存占用 | 低 | 高 |
| 实现复杂度 | 简单 | 中等 |
| 求所有解 | 适合 | 不适合 |
| 求最优解 | 较慢 | 较快 |

## 五、启发式搜索与元启发式

当问题规模巨大或 NP-hard，精确算法不可行时，用启发式快速得到"足够好"的近似解。

### 5.1 爬山法 Hill Climbing

从当前解出发，不断移向更优的邻居，直至没有更优邻居。缺点：易陷入**局部最优**、山脊、高原。

```python
def hill_climbing(init, neighbors, score):
    cur = init
    while True:
        nxt = max(neighbors(cur), key=score)
        if score(nxt) <= score(cur):
            return cur  # 局部最优
        cur = nxt
```

### 5.2 模拟退火 Simulated Annealing

以概率接受劣解跳出局部最优，温度高时接受概率大，逐渐降温收敛。

- **Metropolis 准则**：若 ΔE ≤ 0 直接接受；否则以 `exp(-ΔE / T)` 的概率接受。
- **温度调度**：`T = T0 * α^t`（α∈(0,1)）或线性降温。

```python
import random, math
def simulated_annealing(init, neighbor, energy, T0=1000, alpha=0.995, steps=10000):
    cur = init; cur_e = energy(cur); best = cur; best_e = cur_e
    T = T0
    for _ in range(steps):
        nxt = neighbor(cur); nxt_e = energy(nxt)
        delta = nxt_e - cur_e
        if delta < 0 or random.random() < math.exp(-delta / T):
            cur, cur_e = nxt, nxt_e
            if cur_e < best_e:
                best, best_e = cur, cur_e
        T *= alpha
    return best
```

### 5.3 遗传算法 Genetic Algorithm

模拟自然选择。核心要素：**基因编码、种群、适应度、选择、交叉、变异**。

```python
import random
def genetic_algorithm(pop_size, gene_len, fitness, gens=100):
    pop = [[random.randint(0,1) for _ in range(gene_len)] for _ in range(pop_size)]
    for _ in range(gens):
        pop.sort(key=fitness, reverse=True)        # 选择
        elites = pop[:pop_size//2]
        children = []
        while len(children) < pop_size:
            p1, p2 = random.sample(elites, 2)
            pt = random.randint(1, gene_len-1)     # 交叉
            child = p1[:pt] + p2[pt:]
            if random.random() < 0.1:              # 变异
                idx = random.randint(0, gene_len-1)
                child[idx] ^= 1
            children.append(child)
        pop = children
    return max(pop, key=fitness)
```

| 算子 | 作用 | 常见方法 |
|------|------|---------|
| 选择 | 保留优秀个体 | 轮盘赌、锦标赛、精英保留 |
| 交叉 | 组合父代基因 | 单点、多点、均匀 |
| 变异 | 维持多样性 | 位翻转、交换、高斯扰动 |

### 5.4 蚁群 ACO 与粒子群 PSO

| 算法 | 机制 | 适用 |
|------|------|------|
| 蚁群算法 ACO | 信息素浓度 + 启发式引导路径选择 | TSP、路由、调度 |
| 粒子群优化 PSO | 粒子跟踪个体最优与全局最优 | 连续优化、参数寻优 |

### 5.5 禁忌搜索 Tabu Search

通过**禁忌表**记录近期移动禁止重访，避免循环；配合**渴望准则（aspiration）**：若移动导致新最优则解除禁忌。

### 5.6 启发式算法对比

| 算法 | 全局性 | 收敛速度 | 参数量 | 适用场景 |
|------|--------|---------|--------|---------|
| 爬山法 | 弱 | 快 | 极少 | 单峰、快速近似 |
| 模拟退火 | 强 | 中 | 中 | 组合优化、TSP |
| 遗传算法 | 强 | 中 | 多 | 编码空间大、多目标 |
| 蚁群算法 | 强 | 慢 | 中 | 离散路径优化 |
| 粒子群 | 中 | 快 | 少 | 连续函数优化 |
| 禁忌搜索 | 中 | 快 | 少 | 邻域结构清晰 |

## 六、搜索策略综合

### 6.1 DFS vs BFS vs IDDFS vs A*

| 策略 | 数据结构 | 空间 | 完备性 | 最优性 | 特点 |
|------|---------|------|--------|--------|------|
| DFS | 栈 | O(d) | 否(无限深) | 否 | 深入快，空间省 |
| BFS | 队列 | O(b^d) | 是 | 是(等权) | 层序，最优但空间大 |
| IDDFS | 递归 | O(d) | 是 | 是(等权) | 兼顾空间与最优 |
| A* | 优先队列 | O(b^d) | 是 | 是(可纳h) | 启发式加速 |

注：b 为分支因子，d 为解深度。

### 6.2 双向搜索

从起点和终点同时 BFS，在中间相遇，将复杂度从 O(b^d) 降至 O(b^(d/2))。

### 6.3 Meet in the Middle

将问题分成两半各自枚举，再合并。常用于子集和等指数问题，将 O(2^n) 降为 O(2^(n/2))。

```python
def meet_in_the_middle(nums, target):
    n = len(nums); half = n // 2
    left = {sum(s) for r in range(len(nums[:half])+1)
            for s in __import__('itertools').combinations(nums[:half], r)}
    right = [sum(s) for r in range(len(nums[half:])+1)
             for s in __import__('itertools').combinations(nums[half:], r)]
    best = 0
    for s in right:
        # 在 left 中找 <= target - s 的最大
        want = target - s
        cand = max((x for x in left if x <= want), default=None)
        if cand is not None:
            best = max(best, cand + s)
    return best
```

### 6.4 迭代加深 IDDFS

反复以递增深度上限做 DFS，享受 DFS 的 O(d) 空间与 BFS 的最优性。重复展开的开销为常数倍，渐近仍 O(b^d)。

```python
def iddfs(root, goal, max_depth):
    for limit in range(max_depth+1):
        if dfs(root, goal, limit, 0):
            return True
    return False
def dfs(node, goal, limit, depth):
    if depth > limit:
        return False
    if node == goal:
        return True
    return any(dfs(child, goal, limit, depth+1) for child in expand(node))
```

### 6.5 搜索剪枝技术汇总

| 技术 | 原理 | 场景 |
|------|------|------|
| alpha-beta 剪枝 | 维护 α/β 窗口截断必不选的分支 | 博弈树 Minimax |
| 记忆化 | 缓存子问题结果避免重算 | DP、DFS+Memo |
| 对称性消减 | 去除等价状态 | N皇后、棋类 |
| 约束传播 | 提前传播约束缩减取值域 | CSP、数独 |
| 上下界剪枝 | 界函数不优于当前最优则剪 | 分支限界 |

### 6.6 竞赛与面试搜索问题模式

| 模式 | 识别信号 | 推荐策略 |
|------|---------|---------|
| 全排列/组合/子集 | "所有方案""枚举" | 回溯 |
| 棋盘/网格摆放 | "放置""互不攻击" | 回溯 + 剪枝 |
| 最短路(等权) | "最少步数""最少操作" | BFS |
| 最短路(带权) | "最短/最小代价" | Dijkstra/A* |
| 最优组合(指数) | "最大价值""最小代价" | DP 或分支限界 |
| 大规模近似 | "近似""尽量优" | 模拟退火/遗传 |
| 二维指数 | n ≤ 40 | Meet in the Middle |
| 博弈对抗 | "双方轮流""必胜" | Minimax + alpha-beta |
