## 目录结构

| 文件 | 主题 | 简述 |
|------|------|------|

## 核心脉络

```
认知心理学 ── 心智是信息加工系统
发展心理学 ── 生命全程的连续与阶段
社会心理学 ── 个体在群体中的变与不变
变态心理学 ── 正常与异常的边界
精神分析 ── 无意识驱力与早期经验
人本/积极 ── 人的潜能与幸福
```

心理学既是一门科学，也是一种人文关切。它试图用量化的方法回答最主观的问题——我们如何感知、如何记忆、如何爱、如何痛苦。本目录沿此线索展开，每篇独立可读，篇间交叉引用。
