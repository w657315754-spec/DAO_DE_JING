## 核心概念速查

| 概念 | 一句话解释 | 详见 |
|------|-----------|------|
| Qubit（量子比特） | 同时处于 0 和 1 叠加态的信息单元 | 01 |
| Superposition（叠加） | 量子系统同时处于多个状态的能力 | 01 |
| Entanglement（纠缠） | 量子比特间的非经典关联，"幽灵般的超距作用" | 01 |
| Interference（干涉） | 放大正确答案、抵消错误答案的量子效应 | 01 |
| Shor 算法 | 指数级加速大数分解，威胁 RSA | 03 |
| Grover 算法 | √N 加速搜索，适用任何穷举问题 | 03 |
| NISQ | 含噪声中等规模量子计算，当前所处阶段 | 01 |
| 量子优越性 | 量子计算机在特定任务上超越经典计算机 | 01, 04 |
| QKD | 量子密钥分发，利用量子力学实现安全通信 | 03 |
| PQC | 后量子密码学，抵御量子攻击的经典加密 | 03 |
| Transmon | 超导量子比特的主流设计 | 02 |
| 马约拉纳零模 | 拓扑量子比特的物理基础 | 02 |
| QCaaS | 量子计算即服务，当前主要商业模式 | 04 |
