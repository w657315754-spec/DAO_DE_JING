# 04 - 量子计算产业格局

量子计算已从学术实验室走向产业竞争。全球科技巨头、初创公司和国家级实验室正展开激烈角逐。

---

## 主要玩家

### IBM

| 维度 | 详情 |
|------|------|
| 技术路线 | 超导量子比特（transmon） |
| 核心产品 | IBM Quantum System One / System Two |
| 软件框架 | **Qiskit**（开源，Python 量子计算框架） |
| 量子比特路线图 | 2021: 127 (Eagle) → 2022: 433 (Osprey) → 2023: 1,121 (Condor) → 目标: 4,158 (Kookaburra) |
| 商业策略 | **QCaaS**（Quantum Computing as a Service）——通过 IBM Cloud 提供量子计算访问 |
| 独特优势 | 最完整的量子计算生态系统（硬件+软件+云+教育），拥有最大的量子计算社区 |

### Google

| 维度 | 详情 |
|------|------|
| 技术路线 | 超导量子比特 |
| 核心产品 | Sycamore 处理器 |
| 软件框架 | **Cirq**（开源 Python 框架） |
| 里程碑 | 2019 年宣布**量子优越性**（Quantum Supremacy）：Sycamore 53 qubit 在 200 秒内完成随机电路采样，声称经典超算 Summit 需 10,000 年 |
| 争议 | IBM 反驳称该任务在经典超算上仅需 2.5 天（使用硬盘存储优化），"量子优越性"的定量定义存在争议 |
| 最新进展 | Willow 芯片（2024），105 qubit，在量子纠错方面取得突破——错误率随量子比特数量增加而降低 |

### Microsoft

| 维度 | 详情 |
|------|------|
| 技术路线 | **拓扑量子比特**（马约拉纳零模，Majorana Zero Mode） |
| 核心产品 | Azure Quantum（云平台 + 量子开发工具） |
| 软件框架 | Q# 语言、Azure Quantum Development Kit |
| 硬件突破 | 2022 年宣布马约拉纳零模硬件验证；2025 年发布 Majorana 1 芯片 |
| 商业策略 | 不追求短期内量子比特数量领先，而是押注拓扑路线实现"质的飞跃"——天然抗噪声的量子比特 |
| 独特优势 | Azure 云生态整合，提供混合量子-经典计算平台 |

### Intel

| 维度 | 详情 |
|------|------|
| 技术路线 | **硅自旋量子比特**（Silicon Spin Qubit） |
| 核心产品 | Tunnel Falls（12 qubit 测试芯片） |
| 独特优势 | **可兼容传统 CMOS 半导体制造工艺**——2022 年成功用 300mm 晶圆厂光刻工艺批量制造量子比特 |
| 策略 | 利用全球领先的半导体制造能力，将量子比特制造从"手工艺"转向"规模化量产" |
| 挑战 | 硅自旋量子比特的均匀性和保真度仍需提升 |

### D-Wave

| 维度 | 详情 |
|------|------|
| 技术路线 | 量子退火（Quantum Annealing）+ 门模型（Gate-Based） |
| 核心产品 | Advantage 系列 → Advantage2（计划 7,000 qubit） |
| 软件框架 | **Ocean SDK**（开源 Python 框架） |
| 发展历程 | 2007: 16 qubit → 2011: 128 qubit（首台商用，卖给 Lockheed Martin）→ 2015: 突破 1,000 qubit |
| 独特优势 | 最早商用的量子计算公司，在优化问题上有实际应用案例 |
| 挑战 | 量子退火是专用计算而非通用量子计算，量子优势的证明存在争议 |

### 中国力量

| 机构 | 技术路线 | 里程碑 |
|------|----------|--------|
| **中国科学技术大学** | 超导量子比特 | **祖冲之号**（62 qubit），1.2 小时完成经典超算 8 年的采样基准测试（2021） |
| **阿里巴巴** | 超导量子比特 | 与中科院合作，发布 11 qubit 量子云平台 |
| 其他 | 多路线探索 | 中国在量子通信（量子卫星"墨子号"）、量子密钥分发领域全球领先 |

## 量子计算里程碑

| 年份 | 事件 | 意义 |
|------|------|------|
| 1982 | Feynman 提出量子计算构想 | 理论基础 |
| 1994 | Shor 算法 | 证明量子计算的实用价值 |
| 2019 | Google 量子优越性 | 首次实验证明量子计算机超越经典超算 |
| 2021 | 中国科大祖冲之号超越 | 进一步巩固量子优越性 |
| 2023 | IBM 1,121 qubit Condor | 量子比特数量突破千位 |
| 2024 | Google Willow 纠错突破 | 错误率随规模增加而降低 |
| 2024 | NIST 发布 PQC 标准 | 后量子密码标准化 |
| 2025 | Microsoft Majorana 1 | 拓扑量子比特首个芯片 |

## 量子计算云平台（QCaaS）

量子计算即服务（Quantum Computing as a Service）是当前量子计算商业化的主要模式。

| 平台 | 提供方 | 特点 |
|------|--------|------|
| IBM Quantum | IBM | 最大用户群，免费层+付费层 |
| Amazon Braket | AWS | 多硬件后端（IonQ, Rigetti, D-Wave） |
| Azure Quantum | Microsoft | 混合量子-经典计算，Q# 生态 |
| Google Quantum AI | Google | 通过 Cirq 访问 |
| Xanadu Cloud | Xanadu | 光子量子计算 |
| D-Wave Leap | D-Wave | 量子退火云服务 |
