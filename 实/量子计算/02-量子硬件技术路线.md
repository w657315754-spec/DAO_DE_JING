# 02 - 量子硬件技术路线

量子比特的物理实现是量子计算最大的工程挑战之一。目前存在多种竞争技术路线，尚无一种方案实现绝对领先。

---

## 六种主要量子比特技术

### 1. 超导量子比特（Superconducting Qubit）

**代表厂商**：IBM、Google

| 特性 | 说明 |
|------|------|
| 物理实现 | 基于约瑟夫森结（Josephson Junction）的 transmon 设计，材料为铌（Nb）或铝（Al） |
| 工作温度 | 约 15 mK（毫开尔文），接近绝对零度，需稀释制冷机（Dilution Refrigerator） |
| 优势 | 工艺成熟，可扩展性强，门操作速度快（ns 级），与半导体制造工艺兼容 |
| 劣势 | 需要极低温冷却，量子比特相干时间短（~100 μs），易受噪声干扰 |
| 当前状态 | IBM 已发布 433 qubit Osprey（2022），路线图指向 4,158 qubit；Google Sycamore 53 qubit 实现量子优越性 |

### 2. 离子阱量子比特（Trapped-Ion Qubit）

**代表厂商**：IonQ、Quantinuum（Honeywell）

| 特性 | 说明 |
|------|------|
| 物理实现 | 使用电磁场囚禁镱离子（Yb⁺），以离子的电子能级编码量子比特 |
| 工作温度 | 常温或低温（不需要 mK 级冷却） |
| 优势 | 相干时间极长（秒级），门保真度极高（>99.9%），全连接（任意两量子比特可纠缠） |
| 劣势 | 门操作速度慢（μs 级），扩展难度大，离子串扰随规模增加 |
| 当前状态 | IonQ 已上市（NYSE: IONQ），Quantinuum 发布 H2 系统，32 全连接量子比特 |

### 3. 光子量子比特（Photonic Qubit）

**代表厂商**：Xanadu、PsiQuantum

| 特性 | 说明 |
|------|------|
| 物理实现 | 利用激光压缩态（Squeezed State）和环形谐振器，以光子编码量子比特 |
| 工作温度 | **室温运行**——这是光子路线的最大优势之一 |
| 优势 | 无需极低温冷却，低噪声，天然适合量子通信和量子网络，可集成到硅光子芯片 |
| 劣势 | 实现双量子比特门难度大，光子损耗是主要挑战，纠错方案仍在发展中 |
| 当前状态 | Xanadu 发布 Borealis（2022）云平台，在量子优越性基准测试中展现优势；PsiQuantum 获数亿美元融资，目标建造百万量子比特光量子计算机 |

### 4. 硅自旋量子比特（Silicon Spin Qubit）

**代表厂商**：Intel

| 特性 | 说明 |
|------|------|
| 物理实现 | 在硅量子点（Quantum Dot）中囚禁单个电子，利用电子自旋编码量子比特 |
| 工作温度 | 约 1 K（虽仍需低温，但远高于超导路线的 mK 级） |
| 优势 | **可兼容传统半导体制造工艺**——Intel 2022 年已成功用传统光刻工艺批量制造硅自旋量子比特 |
| 劣势 | 量子比特间变异大，门保真度仍需提升，扩展过程中的均匀性控制是挑战 |
| 当前状态 | Intel 发布 Tunnel Falls 12-qubit 芯片（2023），利用 300mm 晶圆厂量产能力 |

### 5. 中性原子量子比特（Neutral Atom Qubit）

**代表厂商**：Atom Computing

| 特性 | 说明 |
|------|------|
| 物理实现 | 利用光镊（Optical Tweezer）阵列囚禁中性原子，以原子核自旋编码量子比特 |
| 工作温度 | 常温（需激光冷却，但不需要稀释制冷机） |
| 优势 | 可扩展至数千个量子比特，原子间全连接性好，相干时间较长 |
| 劣势 | 门操作速度较慢，光学系统复杂度高，原子丢失是实际问题 |
| 当前状态 | Atom Computing 宣布 1,180+ qubit 系统（2023），使用锶-87 原子 |

### 6. 拓扑量子比特（Topological Qubit）

**代表厂商**：Microsoft

| 特性 | 说明 |
|------|------|
| 物理实现 | 基于马约拉纳零模（Majorana Zero Mode），利用拓扑物质态的非局域编码保护量子信息 |
| 工作温度 | 极低温 |
| 优势 | **理论上天然抗噪声**——量子信息存储在拓扑性质中，对外界扰动不敏感，可能大幅降低纠错开销 |
| 劣势 | 马约拉纳零模的物理实现极其困难，至今仍处于基础研究阶段 |
| 当前状态 | 微软 2022 年宣布取得硬件突破，但尚未发布可用的量子比特；2025 年推出 Majorana 1 芯片 |

## 量子退火 vs 门模型

| 维度 | 量子退火（Quantum Annealing） | 门模型（Gate-Based） |
|------|------------------------------|----------------------|
| **代表厂商** | D-Wave | IBM、Google、IonQ 等 |
| **原理** | 利用量子隧穿效应寻找能量最低态，天然适合优化问题 | 通过量子门序列执行任意量子算法，是通用量子计算 |
| **适用场景** | 组合优化、采样、约束满足 | 通用——可运行 Shor、Grover 等所有量子算法 |
| **优势** | 工程实现相对简单，已商用，量子比特数量多 | 通用性强，可运行所有量子算法 |
| **劣势** | 非通用，只能解决特定类型问题 | 实现难度大，当前阶段量子比特数量和保真度有限 |

**D-Wave 发展历程**：
- 2007 年：16 量子比特
- 2011 年：128 量子比特 D-Wave One，首台商用量子计算机，卖给洛克希德·马丁（Lockheed Martin）
- 2015 年：突破 1,000 量子比特
- 计划：Advantage2 系统，目标 7,000 量子比特
- 2023 年：D-Wave 也推出门模型量子处理器，从纯退火路线向混合路线发展

## 关键洞察

1. **尚无赢家**：所有技术路线都面临不同的工程挑战，未来 5–10 年内可能仍是多路线并行的格局。
2. **超导路线目前领先**：IBM 和 Google 的投入最大，量子比特数量和软件生态最成熟。
3. **光子路线的室温优势**：如果双量子比特门和纠错方案取得突破，光子路线可能成为颠覆者。
4. **硅自旋的制造优势**：Intel 的半导体制造能力是独特护城河，一旦技术成熟，规模化速度可能远超其他路线。
5. **拓扑是"圣杯"**：如果实现，将彻底改变量子纠错的格局，但距离实用还有很长的路。
