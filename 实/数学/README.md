# 数学研究目录

> "数学是上帝的语言。" —— 伽利略

## 目录结构

| 文件 | 主题 | 简述 |
|------|------|------|
| `01-数论基础.md` | Number Theory | 素数、同余、费马小定理 |
| `02-微积分.md` | Calculus | 极限、导数、积分——变化与累积的语言 |
| `03-线性代数.md` | Linear Algebra | 向量、矩阵、特征值——空间的代数化 |
| `04-概率与统计.md` | Probability & Statistics | 从随机中提取秩序 |
| `05-几何学.md` | Geometry | 从欧几里得到微分几何 |
| `06-拓扑学.md` | Topology | 形变的科学——不度量距离的几何 |

## 核心脉络

```
数论 ── 离散的最纯粹
微积分 ── 连续的变化法则
线性代数 ── 空间的代数语言
概率统计 ── 不确定性的度量
几何学 ── 形与空间的直觉
拓扑学 ── 形变不变性的抽象
```

数学的伟大之处在于：它既是独立的艺术，又是物理学的底层语法。本目录沿此线索展开，每篇独立可读，篇间交叉引用。
