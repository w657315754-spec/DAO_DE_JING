# 传播学理论

> "媒介即讯息。" —— 马歇尔·麦克卢汉

传播学是一门研究人类信息传递与意义共享之规律的学科。它脱胎于政治学、社会学与心理学的交叉地带，在二十世纪中叶借由香农的数学模型、拉斯韦尔的传播程式与施拉姆的学科化努力，逐步自立门户。自诞生之日起，它便在两种张力之间生长：一者是经验主义的量化传统，追问"传播有何效果、效果如何产生"；一者是批判理论的思辨锋芒，拷问"谁在传播、为谁传播、传播何以成为权力"。本篇自学科起源起笔，经过程模型的谱系、效果范式的百年演变、批判理论的诸家争鸣，入信息加工的认知微观，终于传播学在中国的落地与生长。六篇既立，一幅从模型到权力、从机制到文化的传播图景可窥。

## 一、传播学的起源

### 1.1 概念动机

十九世纪末至二十世纪初，工业革命催生了大众报刊、电影与广播，人类社会第一次面对"媒介饱和"的局面。宣传在两次世界大战中显示了惊人的动员力量，纳粹的广播与好莱坞的新闻片同时证明了：信息一旦工业化生产与规模化分发，便能以前所未有的速度塑造认知与情绪。然而彼时的社会科学尚无一套完整的框架来解释这一现象——新闻学关注采访伦理，社会学关注群体行为，心理学关注个体反应，却无人将"信息—媒介—受众—效果"作为一个闭环系统加以研究。传播学正是在这一空缺中应运而生。

### 1.2 香农-韦弗数学模型（1949）

贝尔实验室的工程师香农（C. Shannon）在研究电话线路的信息传输效率时，与韦弗（W. Weaver）合著《传播的数学理论》（1949），提出了一条线性传播链：

```
信源 → 发射器 → 信道 → 接收器 → 信宿
                    ↑
                   噪声
```

| 要素 | 功能 | 举例 |
|------|------|------|
| 信源 | 产生待传信息 | 说话者、记者 |
| 发射器 | 将信息编码为可传输信号 | 电话将语音转为电信号 |
| 信道 | 承载信号的媒介 | 电话线、电波 |
| 接收器 | 将信号解码还原为信息 | 电话还原电信号为语音 |
| 信宿 | 接收并处理信息 | 听话者、读者 |
| 噪声 | 信道中干扰信号的扰动 | 杂音、失真、干扰 |

香农模型的革命性在于：它首次以形式化、可度量的方式描述传播过程，并引入"熵""冗余""信道容量"等信息论概念，使传播效率可被精确计算。其局限同样明显——它只描述技术层面，对意义、动机与权力三缄其口。然而正是这一"去语义化"的抽象，为后来的传播过程模型提供了共同骨架。

### 1.3 施拉姆与传播学学科化

施拉姆（W. Schramm）被公认为传播学的奠基人。他在衣阿华大学创建了世界上首个传播学研究所（1943），开设首个传播学博士学位课程（1947），并在伊利诺伊、斯坦福等地相继建立研究机构。其关键贡献有四：

| 维度 | 贡献 | 意义 |
|------|------|------|
| 机构 | 创建传播研究所与博士项目 | 使传播学获得制度化建制 |
| 教材 | 编撰《大众传播学》（1949） | 首部传播学教科书，划定学科边界 |
| 理论 | 整合香农、拉斯韦尔、拉扎斯菲尔德诸家 | 以"大众传播过程"图统一分散成果 |
| 培养 | 指导数十位博士，形成学术网络 | 学科再生产的人力基础 |

施拉姆的整合之功在于：他不是某一理论的发明者，而是学科的"建筑师"——将散落于社会学、心理学、新闻学各处的砖瓦收拢，以统一框架砌成一座名为"传播学"的大厦。

### 1.4 拉扎斯菲尔德与经验学派

拉扎斯菲尔德（P. Lazarsfeld）代表了传播学中经验—量化研究的路向。他出身维也纳数学训练，赴美后主持哥伦比亚大学应用社会研究局，将社会学调查方法系统引入传播研究：

| 方法贡献 | 说明 | 应用场景 |
|----------|------|----------|
| 固定样本组（Panel） | 对同一群体重复访谈以追踪态度变化 | 1940 年大选研究 |
| 焦点访谈法 | 半结构化深度访谈，捕捉决策动因 | 陪审团、选民研究 |
| 两级传播假说 | 信息经"意见领袖"中转方达受众 | 见第三节 |
| 统计分析 | 引入路径分析与交叉表 | 量化效果归因 |

1940 年美国总统大选期间，拉扎斯菲尔德对伊利县（Erie County）六百户选民追踪半年，发现：直接改变投票意向的媒体影响微乎其微，真正起作用的是那些"频繁接触媒体并将观点转告他人"的意见领袖。这一发现颠覆了"媒体万能"的直觉，开启了"有限效果论"时代，也奠定了"经验学派"在传播学中的方法论正统地位。

### 1.5 实际应用

- **通信工程**：香农的信息论至今是数据压缩、纠错编码的理论基石
- **受众调查**：拉扎斯菲尔德的固定样本法仍是收视率与民调的方法底座
- **学科建设**：施拉姆的建制化范式被各国传播学院系广泛仿效
- **政策评估**：经验学派方法用于评估公益广告、健康传播的实际效果

## 二、传播过程模型

### 2.1 概念动机

传播非一次性事件，而是一个涉及发送、接收、反馈、噪音、语境的动态过程。自香农给出线性骨架之后，学者们不断为其添加社会与心理维度：线性模型追问"谁对谁说了什么"，循环模型强调"双方互为发送者与接收者"，系统模型则引入"守门人"以解释信息何以被选择、过滤与重构。模型之争，本质是对"传播究竟是单向灌输还是双向协商"这一本体论问题的不同回答。

### 2.2 拉斯韦尔 5W 模型（1948）

拉斯韦尔（H. Lasswell）在一篇政治学论文中顺笔写下一句程式，却成为传播学最广为引用的模型：

> Who, says what, in which channel, to whom, with what effect.

| 5W | 中译 | 对应分析领域 |
|----|------|-------------|
| Who | 谁 | 传播者分析（控制分析） |
| Says what | 说了什么 | 内容分析 |
| In which channel | 通过何种渠道 | 媒介分析 |
| To whom | 对谁说 | 受众分析 |
| With what effect | 有何效果 | 效果分析 |

5W 模型以一句话划定了传播学的五大研究领域，其简洁性至今无人超越。缺陷在于：它是单向的、线性的，忽略了反馈与语境。

### 2.3 布雷多克 7W 模型（1958）

布雷多克（R. Braddock）在 5W 基础上补入两个维度：

> Who, says what, in which channel, to whom, with what effect, **when, where**.

| 新增要素 | 中译 | 意义 |
|----------|------|------|
| When | 在何时 | 时间维度：时机影响效果 |
| Where | 在何地 | 场景维度：空间语境塑造意义 |

7W 模型提醒研究者：传播效果不仅取决于内容与渠道，还受制于时空语境。同一句话在战时与和平时期、在广场与卧室，意义迥然不同。

### 2.4 奥斯古德-施拉姆循环模型（1954）

奥斯古德（C. Osgood）与施拉姆认为，真实的人际传播中不存在固定的"发送者"与"接收者"——每一方都在不断切换角色。他们提出循环模型：

```
A：编码 → 释码 → 译码
              ↕        ← 传播往返循环 →
B：译码 → 释码 → 编码
```

| 概念 | 含义 |
|------|------|
| 编码 | 将意义转为符号（说/写） |
| 释码 | 解释接收到的符号 |
| 译码 | 在自身经验中赋予符号意义 |

此模型的革命性在于"循环"二字：传播不是子弹从枪膛到靶心，而是乒乓球来回往复。反馈被内化为模型的核心，而非事后追加。它适用于人际传播，却难以直接套用于广播式的大众传播。

### 2.5 纽科姆 ABX 平衡模型（1953）

社会心理学家纽科姆（T. Newcomb）将传播嵌入人际关系的结构中，提出 ABX 模型：

```
    A —— X —— B
     \       /
      \     /
       \   /
        \ /
```

| 要素 | 含义 |
|------|------|
| A | 传播者 |
| B | 接收者 |
| X | 双方共同关心的对象（话题） |

其核心命题是：A 与 B 对 X 的态度若不一致，会产生心理张力，促使双方通过传播来寻求平衡。传播由此被理解为一种"维持或恢复认知平衡"的社会行为。当 A 喜爱 X 而 B 厌恶 X 时，传播便会发生——或 A 说服 B，或 B 反过来影响 A，或双方调整对彼此的吸引力以消解张力。

### 2.6 韦斯特利-麦克莱恩信源-守门人模型（1957）

韦斯特利（B. Westley）与麦克莱恩（M. MacLean）融合纽科姆模型与大众传播现实，引入"守门人"角色 C：

```
X（信源/事件） → A（倡导者） → C（守门人/媒介） → B（受众）
                    ↑__________________|
                         反馈回路
```

| 角色 | 功能 |
|------|------|
| X | 客观世界中发生的事件 |
| A | 主动发声的利益相关方（政党、企业、活动家） |
| C | 媒介组织，从海量 X 与 A 声音中筛选、编辑后分发 |
| B | 受众 |

C 是模型的关键：它不代表自身立场发声，而是充当"环境的代理"——替受众从嘈杂的世界中选取值得注意的信息。C 的筛选标准既受制于组织惯例（新闻价值、截稿时间），也受制于外部压力（广告商、政府、舆论）。此模型首次将"守门人"概念正式纳入传播过程，为后来的媒介社会学与新闻生产研究铺路。

### 2.7 各模型核心要素对比

| 模型 | 年代 | 方向 | 反馈 | 核心要素 | 主要贡献者 |
|------|------|------|------|----------|-----------|
| 香农-韦弗 | 1949 | 单向 | 无 | 信源—信道—噪声 | Shannon & Weaver |
| 拉斯韦尔 5W | 1948 | 单向 | 无 | 谁—说什么—渠道—对谁—效果 | Lasswell |
| 布雷多克 7W | 1958 | 单向 | 无 | 5W + 何时 + 何地 | Bradock |
| 奥斯古德-施拉姆 | 1954 | 循环 | 内在 | 编码—释码—译码循环 | Osgood & Schramm |
| 纽科姆 ABX | 1953 | 双向 | 有 | A—B—X 平衡张力 | Newcomb |
| 韦斯特利-麦克莱恩 | 1957 | 双向 | 有 | 信源—倡导者—守门人—受众 | Westley & MacLean |

模型演变的逻辑清晰可见：从线性到循环，从无反馈到有反馈，从个体到系统，从技术到社会。每一次扩展都是对前者的补正，而非否定。

### 2.8 实际应用

- **新闻生产研究**：守门人模型用于分析编辑部的选题机制
- **公关策略**：7W 模型提醒策划者关注传播时机与场景
- **人际沟通训练**：循环模型是谈判与婚姻咨询的理论工具
- **危机传播**：ABX 模型解释公众与企业对同一事件的认知分裂

## 三、效果研究范式演变

### 3.1 概念动机

传播学自诞生之日起便被一个核心问题所牵引：**媒介到底有多大力量？** 答案在百年间经历了戏剧性的摇摆——从"无所不能"到"几乎无效"，再到"适度而深远"，最终归于"因人因境而异"。这一摇摆并非学者朝三暮四，而是研究方法、社会语境与媒介技术共同演变的产物。每一阶段的范式更替，都伴随着一次方法论突破或一次现实冲击。

### 3.2 时间线总览

| 阶段 | 年代 | 代表理论 | 核心命题 |
|------|------|----------|----------|
| 子弹理论 | 1900s–1930s | 魔弹论 / 注射论 | 媒介直接注入受众，效果强大且即时 |
| 有限效果论 | 1940s–1960s | 两级传播 / 意见领袖 | 媒介效果经由人际网络衰减 |
| 适度效果论 | 1960s–1970s | 议程设置 / 使用与满足 | 媒介不决定"怎么想"，但决定"想什么" |
| 强大效果论 | 1970s–1980s | 沉默的螺旋 / 涵化理论 | 长期累积效果可重塑社会认知结构 |
| 谈判式效果 | 1980s 至今 | 编码/解码 / 接收分析 | 效果是文本与受众意义协商的产物 |

### 3.3 子弹理论（魔弹论）

兴起于一战宣传研究。其隐喻是：受众如同靶子，媒介信息如同子弹，一击即中、弹无虚发。代表人物包括宣传分析学者李普曼（W. Lippmann），他在《公众舆论》（1922）中描绘了"拟态环境"——公众眼中的世界并非现实本身，而是媒介建构的图景。此说盛行于广播与电影初生的年代，彼时受众对新型媒介尚无免疫力，确有"一听即从"的现象。但随后更严谨的调查发现，所谓"子弹"大多被群体的盾牌所阻挡。

### 3.4 有限效果论与两级传播

1940 年拉扎斯菲尔德的伊利县研究是范式转折的标志。他发现媒介对选民的影响被一层"意见领袖"过滤：活跃阅读者先接触媒介，再以人际交谈将观点扩散给不那么活跃的人。

```
媒介 ──→ 意见领袖 ──→ 普通受众
            （两级传播）
```

| 命题 | 说明 |
|------|------|
| 两级传播 | 信息先达意见领袖，再经人际扩散 |
| 意见领袖 | 在某一议题上更关注媒介、更愿发声者 |
| 强化效应 | 媒介更多是强化既有态度，而非改变 |
| 选择性接触 | 受众倾向于接触与自己立场一致的媒介 |

有限效果论将媒介从"全能暴君"降格为"温和顾问"，在 1940–1960 年代占据正统地位。其隐含的方法论偏好是短期、可测的态度变化——这也恰恰是它后来被超越的原因。

### 3.5 适度效果论与议程设置

1968 年，麦库姆斯（M. McCombs）与肖（D. Shaw）在 Chapel Hill 研究中发现：报纸重点报道的议题，恰恰也是选民认为最重要的议题。由此提出议程设置假说：

> 媒介也许不能成功地告诉我们"怎么想"，但它在告诉我们"想什么"方面极为成功。

| 议程层次 | 内容 | 后续发展 |
|----------|------|----------|
| 议程设置（第一层） | 媒介决定哪些议题受关注 | McCombs & Shaw, 1972 |
| 议程设置（第二层） | 媒介决定议题的哪些属性受关注 | 属性议程 / 框架雏形 |
| 逆向议程设置 | 公众议程反过来影响媒介议程 | 互联网时代尤为显著 |

同期，卡茨（E. Katz）提出"使用与满足"理论，将视角从"媒介对受众做了什么"翻转为"受众用媒介做了什么"——人们主动选择媒介以满足信息、娱乐、社交或认同的需求。受众不再是靶子，而是消费者。

### 3.6 强大效果论与沉默的螺旋

1974 年，诺埃尔-诺依曼（E. Noelle-Neumann）提出沉默的螺旋假说：

| 要素 | 机制 |
|------|------|
| 害怕孤立 | 人有归属于群体的社会本能 |
| 准统计器官 | 人能直觉感知"意见气候" |
| 螺旋机制 | 感觉自己属少数派者趋于沉默，多数派愈发敢言 |

结果：媒介呈现的"多数意见"即使并非真实多数，也会因沉默螺旋而自我实现。此说揭示了媒介的长期、累积、结构化效果——它不改变一个个体，但能重塑整个意见生态。同期格伯纳（G. Gerbner）的涵化理论亦指出：长期收看电视者，其对社会暴力程度的认知会系统性偏离现实，趋向"险恶世界"的统一图景。

### 3.7 谈判式效果与使用与满足

1980 年代以后，效果研究进一步从"媒介中心"转向"受众中心"。霍尔的编码/解码理论（详见第四节）指出：受众对同一文本可采取主导式、协商式或对抗式三种解码立场，意义并非由文本单方面决定，而是文本与受众"谈判"的产物。这标志着效果观从"因果传导"走向"意义协商"，也为数字时代的受众主动性研究埋下伏笔。

### 3.8 实际应用

- **舆论监测**：议程设置理论指导议题热度与舆情走向分析
- **公共外交**：沉默的螺旋提示压制异见的"寒蝉效应"
- **健康传播**：有限效果论提醒，单纯信息投放不足以改变行为
- **算法推荐**：逆向议程设置在热搜与个性化推荐中反复上演

## 四、批判理论传统

### 4.1 概念动机

经验学派追问"传播效果如何"，批判理论则追问"传播何以成为统治的工具"。前者以量化为器，后者以思辨为刃。批判理论拒绝将既有媒介体制视为中性管道，而是将其置于资本主义权力结构中审视：谁拥有媒介？媒介生产了什么样的意识？这种意识服务于谁的利益？自法兰克福学派至文化研究，批判传统构成了一条与经验研究并行的理论河流。

### 4.2 法兰克福学派：文化工业批判

阿多诺（T. Adorno）与霍克海默（M. Horkheimer）在《启蒙辩证法》（1944）中提出"文化工业"（Kulturindustrie）概念：

| 维度 | 批判内容 |
|------|----------|
| 标准化 | 文化产品如工厂流水线，千人一面 |
| 伪个性化 | 表面给消费者"选择"，实则选项皆预设好 |
| 意识形态功能 | 娱乐使人安于现状，消解反抗意识 |
| 异化 | 受众沦为被动消费者，创造力被剥夺 |

文化工业论的要害在于：它指出大众文化不是"大众自发的文化"，而是"针对大众的工业"。阿多诺以爵士乐与好莱坞电影为靶，痛斥其以"娱乐"之名行"驯化"之实。此说常被批评为精英主义，却精准捕捉了文化生产的工业化逻辑。

### 4.3 哈贝马斯：公共领域理论

哈贝马斯（J. Habermmas）在《公共领域的结构转型》（1962）中追溯了一种理想型的传播空间：

| 要素 | 内容 |
|------|------|
| 公共领域 | 介于国家与私人之间的讨论空间 |
| 理性—批判辩论 | 参与者以论证而非身份说话 |
| 历史原型 | 十八世纪沙龙、咖啡馆、报刊 |
| 转型危机 | 商业化与国家化使公共领域"再封建化" |

哈贝马斯的核心忧虑是：当媒介从"理性辩论的论坛"沦为"展示权力的橱窗"，公民便从"讨论者"退化为"消费者"，民主的根基随之松动。他后期提出"交往行为理论"，将"以达成理解为目标的言语行为"视为人类解放的潜力所在。

### 4.4 政治经济学派：媒介垄断与商品化

政治经济学派聚焦媒介的所有权结构与资本积累逻辑。代表人物与命题如下：

| 学者 | 核心命题 | 要点 |
|------|----------|------|
| 斯麦兹（D. Smythe） | 受众商品论 | 媒介将受众注意力卖给广告商，受众即"被无偿劳动的工人" |
| 席勒（H. Schiller） | 文化帝国主义 | 西方跨国媒介将消费主义意识形态输出至发展中国家 |
| 莫斯可（V. Mosco） | 商品化三维度 | 媒介将内容、受众、劳动三者皆商品化 |
| 加汉姆（N. Garnham） | 垄断集中 | 媒介所有权集中于少数集团，危及多元表达 |

该学派的方法论偏好是政治经济分析——所有权数据、市场份额、资本流动——而非问卷调查。它揭示了一个朴素却常被遮蔽的事实：传播不是真空中的信息流动，而是嵌入资本结构的权力实践。

### 4.5 文化研究学派：霍尔的编码/解码理论

霍尔（S. Hall）在《编码/解码》（1973）中将结构主义符号学与意识形态分析熔于一炉：

```
生产环节（编码） → 文本（意义潜势） → 接收环节（解码）
   制度/话语        多义性            受众立场
```

| 解码立场 | 含义 | 举例 |
|----------|------|------|
| 主导式 | 全盘接受文本的 preferred reading | 观众认同主流新闻的官方解读 |
| 协商式 | 部分接受、部分修改 | 认可"守法"原则但质疑某一具体执法 |
| 对抗式 | 颠覆文本意图，读出相反意义 | 工人阶级将反映福利依赖的节目读为讽刺 |

编码/解码理论的意义在于：它既承认文本的意识形态倾向性（继承法兰克福的批判），又赋予受众主动解读的空间（超越法兰克福的悲观主义），由此在"被动受众"与"全能受众"两个极端之间开辟了第三条路。

### 4.6 费斯克：大众文化的乐观论

费斯克（J. Fiske）在《理解大众文化》（1989）中走向比霍尔更乐观的一端。他主张：大众并非文化工业的被动受害者，而是利用既有文本进行"符号游击战"的能动者。

| 概念 | 含义 |
|------|------|
| 符号抵抗 | 受众挪用、拼贴、戏仿主流文本以生产自己的意义 |
| 语义游击战 | 弱者利用强者提供的资源打一枪换一个地方 |
| 生产力 | 受众的解读本身即一种文化生产 |

费斯克的乐观常被批评为浪漫化——并非所有受众都有能力或意愿进行"抵抗式解读"。但他提醒我们：意义的生产不仅发生在编码端，也发生在日常生活的一次次挪用与重写中。

### 4.7 批判诸家对比

| 学派 | 核心问题 | 对受众的判断 | 方法论 |
|------|----------|-------------|--------|
| 法兰克福学派 | 文化工业如何驯化大众 | 被动受害者 | 哲学批判 |
| 哈贝马斯 | 公共领域何以衰落 | 理性辩论者（理想型） | 历史社会分析 |
| 政治经济学派 | 媒介所有权如何塑造内容 | 被商品化的注意力 | 政治经济分析 |
| 文化研究学派 | 受众如何与文本协商意义 | 主动解码者 | 符号学/民族志 |
| 费斯克 | 大众如何挪用文化谋反抗 | 符号游击队员 | 文化分析 |

### 4.8 实际应用

- **媒介批评**：以所有权数据揭露"信息多样性"的假象
- **受众研究**：编码/解码框架用于分析粉丝社群的二次创作
- **公共政策**：公共领域理论为公共广播制度提供正当性
- **文化外交**：文化帝国主义论提示国际传播中的不对称权力

## 五、信息处理与认知效果

### 5.1 概念动机

效果研究在 1970 年代以后逐渐从"态度改变"这一宏观指标下沉至认知的微观机制：人究竟如何处理一条新闻、一则广告、一个框架？信息进入大脑之后经历了哪些加工路径？为何同一则消息有人深究、有人略过，有人信服、有人抗拒？这一系列问题将传播学与认知心理学接驳，催生了信息处理取向的效果研究。

### 5.2 精细加工可能性模型（ELM）

佩蒂（R. Petty）与卡西奥波（J. Cacioppo）于 1986 年提出精细加工可能性模型（Elaboration Likelihood Model），将说服过程分为两条路径：

| 路径 | 特征 | 效果 |
|------|------|------|
| 中枢路径 | 仔细审视论据质量，依赖认知能力与动机 | 态度改变持久、能预测行为 |
| 边缘路径 | 依赖表面线索（信源吸引力、视觉、口号） | 态度改变脆弱、易被新线索推翻 |

个体走哪条路径取决于两个条件：**加工动机**（是否与己相关）与**加工能力**（是否具备相关知识、是否分心）。当动机与能力俱高，走中枢；当其一不足，走边缘。ELM 的实用价值在于：它告诉传播者何时应深耕论据、何时应打磨包装——高卷入产品靠数据说服，低卷入产品靠形象打动。

### 5.3 启发式-系统式模型（HSM）

蔡肯（S. Chaiken）于 1980 年提出与 ELM 平行的双加工模型：

| 加工模式 | 驱动力 | 特征 |
|----------|--------|------|
| 系统式 | 求准动机 | 系统评估论据，追求正确判断 |
| 启发式 | 认知省力 | 依赖经验规则（"专家说的对""多数人赞同的可靠"） |

HSM 与 ELM 在结构上相似，但 HSM 更强调两种模式可**同时**运行——人可能一边认真思考论据，一边无意识地依赖启发线索。两者共同奠基了当代"双加工"认知理论，并为卡尼曼的系统 1/系统 2 提供了先声。

### 5.4 框架理论

戈夫曼（E. Goffman）在《框架分析》（1974）中将框架定义为"人们用以理解情境的意义 schema"。恩特曼（R. Entman）进一步将其精炼为：

> 框架即"选择"与"凸显"——选取现实的某些方面，使其在文本中更为显著，以此定义问题、诊断原因、提出道德判断、示意 remedy。

| 框架功能 | 举例（以贫困报道为例） |
|----------|------------------------|
| 定义问题 | "贫困是个人懒惰" vs "贫困是结构不公" |
| 诊断原因 | "福利养懒人" vs "资本分配失序" |
| 道德判断 | "应缩减福利" vs "应扩大转移支付" |
| 示意对策 | "严审低保资格" vs "提高最低工资" |

同一事件经不同框架呈现，公众的理解与政策偏好可截然相反。框架与议程设置的区别在于：议程设置管"想什么议题"，框架管"怎么想这个议题"。

### 5.5 铺垫效应

艾英格（S. Iyengar）与金德（D. Kinder）在《事关重大》（1987）中通过实验发现：电视反复报道某一议题，会使受众在评价领导人政绩时，赋予该议题更高权重。

| 机制 | 说明 |
|------|------|
| 铺垫 | 媒体高频呈现的议题在记忆中更易提取 |
| 判断权重 | 评价整体表现时，可及性高的信息权重更大 |
| 累积性 | 效果非单次接触，而赖长期反复呈现 |

铺垫与议程设置常被并称，但二者有别：议程设置改变"重要性排序"，铺垫改变"综合判断的信息权重"。前者是态度的对象，后者是态度的形成过程。

### 5.6 第三人称效应

戴维森（W. Davison）于 1983 年提出：人们倾向于认为媒介对"自己"的影响小于对"他人"的影响。

| 维度 | 表现 |
|------|------|
| 认知偏差 | "这条广告骗得了别人，骗不了我" |
| 行为后果 | 因担心"他人被影响"而支持审查或管制 |
| 负面信息 | 对有害信息，第三人称效应更强 |
| 自我增强 | 此偏差服务于"我比大众更有判断力"的优越感 |

第三人称效应在互联网谣言、暴力内容管制的舆论中反复现身：人们一面自信能辨识假新闻，一面强烈主张"应封禁以免误导他人"。它揭示了一个传播学悖论——正是对"他人易受影响"的信念，反过来驱动了对媒介的管控冲动。

### 5.7 认知效果诸理论对比

| 理论 | 层次 | 核心机制 | 关键人物 |
|------|------|----------|----------|
| ELM | 个体说服 | 中枢 vs 边缘双路径 | Petty & Cacioppo |
| HSM | 个体说服 | 系统式 vs 启发式双模式 | Chaiken |
| 框架理论 | 文本—认知 | 选择与凸显塑造理解 | Goffman / Entman |
| 铺垫效应 | 议题—判断 | 可及性影响权重 | Iyengar & Kinder |
| 第三人称效应 | 认知偏差 | 高估对他人的影响 | Davison |

### 5.8 实际应用

- **广告设计**：ELM 指导高卷入品投论据型长文案、低卷入品投形象型短素材
- **舆论引导**：框架理论用于设计政策叙事的切入角度
- **假新闻治理**：第三人称效应提示，纠正"他人被误导"的信念比纠正信息本身更影响管制意愿
- **新闻编辑**：铺垫效应解释为何持续报道某一议题会左右领导人支持率

## 六、传播学在中国

### 6.1 概念动机

传播学作为一门源于西方的学科，其入华历程本身就是一次跨文化传播的案例。从 1978 年的"破冰"到今日的学科繁荣，中国传播学的发展既分享了全球学术的共同议题，也面对着本土语境的独特张力：如何在尊重学术普遍性的同时回应中国媒介体制与文化传统的特殊性？如何在接轨国际学术规范的同时保持理论自觉？这些问题贯穿了中国传播学四十余年的生长。

### 6.2 传播学引入中国的历程

| 时间节点 | 事件 | 意义 |
|----------|------|------|
| 1956 | 复旦大学郑学韬在《新闻学译丛》中首次介绍"群众传播" | 传播学概念初入华土 |
| 1978 | 郑北渭在《外国新闻资料》介绍西方传播学 | 改革开放后破冰之举 |
| 1982 | 施拉姆访华，讲学于北京、上海、广州 | 首位传播学奠基人系统授课 |
| 1982 | 第一次全国传播学研讨会（北京） | 学科建设的起点 |
| 1983 | 张隆栋主编《大众传播学》教材 | 首部系统介绍性教材 |
| 1997 | 国务院学位委员会将"新闻传播学"列为一级学科 | 学科建制的里程碑 |

施拉姆 1982 年的访华具有象征意义：学科奠基人亲自"播种"，此后中国学者赴美攻读传播学博士渐成潮流，"译介—消化—创新"的学术链路由此接通。

### 6.3 本土化探索

"传播学本土化"是贯穿中国传播学的核心议题，大致经历了三个阶段：

| 阶段 | 特征 | 代表努力 |
|------|------|----------|
| 译介期（1978–1990s） | 翻译引进西方经典 | 译介施拉姆、麦奎尔等著作 |
| 对话期（1990s–2000s） | 提出本土化命题，与西方理论对话 | 华夏传播研究、传播学中国化讨论 |
| 创新期（2000s 至今） | 基于中国经验提出原创概念 | 新媒体治理、网络舆论、平台研究 |

本土化的核心争论在于：是否存在一套"中国特色"的传播理论？乐观派主张从中国传统文化（如"言不尽意""辞达而已"）与当代体制实践中提炼概念；审慎派则担心"本土化"沦为学术保护主义，削弱理论的可比性与积累性。这一争论至今未决，但正是这种未决保持了学科的活力。

### 6.4 特色研究领域

中国传播学在以下三个领域形成了较为鲜明的研究取向：

#### 舆论学

| 维度 | 特点 |
|------|------|
| 历史渊源 | 与新闻学、政治学关系密切 |
| 核心议题 | 网络舆情监测、群体性事件的传播机制、舆论引导 |
| 方法 | 文本挖掘、情感分析、社会网络分析 |
| 张力 | 学术中立与政策应用之间的平衡 |

中国的舆论学既有与全球接轨的舆情监测技术，也有根植于社会治理需求的舆论引导研究，两者时有张力。

#### 网络传播

| 维度 | 特点 |
|------|------|
| 规模 | 中国网民逾十亿，全球最大的数字传播实验场 |
| 核心议题 | 算法推荐、平台治理、短视频传播、直播经济 |
| 概念创新 | "网络民族主义""数字鸿沟中国版""平台社会" |
| 国际影响 | 中国互联网研究成为全球传播学的新增长点 |

#### 国际传播

| 维度 | 特点 |
|------|------|
| 政策驱动 | "讲好中国故事""对外话语体系建设"等政策需求 |
| 核心议题 | 跨文化传播障碍、国家形象建构、国际舆论博弈 |
| 方法 | 比较内容分析、跨国调查、话语分析 |
| 挑战 | 意识形态差异、文化折扣、"他者"刻板印象 |

国际传播研究在中国兼具学术与战略双重属性，既是理论议题，也是国家软实力建设的实务。

### 6.5 学科建制化现状与挑战

| 维度 | 现状 |
|------|------|
| 学科地位 | "新闻传播学"为一级学科，下设新闻学、传播学等 |
| 培养体系 | 全国百余所高校设新闻传播学院，博士点数十个 |
| 学术期刊 | 《新闻与传播研究》《国际新闻界》《新闻大学》等 |
| 国际发表 | 在 SSCI 期刊的发表量持续增长，但话语权仍弱 |
| 方法训练 | 量化方法渐成主流，计算传播学方向兴起 |

挑战亦不容回避：一是**理论原创性不足**，大量研究仍在验证西方理论而非生成新概念；二是**方法与问题的张力**，数据驱动的计算传播学兴盛，但"大数据小问题"的批评亦随之而来；三是**自主性与普遍性的平衡**，本土化若走向封闭则失去可比性，全盘接轨则丧失理论自觉；四是**学术与实务的界限**，应用性研究丰富，基础理论建设仍显薄弱。

### 6.6 实际应用

- **舆情治理**：舆论学成果应用于政府舆情监测与应急响应
- **平台治理**：网络传播研究为算法监管与内容审核提供学理支撑
- **国际传播能力建设**：国际传播研究服务于对外媒体布局与文化外交
- **数字产业**：计算传播学方法被互联网企业用于用户行为与内容分发优化

## 结语

传播学自香农的一根电话线起笔，经拉斯韦尔的五字程式、施拉姆的学科大厦、法兰克福的批判锋芒、霍尔的编码解码、中国学者的落地耕耘，已长成一棵枝繁叶茂的大树。它的每一次理论推进，都在回应一个古老的困惑：**人何以能借符号而相通，又何以因符号而相隔**。从子弹到协商，从注射到满足，从议程到框架，从沉默的螺旋到算法的茧房——模型在变，但那个关于"信息如何塑造我们"的追问始终未变。也许传播学的终极启示恰恰在于：我们既是讯息的发送者，也是它的接收者，更是它最终的产物。
