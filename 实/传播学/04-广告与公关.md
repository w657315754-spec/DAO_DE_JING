# 广告与公关

> "广告是付费的传播，公关是信任的建构。" —— 化用伯内斯语

广告与公共关系同属"有意图的传播"，却各自开辟了一条通往公众心智的路径。前者以金钱购买注意力，以创意兑换记忆，在市场喧嚣中为商品与服务凿出一条认知通道；后者以关系经营声誉，以叙事塑造认同，在组织与其利益相关者之间编织一张信任之网。本篇自广告原理出发，经创意策划、品牌传播，转入公共关系原理与危机传播管理，终落于整合营销传播（IMC）——一个试图把所有声音调谐为同一和弦的现代框架。沿此脉络，可见商业传播自"叫卖"走向"对话"、自"单向说服"走向"双向建构"的整体演进。

## 一、广告原理与历史

### 1.1 概念动机

市场的根本难题是信息不对称：生产者知道自己的产品好在哪里，消费者却不知道。口碑太慢、包装太静、店面太窄——于是需要一种能够"主动触达、重复强化、劝服购买"的传播形式。广告由此而生：它是一种**由可识别出资人付费、通过非人际媒介传递、旨在影响认知与行为的信息**。其功能可概括为四：

| 功能 | 说明 | 典型表现 |
|------|------|----------|
| 信息告知 | 让受众知晓产品存在与属性 | 新品上市、价格、地址 |
| 劝服转化 | 改变态度、促成购买 | 对比广告、证言广告 |
| 提醒维持 | 维持品牌在心智中的显著性 | 节日广告、场景唤醒 |
| 价值附加 | 为产品赋予符号意义 | 形象广告、价值观营销 |

### 1.2 广告史：从叫卖到数字广告

广告的雏形早于印刷术——古希腊的叫卖者、宋代的酒幌与印刷招帖，皆是"人对人"或"幌对人"的低带宽传播。现代广告业的成形则与媒介技术同步：

| 时期 | 主导媒介 | 广告形态 | 标志事件 |
|------|----------|----------|----------|
| 17–18 世纪 | 报纸 | 文字分类广告 | 1622 年《伦敦周报》登广告 |
| 19 世纪末 | 报刊+路牌 | 插图广告、代理佣金制 | 1843 年费城第一家广告代理公司 |
| 1920s | 广播 | 声音广告、赞助节目 | 1922 年 AT&T 首播广播广告 |
| 1950s | 电视 | 影像广告、黄金时段 | 1941 年首条电视广告 |
| 1990s | 互联网 | 横幅广告、搜索广告 | 1994 年 AT&T 横幅广告 |
| 2010s 至今 | 移动+社交+算法 | 信息流、程序化购买、原生广告 | Facebook 精准投放、Google AdWords |

媒介的演进不断改写广告的逻辑：从"广而告之"走向"准而告之"，从"购买媒介"走向"购买受众"，从"打断式曝光"走向"嵌入式共生。

### 1.3 USP：独特销售主张理论

20 世纪 40 年代，罗瑟·里夫斯（Rosser Reeves）提出 USP（Unique Selling Proposition），其三条要义至今仍是广告创意的基石：

1. **每一则广告必须向消费者提出一个主张**——"买这个产品，你将得到这个利益"
2. **主张必须是竞争者所不能或未曾提出的**——独特
3. **主张要强到足以打动数百万受众**——即能拉动新增需求

经典案例是 M&M 巧克力"只溶在口，不溶在手"——把产品属性（糖衣包裹）翻译为消费者利益（不黏手），一句话区隔于所有竞品。USP 的局限在于：它假设产品本身存在实质差异，而在同质化严重的成熟品类中，差异往往需诉诸符号与情感。

### 1.4 品牌定位理论：里斯与特劳特

1969 年，里斯（Al Ries）与特劳特（Jack Trout）连载《定位时代来临》，正式宣告"产品中心论"让位于"心智中心论"。其要义为：**传播过载的时代，品牌须在消费者心智中占据一个独特位置（一个词、一种属性、一个品类）**。定位的法则包括：

- **抢先占位**：做品类第一比做得更好更易被记住（可口可乐=可乐）
- **重新定位对手**：借对手之势反衬自己（七喜"非可乐"）
- **关联强势者**：把自己与领导者并置（安飞士"我们更努力"）
- **品类分化**：在原品类中开创子品类并占首位（特斯拉=高端电动车）

定位理论把广告从"卖产品"升维为"经营心智资源"，深刻影响了此后的品牌战略与营销传播实践。

### 1.5 AIDA 模型与消费者旅程 AISAS

AIDA 由 E. St. Elmo Lewis 于 1898 年提出，描述消费者从接触广告到购买的心理阶梯：

```
Attention 注意 → Interest 兴趣 → Desire 欲望 → Action 行动
```

互联网时代，电通提出 AISAS，反映了搜索与分享两个新环节的嵌入：

```
Attention 注意 → Interest 兴趣 → Search 搜索 → Action 行动 → Share 分享
```

| 模型 | 时代背景 | 核心环节 | 对广告设计的启示 |
|------|----------|----------|------------------|
| AIDA | 大众媒介、单向传播 | 注意—兴趣—欲望—行动 | 强创意、强曝光、强诉求 |
| AISAS | 互联网、双向互动 | 加入"搜索"与"分享" | 需布局 SEO/内容、设计可分享触点 |
| 消费者旅程 | 全渠道、数字化 | 觉知—考量—购买—留存—拥护 | 接触点一体化、数据驱动运营 |

### 1.6 实际应用

- **新品上市**：以 USP 锤炼一句主张，以定位选定心智战场，以 AIDA/AISAS 设计传播节奏
- **品牌焕新**：借重新定位跳出价格战，把功能差异升维为意义差异
- **效果优化**：按消费者旅程各环节诊断漏斗，针对性补强触点

## 二、广告创意与策划

### 2.1 概念动机

广告要做两件事：被人看见，且被人记住并行动。前者是媒介的事，后者是创意的事。在信息过载的环境中，平庸的信息等于没有信息——创意因此不是"锦上添花"，而是穿透噪声的唯一杠杆。策划则是创意的"前置工程"：把模糊的市场问题，翻译为可执行的传播方案。

### 2.2 创意策略：理性诉求 vs 感性诉求

广告说服有两条主路：诉诸理性，或诉诸情感。二者并非对立，而是按品类、受众与情境配比。

| 维度 | 理性诉求 | 感性诉求 |
|------|----------|----------|
| 逻辑 | 给出功能利益、证据、对比 | 唤起情感、价值观、身份认同 |
| 语言 | 数据、演示、证言 | 故事、隐喻、氛围 |
| 适用 | 高卷入、功能差异大的品类（汽车、B2B） | 低卷入、差异小的品类（饮料、奢侈品） |
| 风险 | 枯燥、记忆度低 | 与产品脱节、徒有感动 |
| 案例 | 沃尔沃"安全测试" | 耐克"Just Do It" |

现代趋势是"理性内核+感性外壳"：用情感吸引注意、用故事承载利益、用数据建立信任。

### 2.3 广告表现手法

| 手法 | 机制 | 典型案例 | 注意事项 |
|------|------|----------|----------|
| 幽默 | 降低防御、提升记忆 | Old Spice 男士香水 | 易喧宾夺主、文化差异大 |
| 恐惧 | 唤起威胁、给出方案 | 公益戒烟广告 | 强度过高引发回避反应 |
| 性感 | 注意力捕获、联想转移 | 卡尔文·克莱恩内衣 | 伦理风险、品牌联想偏移 |
| 名人代言 | 借势光环、信任转移 | 乔丹与耐克 | 名人塌房连带品牌 |
| 故事性 | 沉浸、共情、记忆锚点 | 苹果"1984" | 制作成本高、信息需聚焦 |

手法的选择须服从策略，而非创意人的偏好——一条与策略脱节的精妙广告，是昂贵的失败。

### 2.4 广告策划流程

标准流程是一条从问题到评估的闭环：

```
市场调研 → 目标受众画像 → 创意简报(Brief) → 提案 → 投放 → 效果评估
```

| 环节 | 产出 | 关键问题 |
|------|------|----------|
| 市场调研 | 市场结构、竞品、趋势 | 品类处于什么阶段？谁在赢？ |
| 目标受众 | 人口+心理画像 | 我们对谁说话？他们的痛点与媒介习惯？ |
| 创意简报 | 一页纸的创意任务书 | 核心诉求是什么？希望受众感受/做什么？ |
| 提案 | 创意概念、分镜、文案 | 大创意是否足够"大"？是否可延展？ |
| 投放 | 媒介计划与排期 | 在哪里、何时、出现多少次？ |
| 效果评估 | 曝光/互动/销售指标 | 是否达成目标？哪些可优化？ |

创意简报（Creative Brief）是流程的"咽喉"——它把策略压缩为创意人可操作的几行字：目标受众、核心诉求、支持点、调性、必须出现的信息。一份好的简报，半条广告已成。

### 2.5 广告媒介选择与排期：GRP / 到达率 / 频次

媒介计划的核心是在预算约束下，把"对的广告"送到"对的人"面前"足够的次数"。三个关键指标：

| 指标 | 定义 | 说明 |
|------|------|------|
| 到达率 Reach | 在周期内接触过广告的受众占比 | 广度 |
| 频次 Frequency | 平均每人接触次数 | 深度 |
| GRP 毛评点 | 到达率 × 平均频次 | 总压力，如 60% × 5 = 300 GRP |

排期策略有三种典型模式：

- **连续式**：均匀投放，适合常年销售、维持显著度
- **起伏式**：集中脉冲，适合季节性、促销节点
- **脉动式**：基础连续+高峰脉冲，兼顾维持与爆发

媒介选择还需考量媒介权重（受众重合度）、CPM/CPC 成本、以及媒介本身的语境适配（奢侈品不投折扣感强的媒介）。

### 2.6 实际应用

- **快消品**：高到达率+低频次，依赖媒介组合覆盖广谱人群
- **耐用品/B2B**：低到达率+高频次，深耕垂直渠道与内容
- **数字时代**：程序化购买把 GRP 逻辑精细化到"人 × 场景 × 时机"

## 三、品牌传播

### 3.1 概念动机

广告解决"一次成交"，品牌解决"长期关系"。一个强势品牌能让消费者在看不到广告时仍愿意购买、在价格更高时仍愿意支付、在出现失误时仍愿意原谅。品牌传播的核心，就是有意识地经营这一层超越单次交易的"心智资产"。

### 3.2 品牌资产模型：Aaker 四维度与 Keller CBBE 金字塔

**Aaker（1991）四维度模型**——把品牌资产拆为可测量的四块：

| 维度 | 内涵 | 评估线索 |
|------|------|----------|
| 品牌忠诚度 | 重复购买、价格容忍 | 留存率、溢价意愿 |
| 品牌认知度 | 识别与回忆 | 提示/无提示回忆率 |
| 感知质量 | 主观品质评价 | 评分、NPS |
| 品牌联想 | 与品牌链接的属性、利益、人格 | 联想词云、映射图 |

**Keller（1993）CBBE（Customer-Based Brand Equity）金字塔**——自下而上六层：

```
           品牌共鸣 Resonance
          /              \
    感觉 Feelings    判断 Judgments
      /                    \
 表现 Performance   影像 Imagery
      \                    /
   品牌功效 Salience（品牌识别）
```

两层为"品牌认知"（这是谁），中层为"品牌判断与感觉"（它怎么样、我用着如何），顶层为"品牌关系"（我与它的共鸣）。模型强调：资产须从消费者心智中"自下而上"建构，而非靠广告"自上而下"灌输。

### 3.3 品牌个性维度：Jennifer Aaker 五因素模型

Jennifer Aaker（1997）借用"大五人格"框架，实证出品牌个性的五个维度：

| 维度 | 描述 | 典型品牌 |
|------|------|----------|
| 真诚 Sincerity | 务实、诚实、有益、欢愉 | 强生、可口可乐 |
| 刺激 Excitement | 大胆、活跃、富有想象力、前卫 | 红牛、维珍 |
| 能力 Competence | 可靠、智能、成功 | IBM、奔驰 |
| 精致 Sophistication | 上层、迷人 | 香奈儿、宝马 |
| 粗犷 Ruggedness | 户外、强韧 | 哈雷、Jeep |

品牌个性为创意提供了"人设锚点"：所有传播的调性、视觉、叙事都应与此一致，从而在消费者心中形成"一个人"般的稳定印象。

### 3.4 品牌延伸与子品牌策略

| 策略 | 做法 | 优势 | 风险 |
|------|------|------|------|
| 品牌延伸 Line/Category Extension | 把现有品牌名用到新品类 | 借势认知、降低上市成本 | 稀释原联想、失败反伤母品牌 |
| 子品牌 Sub-brand | 母品牌+新名，如"丰田·凯美瑞" | 兼顾继承与区隔 | 定位不清则两边不讨好 |
| 多品牌 House of Brands | 每个品类独立品牌，如宝洁 | 风险隔离、细分精准 | 资源分散、协同弱 |
| 担保品牌 Endorsed | 母品牌为子品牌背书 | 借信任、保区隔 | 母品牌出事则全盘受累 |

品牌延伸的"契合度"是成败关键：新品类须与原品类共享某一联想（技术、个性、利益），否则延伸无效甚至有害。

### 3.5 品牌危机管理案例：强生泰诺事件

1982 年，美国发生泰诺胶囊被投毒致 7 人死亡事件。强生作出教科书级反应：

1. **立即召回** 3100 万瓶、损失超 1 亿美元，不辩解
2. **主动披露** 信息透明、配合调查
3. **创新包装** 推出防篡改包装、改为胶囊片，重塑行业标准
4. **重建信任** 六周内恢复 70% 市场份额

此案成为"把消费者安全置于短期利润之上"的典范，亦是品牌资产能在危机中起缓冲作用的实证——多年积累的信任，使公众愿意给予第二次机会。

### 3.6 实际应用

- **新品牌**：先用定位选定心智位置，再用个性锁定调性，最后用资产模型监测健康度
- **成熟品牌**：定期审计四维度资产，识别弱项对症补强
- **延伸决策**：以"契合度+母品牌风险"两轴评估，宁可放弃不契合的机会

## 四、公共关系原理

### 4.1 概念动机

组织生存在一张由员工、客户、投资者、政府、媒体、社区构成的关系网中。任何一环的断裂都可能引发连锁危机。广告买得到曝光，却买不到信任；公关的核心，正是**通过经营关系与声誉，使组织获得可持续的合法性与善意**。它的职能包括：

| 职能 | 说明 |
|------|------|
| 媒介关系 | 与记者建立长期互信，争取正面报道 |
| 议程设置 | 议题管理、白皮书、行业话语权 |
| 内部传播 | 员工沟通、文化建设 |
| 投资者关系 | 与资本市场沟通战略与业绩 |
| 危机管理 | 预警、响应、恢复 |
| 社会责任 | 公益、CSR/ESG 叙事 |

### 4.2 伯内斯与公关职业化

爱德华·伯内斯（Edward Bernays）被尊为"公关之父"。1923 年他出版《塑造公众舆论》（*Crystallizing Public Opinion*），首次将"公共关系顾问"作为一种职业提出，并开设首门公关课程。其代表作"自由之火"（1929 年让女性公开抽烟，称之为"自由的火炬"）展示了公关"制造同意"的威力——也因而招致后世对其操纵伦理的批评。

伯内斯把公关从"粉饰"提升为"调适"：**组织须主动调整自身行为以适应公众，再借传播让公众理解组织**。这一"双向调适"的观念，是现代公关区别于早期"新闻代理"吹嘘术的分水岭。

### 4.3 PR vs Advertising 对比

| 维度 | 广告 Advertising | 公关 Public Relations |
|------|------------------|----------------------|
| 付费 | 付费购买媒介时空 | 多靠关系赢取报道（第三方背书） |
| 控制 | 对内容、版面、时间完全可控 | 内容由记者/平台决定，控制弱 |
| 可信度 | 受众知其为广告，信任度低 | 第三方叙述，可信度高 |
| 时效 | 投放即出现，停投即消失 | 效果累积慢、消退也慢 |
| 目标 | 促进销售 | 经营声誉与关系 |
| 衡量 | 曝光、转化、ROI | 提及量、声誉、议题占有率 |

二者互补：广告强于"说"，公关强于"被说"；前者可控，后者可信。

### 4.4 利益相关者管理

组织需识别并平衡多方诉求，其经典框架为"利益相关者地图"：

| 利益相关者 | 主要诉求 | 关系策略 |
|------------|----------|----------|
| 员工 | 公平、发展、归属 | 内部沟通、雇主品牌 |
| 客户 | 价值、安全、尊重 | 客户体验、服务响应 |
| 投资者 | 回报、透明、合规 | 定期披露、IR 会议 |
| 政府/监管 | 合规、税收、稳定 | 政府关系、政策参与 |
| 媒体 | 独家、真相、故事 | 媒介关系、新闻资料 |
| 社区/NGO | 环境、公平、公益 | CSR、社区共建 |

管理的要义是**优先级动态排序**：按"权力×合法性×紧迫性"识别关键利益相关者，集中资源经营。

### 4.5 PR 的四种模式

Grunig & Hunt（1984）依"方向性"（单向/双向）与"效果"（不平等/平等）划分四种公关实践：

| 模式 | 方向 | 目的 | 典型 |
|------|------|------|------|
| 新闻代理 Press Agentry | 单向 | 宣传、博眼球，不计真假 | 19 世纪马戏团炒作 |
| 公共信息 Public Information | 单向 | 真实但单向发布信息 | 政府新闻发布 |
| 双向不平衡 Two-way Asymmetrical | 双向 | 研究公众以说服之，利于组织 | 企业游说、议题营销 |
| 双向平衡 Two-way Symmetrical | 双向 | 组织与公众相互调适、共赢 | 卓越公关的理想型 |

双向平衡被视为"卓越公关"（Excellence Theory）的标杆，也是社交媒体时代组织难以回避的方向——因为公众已拥有发声通道，单向说服越来越行不通。

### 4.6 实际应用

- **企业公关部**：把媒体、政府、投资者、社区关系整合为统一职能
- **议题管理**：监测政策与舆论趋势，提前介入有利于组织的议程
- **雇主品牌**：以内部沟通与文化叙事吸引并留住人才

## 五、危机传播管理

### 5.1 概念动机

危机是"对组织声誉与运营构成重大威胁、需快速决策的非常规事件"。其特征是突发性、不确定性、威胁性、时间压缩。危机传播管理的目的不是"消灭新闻"，而是**在信息真空期迅速填补真相、在情绪沸腾期重建信任、在事后恢复期兑现承诺**。

### 5.2 危机的类型学

| 类型 | 特征 | 典型 |
|------|------|------|
| 技术危机 | 设备/系统故障、事故 | 核泄漏、飞机失事 |
| 人际危机 | 内部冲突、性骚扰、劳资 | 高管丑闻、罢工 |
| 道德危机 | 价值观失范、欺诈 | 财务造假、虚假宣传 |
| 自然危机 | 不可抗力 | 地震、疫情波及 |
| 故意危机 | 蓄意破坏、恐怖袭击 | 投毒、黑客攻击 |

类型不同，责任归属与公众期待亦不同：技术危机偏"能力追问"，道德危机偏"动机审判"，故意危机则更易获得同情。

### 5.3 库姆斯情境危机传播理论 SCCT

W. Timothy Coombs 提出 SCCT（Situational Crisis Communication Theory），依"责任强度"匹配不同回应策略：

| 责任强度 | 危机类型 | 推荐策略 | 说明 |
|----------|----------|----------|------|
| 弱 | 受害型（遭黑客、天灾） | 告知策略 Inform | 说明事实、提醒防范，少担责 |
| 中 | 意外型（事故、失误） | 调整策略 Accommodate | 表达关切、补偿、承诺改进 |
| 强 | 可预防型（失职、违规） | 指导策略 Instruct | 道歉、担责、整改、召回 |

误判责任强度是常见错误：明明是可预防型却用告知策略"轻描淡写"，会激怒公众、放大声誉损失。

### 5.4 危机前—中—后三阶段管理

| 阶段 | 重点 | 工具 |
|------|------|------|
| 危机前 Pre-crisis | 预警、预案、演练 | 风险清单、危机手册、发言人培训、舆情监测 |
| 危机中 Acute | 快速响应、统一口径、透明沟通 | 黄金 4 小时、单一发言人、事实+共情 |
| 危机后 Post-crisis | 兑现承诺、复盘改进、修复声誉 | 整改报告、第三方审计、长期 CSR |

危机前的预案投入，是危机中能否"扛住第一波"的关键；危机后的兑现度，决定信任能否真正回归。

### 5.5 5R 原则

危机响应常被概括为"5R"：

| R | 含义 | 实务 |
|---|------|------|
| Responsibility | 担责 | 不甩锅、明确责任主体 |
| Recognition | 承认 | 承认问题存在，不否认、不掩盖 |
| Reaction | 反应 | 快速、可见的行动 |
| Response | 回应 | 对所有利益相关者持续沟通 |
| Recovery | 恢复 | 兑现改进、修复声誉 |

其精神与 SCCT 一致：责任越重，担责与改进的力度须越大。

### 5.6 案例分析

**海底捞"后厨事件"（2017）**：媒体曝光后厨卫生问题，海底捞两小时内发布声明，以"这锅我背、这错我改、员工我养"三句话完成担责+整改+关怀。其成功在于承认迅速、措施具体、对人厚道——典型"可预防型+指导策略"的正解。

**丰田大规模召回（2009–2010）**：脚踏板卡滞引发加速失控。初期高层反应迟缓、信息混乱，被批"重利润轻安全"；后由社长丰田章男亲赴美国国会听证、流泪道歉、设立质量改革办公室，才逐步止血。教训：技术与规模越大的组织，越易因官僚惯性错过"黄金窗口"。

**BP 墨西哥湾漏油（2010）**：原油平台爆炸致 11 死、数月漏油。CEO 海沃德一句"我希望生活恢复正常"被视为冷血，"小人物"式轻佻沟通彻底毁掉 BP 声誉；公司最终付出超 600 亿美元代价。教训：危机发言人的共情与角色感，比公关辞令更关键。

### 5.7 实际应用

- **预案演练**：每年一次桌面演练，检验发言人、口径、跨部门协同
- **舆情监测**：关键词与情感监测，争取"第一小时"知情权
- **发言人制度**：统一口径、避免多头发声自相矛盾
- **事后审计**：复盘改进并公开，把危机转化为信任增量

## 六、整合营销传播 IMC

### 6.1 概念动机

20 世纪 80 年代，企业面临一个悖论：广告、公关、促销、直效、活动各成一摊，消费者却在同一时间被多个部门用不同声音"轮番轰炸"，结果不是强化而是相互消解。整合营销传播（Integrated Marketing Communications, IMC）由此而生——**以消费者为中心，把所有传播工具调谐为同一声音、同一形象、同一体验**。其演进分三阶段：

| 阶段 | 焦点 | 特征 |
|------|------|------|
| 1.0 协调传播 | 内部统一口径 | 广告与公关不再打架 |
| 2.0 消费者导向 | 围绕消费者旅程 | 按接触点配置工具 |
| 3.0 数据驱动 | 全渠道闭环 | 用数据实时优化触点组合 |

### 6.2 IMC 的 360 度品牌接触点

舒尔茨（Don Schultz）等人提出，消费者对品牌的认知来自其与品牌所有"接触"的总和，而非单条广告。360 度接触点可分六类：

| 类别 | 接触点示例 |
|------|-----------|
| 计划性传播 | 广告、公关、内容、社媒 |
| 产品体验 | 包装、功能、服务、售后 |
| 空间环境 | 门店、展会、办公区 |
| 人员互动 | 销售、客服、员工行为 |
| 数字触点 | 官网、App、搜索、社群 |
| 口碑与第三方 | 评测、KOL、UGC、新闻 |

IMC 的核心任务，是审计所有接触点的一致性：哪里断、哪里噪、哪里可加码。

### 6.3 消费者接触点管理 Touchpoint

接触点管理的标准流程：

```
识别 → 评估（影响力×体验分） → 优化 → 监测
```

| 步骤 | 产出 |
|------|------|
| 识别 | 列出全部现有/潜在接触点 |
| 评估 | 按影响力与体验评分，分四象限 |
| 优化 | 高影响低体验者优先整改 |
| 监测 | 持续追踪体验分变化 |

此法把"品牌体验"从模糊口号，变成可定位、可改造的具体清单。

### 6.4 社交媒体时代的口碑传播 WOM / eWOM

口碑（Word of Mouth, WOM）自古存在，因其来自熟人、可信度高，被视为最强说服形式。互联网把它放大并货币化：

| 维度 | 传统 WOM | 电子口碑 eWOM |
|------|----------|---------------|
| 传播范围 | 1 对 1，慢 | 1 对 N，指数扩散 |
| 留痕 | 无 | 评论、晒单永久留存 |
| 来源 | 熟人 | 陌生者+熟人混合 |
| 可测 | 难 | 可量化（评分、转发、情感） |
| 操纵风险 | 低 | 高（水军、刷评） |

eWOM 的网络结构特征（强弱连带混合）使信息既快又远，也使负面事件极易"破圈"——这是危机传播需前置到舆情监测的根本原因。

### 6.5 KOL / KOC 营销与种草经济

| 角色 | 定义 | 作用 |
|------|------|------|
| KOL（Key Opinion Leader） | 头部意见领袖、百万粉 | 制造曝光、塑造认知 |
| KOC（Key Opinion Consumer） | 真实消费者、千粉—万粉 | 真实评测、促转化 |
| 种草 | 以内容激发购买欲 | 缩短"兴趣—搜索"链路 |

种草经济的逻辑：在 AISAS 的 Search 环节埋下大量 KOC 真实内容，让消费者"搜到即被劝服"。其风险是过度商业化导致信任衰减——一旦被识破为"硬广伪装"，口碑红利反转为口碑负债。

### 6.6 ROI 与归因分析

数字传播带来了"可测性"福音，也带来了归因难题：一次购买可能横跨多个触点，功劳如何分配？常见归因模型：

| 模型 | 分配逻辑 | 适用 |
|------|----------|------|
| 末次点击 | 全归最后一次接触 | 简单、偏转化 |
| 首次点击 | 全归第一次接触 | 偏品牌拉新 |
| 线性 | 均分各触点 | 公平、失焦 |
| 时间衰减 | 越近权重越高 | 短决策周期 |
| 数据驱动 | 算法建模分摊 | 数据充足时最优 |

ROI（Return on Investment）的计算看似简单（收益/投入），难点在于"收益"是否计入品牌长期资产、口碑长效、组织学习等滞后效应——只看短期转化的 ROI，会系统性低估品牌与公关投资。

### 6.7 实际应用

- **预算分配**：以消费者旅程为骨架，把预算分摊到觉知—考量—转化—留存—拥护各环节
- **触点一致性审计**：定期核查所有触点的调性、主张、视觉是否统一
- **品效协同**：品牌广告筑认知，效果广告收转化，二者需共享同一人群与数据中台
- **长效评估**：建立品牌资产指标与短期转化指标的双轨看板，避免被短期 ROI 绑架

## 结语

广告与公关的演进，是一部"从说服到对话、从打断到共生"的传播史。广告以创意与媒介撬动注意，品牌以资产与个性沉淀心智，公关以关系与声誉经营信任，危机管理以担责与整改兑现承诺，IMC 则把这些声音调谐为和弦。媒介技术仍在加速：算法把"广而告之"改写为"准而告之"，社交媒体把"组织发声"稀释为"众声合唱"，AI 正在重塑创意生产与归因分析。但万变不离其宗——**传播的最终对象始终是具体的人，而人对真实、信任与意义的渴求，从未改变**。把握住这条主线，技术的潮起潮落便只是工具的更替，而非方向的重写。
