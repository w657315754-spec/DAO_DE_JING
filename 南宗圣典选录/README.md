## 南宗丹法核心脉络

### 传承谱系

```
刘海蟾 → 张伯端 → 石泰 → 薛道光 → 陈楠 → 白玉蟾
```

### 核心主张

1. **性命双修** — 性功（修心见性）与命功（炼精化气）并重
2. **先命后性** — 先从命功入手（炼精化气），再进入性功（明心见性）
3. **药在自身** — 金丹不在外求，就在自己的精气神中
4. **取坎填离** — 取坎卦中阳爻填入离卦中阴爻，恢复纯阳之体
5. **我命在我** — 「一粒金丹吞入腹，始知我命不由天」

### 丹法阶次

```
炼己筑基 → 炼精化气（小周天）→ 炼气化神（大周天）→ 炼神还虚 → 与道合真
```

### 玄关理解的演变

| 祖师 | 玄关观 |
|------|--------|
| 张伯端 | 肾前脐后为玄关（偏实体） |
| 石泰 | 只在当人一念前（开始心性化） |
| 薛道光 | 一念未生前便是（更明确的心性化） |
| 陈楠 | 只在一念未生时（同三祖） |
| 白玉蟾 | 一念未生则玄关自现，玄关者无念之念也（最精辟） |

可以看到从初祖到五祖，玄关的理解从具体的身体位置逐步演变为纯粹的心境状态，体现了南宗丹法越来越重视心性修养的趋势。
