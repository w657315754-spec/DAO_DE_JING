# 《红书与黑书》（The Red Book: Liber Novus & The Black Books）

> 成书：约1913–1930年代（手稿）｜全集卷号：未收入全集（由菲利蒙基金会独立整理出版）｜一句话定位：荣格"直面无意识"实验的原始记录与其艺术化重造——2009年《红书》问世、2020年《黑书》出版，改写了整个荣格研究的面貌。

---

## 一、成书背景

### 1913年：最艰难实验的开始

- 1912年《转化的象征》出版后，荣格与弗洛伊德决裂，失去学界位置，陷入深刻的内在危机。1913年秋起，他被一系列幻象（洪水、血河、末世景象）淹没，濒临精神崩溃。
- 他决定**主动迎上去**：有意识地唤起并进入幻象，同时保持清醒观察——这一方法后来被命名为**积极想象（active imagination）**。他把这段自我实验称为"与无意识的对峙"（confrontation with the unconscious），也是"我最艰难的一次实验"。
- 实验自**1913年11月12日**开始记录。第一篇黑书手记开篇写道：

> "我的灵魂，我的灵魂，你在哪里？你听见我吗？我说话，我在唤你——你在那里吗？我回来了，我又在这里了。我抖落了双足上所有土地上的尘土，来到你面前……"
> ——荣格，黑书第二册，1913年11月12日（据英译）

### 从黑书到红书

- 实验记录先写在一组笔记本中（后来统称**《黑书》**）：每日记录幻象、与内在人物的对话及自我反思。主要记录期为1913–1916年，其后断续记到至少1932年。
- 1914年一战爆发后，荣格意识到这些幻象不仅是个人性的，也与时代精神危机相关；1914年底至1915年，他把已完成的三册笔记整理成初稿并逐条加评论——这就是《红书》的雏形。
- 1915年11月起，荣格把选定材料以哥特式花体书法誊抄、彩绘进一部定制的红皮大开本（仿中世纪泥金手抄本），书脊烫金题作 **Liber Novus（新之书）**。誊抄工作持续约十五年，到1930年前后停笔——全书约三分之二的材料（约202页）完成誊抄，末句中断。

## 二、内容结构与核心思想

### 《红书》结构（三部分）

| 部分 | 名称 | 内容概要 |
|---|---|---|
| 第一部 | Liber Primus（《第一部》） | 序幕 + 11章："这个时代的精神"与"深层的精神"之分；寻找失落的灵魂；"神秘相遇"中遇见先知以利亚与盲女莎乐美 |
| 第二部 | Liber Secundus（《第二部》） | 21章："漫游者的意象"——沙漠中的隐修士阿莫尼奥斯、与"死亡"的相遇等冒险式对话 |
| 审视 | Scrutinies（Prüfungen） | 末部分，以《向死者的七篇布道》（Septem Sermones ad Mortuos）收尾——荣格生前唯一私下刊印的部分（1916年，笔名"亚历山大港的巴西里得斯"） |

### 双层结构（沙姆达萨尼的校勘结论）

- **第一层**：幻象本身，从黑书誊抄而来，仅有轻微编辑；
- **第二层**：荣格日后加入的评论与诠释。两层之别是解读全书的关键：前者是经验，后者是理论的胚胎。

### 主要内在人物

| 人物 | 角色 |
|---|---|
| 灵魂（Soul） | 荣格的阿尼玛形象，迫使他放下理性确定性、投身非理性 |
| 以利亚与莎乐美 | 老先知与盲女：智慧（逻各斯）与爱欲（厄洛斯）的一对 |
| 腓利门（Philemon） | 长着翠鸟翅膀、公牛角的老人，荣格的"内在导师"；向他证明：心灵中存在自我并不制造的内容——"思想可以自主发生" |
| 卡（Ka） | 大地性、本能性的形象，与腓利门的灵性互补 |
| 红者（the Red One） | 快乐、欲望与僭越的形象，挑战荣格的道德感 |

### 核心意义

1. **全部后期思想的种子**：原型、集体无意识、积极想象、个体化、阴影、阿尼玛——荣格日后所有主要概念都根植于此书记录的经验。
2. **方法的示范**：荣格在书中"发明并亲测"了积极想象，随后鼓励患者也制作自己的"红书"（据沙姆达萨尼）。
3. **"科学的"自我实验**：黑书不是日记，不记日常琐事，只记实验对象——幻象与心灵状态；其性质是"一位临床医生对自己做的实验记录，纪律近乎强迫症"（据 Dowling 专文）。

## 三、关键概念

| 概念 | 说明 |
|---|---|
| 直面无意识 | 1913–1916/1930年的自我实验总称 |
| 积极想象 | 清醒状态下唤起并对话幻象的方法 |
| 这个时代的精神/深层的精神 | 全书开篇的两大对立原则 |
| 内在人物的客观性 | 腓利门所示：思想有其自主性 |
| 曼荼罗 | 书中大量彩绘的整合性图像，个体化的象征 |
| 向死者的七篇布道 | 1916年幻象事件的产物；"死者从耶路撒冷归来，没有找到所寻之物" |

## 五、影响与评价

### 出版传奇

- 荣格生前未出版《红书》：他担心公众把它视为疯子的呓语，损害其"科学家"形象；但身边密友都曾被允许阅读，原稿还一度摆在诊室让患者翻阅。
- 荣格1961年去世后，继承人把《红书》锁进瑞士银行保险库数十年。2000年春，继承人协会经过激烈讨论，决定交由荣格学者**索努·沙姆达萨尼（Sonu Shamdasani）**编辑出版；谈判历时三年。
- 2009年10月7日，《红书》由 W. W. Norton（菲利蒙丛书）出版：大开本摹真版 + 平装读者版。首印仅6000册，旋即脱销——《纽约时报杂志》封面报道《无意识的圣杯》、美国国会图书馆与多家博物馆巡展助推，至第六次印刷已售出5万余册。
- 出版后，学界共识发生转向：荣格1913–1916年并非"精神病发作"，而是高度自觉的冥想式自我实验；《红书》成为重估分析心理学起源的基石文献。

### 《黑书》的补充价值

- 2020年出版的《黑书》揭示：《红书》约50%的文本直接取自1913–1916年黑书材料，编辑痕迹极轻；**未被收入红书的部分同样重要**——它们照亮荣格个人宇宙观的成形过程与"分析心理学的制造过程"。
- 研究者评价：黑书里是"未加伪装的荣格"——没有红书的神秘化装饰，只呈现一个困惑而诚实的人面对陌生内在风景（据 Applied Jung 书评）。
