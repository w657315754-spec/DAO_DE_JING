# 《人及其象征》（Man and His Symbols）

> 初版：1964年（荣格1961年逝世后出版）｜全集卷号：未收入全集（大众普及读物）｜一句话定位：荣格唯一一部专门写给普通读者的书，由1959年BBC电视访谈催生，他亲笔写完开篇章节后离世，弟子续成全书。

---

## 一、成书背景

### 缘起：一场电视访谈

- 1959年春，BBC邀请记者约翰·弗里曼（John Freeman）对荣格做一次电视"深度访谈"（节目《面对面》/ *Face to Face*）。访谈在荣格位于屈斯纳赫特（Küsnacht）苏黎世湖畔的家中进行，大获成功。
- 伦敦奥尔德斯图书公司（Aldus Books）常务董事沃尔夫冈·福格斯（Wolfgang Foges）在电视上看到荣格后，提议他为普通大众写一本书，用通俗方式传达其核心思想。
- 荣格起初坚决拒绝：他一生只写学术与临床著作，担心思想被简化歪曲。促使他改变主意的有两件事——一是BBC访谈后雪片般的读者来信，显示公众对他思想的真实渴求；二是**一个梦**：他梦见自己站在公共场所，对一大群聚精会神、理解力强的听众讲话。他把此梦视为无意识的确认，遂同意接手。

### 约定与分工

- 荣格的条件是：他只亲自撰写开篇第一章，其余四章交由他指定的四位亲传弟子完成，由约翰·弗里曼担任全书编辑协调，保证通俗而不走样。
- 四位合著者：玛丽-路易丝·冯·法兰兹（Marie-Louise von Franz）、约瑟夫·L·亨德森（Joseph L. Henderson）、乔兰德·雅科比（Jolande Jacobi）、阿妮拉·雅菲（Aniela Jaffé）。

### 荣格的最后写作

- 荣格于1961年初完成自己撰写的第一部分《探索无意识》（*Approaching the Unconscious*），这是他极少数直接用英文写就的文字之一。
- 1961年5月27日，荣格完成对手稿的最后一次修订；十余天后一病不起，于1961年6月6日辞世。荣格去世后，冯·法兰兹接手协调完成余下工作。全书1964年正式出版。

## 二、内容结构与核心思想

### 全书结构（五部分 + 结语）

| 部分 | 标题 | 作者 |
|---|---|---|
| 引言 | 本书缘起 | 约翰·弗里曼 |
| 一 | 探索无意识（Approaching the Unconscious） | **卡尔·荣格** |
| 二 | 古代神话与现代人（Ancient Myths and Modern Man） | 约瑟夫·L·亨德森 |
| 三 | 个体化的过程（The Process of Individuation） | 玛丽-路易丝·冯·法兰兹 |
| 四 | 视觉艺术中的象征（Symbolism in the Visual Arts） | 阿妮拉·雅菲 |
| 五 | 个体分析中的象征（Symbols in an Individual Analysis） | 乔兰德·雅科比 |
| 结语 | 科学与无意识 | 冯·法兰兹 |

### 各部分细目（据2023年中文版目录）

- **一、探索无意识**：梦的重要性／无意识的过去和未来／梦的功能／梦的分析／类型的问题／梦的象征中的原型／人类的灵魂／象征的作用／疗愈分裂
- **二、古代神话与现代人**：永恒的象征／英雄与英雄的缔造者／成人礼的原型／美女与野兽／俄尔甫斯与人类之子／超越的象征
- **三、个体化的过程**：心灵成长的模式／无意识初探／阴影的呈现／阿尼玛：内在的女性／阿尼姆斯：内在的男性／原我（自性）：完整的象征／与原我的关系／原我的社会面
- **四、视觉艺术中的象征**：神圣的象征：石头和动物／圆的象征／作为象征的现代绘画／万物隐秘的灵魂／逃离现实／对立的统一
- **五、个体分析中的象征**（一册完整案例记录）：分析的开始／初始之梦／对无意识的恐惧／圣徒与娼妓／分析工作的进展／占卜之梦／直面非理性／最终之梦

### 核心思想

1. **记号与符号的区分**（第一章开篇）。记号（sign）只是所指事物的标签；符号（symbol）则是"除约定俗成、一目了然的意义之外，还具有特殊内涵"的词、名或图像，指向理性尚不能完全把握之物。梦以符号的语言言说。
2. **梦是无意识的自然表达**。与弗洛伊德把梦当作"伪装的愿望"不同，荣格认为梦是无意识自发的、非伪装的象征性沟通，其首要功能是**补偿**意识态度的片面性，维系心灵整体平衡。
3. **无意识的两层结构**。个人无意识（被遗忘、压抑的个人材料）之下，还有更深的**集体无意识**——人类共同的精神地基，其内容即**原型**。这解释了互不相通的文明何以产生高度相似的象征意象。
4. **个体化（individuation）是全书纵贯线**。冯·法兰兹的第三部分系统展开：直面阴影→整合阿尼玛/阿尼姆斯→与自性（Self）建立关系→人格的整体化。
5. **现代人的精神危机源于与象征生活的断裂**。荣格认为，现代人过度依赖理性与技术，切断了梦、神话、仪式等象征渠道，导致心灵失衡；重新理解象征，是疗愈"时代病"的路径。
6. **图像即论证**。原版附有数百幅插图（绘画、雕塑、部落艺术、炼金术图、梦境绘画），这不是装饰：荣格坚持象征必须通过图像传达——概念说不出的，图像可以说。

## 三、关键概念

| 概念 | 书中含义 |
|---|---|
| 符号（symbol） | 指向未知之物的活的意象；与死的"记号"相对 |
| 梦 | 无意识的直接语言；补偿、预示功能 |
| 个人无意识 | 被压抑、遗忘的个人经验层 |
| 集体无意识 | 人类世代积淀的共同心理结构层 |
| 原型（archetype） | 集体无意识中的形式倾向，在各文化中反复生成典型意象 |
| 阴影（shadow） | 个体化第一步须面对的自身黑暗面 |
| 阿尼玛/阿尼姆斯 | 男性心中的女性面向 / 女性心中的男性面向 |
| 自性（Self） | 心灵整体的中心与原型；个体化的目标 |
| 个体化 | 成为"本来所是之人"的终身过程 |

## 五、影响与评价

- **荣格唯一的大众著作**。英国《卫报》评论（据中文版书讯转引）："这本书是荣格在1961年去世之前最后的作品，它是独一无二的——这是他第一次试着把自己毕生的心理学思想介绍给非专业领域的大众。"
- **入门经典的地位**。全书以梦为入口、以个体化为归宿，被公认为进入荣格思想的最佳起点；其"视觉化"写法使象征分析第一次以图文并茂的方式呈现。
- **跨文化影响**。据中文版书讯：本书已被译为近三十种语言，Goodreads 上评分长期保持高位，在美国心理类畅销榜常驻前列。
- **学术上的定位**：它不是教材，而是"一次对象征性思维如何运作的示范"；学界通常将其与《全集》（CW）区分开来阅读，但视其为荣格晚期思想的忠实通俗化（据 Thalira 书评）。
- **争议**：也有学者指出，通俗化不可避免带来简化；五位作者笔调不一，书中对艺术、宗教的个别论断带有时代局限（综合评价性说法，见 Thalira 书评）。
