# 《共时性》（Synchronizität als ein Prinzip akausaler Zusammenhänge）

> 初版：1952年（德文，收入荣格与泡利合著集《自然解释与心灵》，苏黎世：Rascher Verlag）
> 全集卷号：收入 CW 8《心灵的结构与动力》（*The Structure and Dynamics of the Psyche*）
> 一句话定位：荣格与诺奖物理学家泡利并肩二十余年的结晶——提出与因果律并列的"非因果性联系原理"，为有意义的巧合、占星与占卜提供自然哲学解释

---

## 一、成书背景

- **概念的萌芽（1920年代）**：荣格在使用《易经》蓍占与临床观察中，注意到卜卦结果与所问情境之间存在无法用偶然解释的对应。1930年，他在纪念汉学家卫礼贤（Richard Wilhelm）的悼辞中首次公开使用"共时性原理"（synchronistic principle）一词：
  > "《易经》的科学不建立在因果律之上，而建立在一个我们至今未曾命名的原理上——因为它对我们来说还陌生——我姑且称之为**共时性原理**。"
- **思想前驱**：莱布尼茨（经由《易经》与二进制的接触）、叔本华（《论个体命运中表面上的有意安排》中的"主观联系"）、开普勒的宇宙和谐观，以及保罗·卡梅雷（Paul Kammerer）1919年的"系列性"（Serialität）理论。
- **泡利合作**：1932年物理学家沃尔夫冈·泡利（Wolfgang Pauli）经荣格转介接受分析，此后两人通信长达二十五年（书信集《原子与原型》收录1932–1958年通信）。泡利认为亚原子粒子的悖论行为无法用经典物理的因果原理描述，力主心理学与物理学应当互补；正是他的催促与支持，促使荣格在1948年开始落笔。
- **"泡利效应"**：泡利对心-物相互作用有切身体验——据说他在实验室的出现常令仪器出故障，同事奥托·斯特恩（Otto Stern）甚至禁止他在实验进行时进入实验室。
- **《易经》的私人使用**：泡利本人就健康、婚姻、物理研究等事由长期蓍占，并在信中追问卦象的物理意义；约1950年他向荣格表示：占筮的结果落在一个"主体与对象、心理与物理的寻常区分不再完全有效"的实在区域（转述自《原子与原型》书信集）。
- **概念命名的斟酌**：荣格严格区分 synchronism（单纯的同时发生）与 synchronicity（以意义相连的同时性）；只有后者才是本书的原理性概念。
- **与占卜传统的对话**：荣格称占星与其他占卜术"堪称古代的科学"（1931年语），并注意到"今天绘制的星盘至少是三百年前的千倍"。
- **正式问世**：1951年，荣格在厄拉诺斯（Eranos）年会上作《论共时性》演讲，首次系统陈述；1952年，与泡利合著的《自然解释与心灵》（*Naturerklärung und Psyche*）在苏黎世出版：
  - 荣格论文：《共时性：一种非因果性的联系原理》（*Synchronizität als ein Prinzip akausaler Zusammenhänge*）
  - 泡利论文：《原型观念对开普勒科学理论的影响》

## 二、内容结构与核心思想

**定义**：荣格把共时性界定为

> "某一心理状态与一个或多个外部事件的**同时发生**，这些外部事件看似与当下的主观状态构成有意义的平行对应。"

并强调与单纯"同时性"（synchronism）的区别：共时性要求**意义**作为联系项，而非因果机制。

**三种形式**（依文中分类）：

| 类型 | 描述 |
|------|------|
| 一 | 心理内容与同时被感知的客观过程巧合（如正想着某人，某人来电） |
| 二 | 主观心理状态（梦/异象）与**远方**同时发生的客观事件吻合（传统上称心灵感应） |
| 三 | 梦/异象与**未来**事件的对应（预知梦等） |

**论证材料**：

1. **金甲虫案例**（全书最著名的段落，CW 8 §843-845）：一位深陷理性主义的女患者梦见有人赠她一枚金圣甲虫；她向荣格转述此梦时，窗外传来轻叩声——一只金龟子（玫瑰金龟 *Cetonia aurata*，本地最接近金圣甲虫的昆虫）正撞向玻璃。荣格开窗捉住它递给患者："这就是您的圣甲虫。"甲虫在埃及神话中是重生之神 Khepri 的象征；这一事件"戳穿了她的理性主义"，打破了治疗的僵局。荣格自述此类事件在其经验中绝无仅有。
2. **莱因（J. B. Rhine）超感官知觉实验**：杜克大学的卡牌猜测统计学证据，说明心灵似可超越时空——荣格引为支持性论据。
3. **占星统计实验**（"婚姻实验"）：荣格收集夫妻星盘（一说约483对，另说约300对随机抽样，数字记载不一，待核实），分三批检验传统占星学所重视的婚配相位。第一批出现与占星预期惊人吻合的日-月合相高比例；第二批却是月-月合相偏高，第三批为上升点-月亮合相偏高，三批合并后无任何单一构型具备统计学显著性。荣格并不视之为反驳，反而以"观察者被同步性现象卷入过程本身"解读实验本身的变形。
4. **占卜术**：《易经》、星盘、塔罗等被视为"古人关于自然的科学"——其操作原理不是因果而是共时性：占卜时刻的品质刻印在随机操作的结果上。

**合刊的另一半——泡利的论文**：《原型观念对开普勒科学理论的影响》论证：开普勒之发现行星运动定律，深受"宇宙必可按原型（几何-数学）模式理解"这一近于神秘的信念所塑造。两篇论文合刊并非偶然：荣格论证心灵一侧"有意义的巧合"，泡利论证物质一侧理论建构的原型根基，共同指向同一底层秩序。

**理论升华**：

- 意义（Meaning）是与因果性并列的自然**排列原理**；原型是激活共时性事件的深层结构。
- **单一体（Unus mundus）**：荣格沿用炼金术士多恩（Gerardus Dorn）的术语，主张心与物是同一底层实在的两个面向（双面一元论）；荣格-泡利的合作因此被称为"泡利-荣格猜想"。
- **与量子物理的呼应**：泡利认为经典因果框架不足以描述微观世界，心灵与物质须以互补方式理解；两篇论文合刊正是为了呈现"自然解释"与"心灵"的会师。

## 三、关键概念

| 概念 | 说明 |
|------|------|
| 共时性（Synchronicity） | 时间上巧合、因果上无关、以意义相连的事件对应 |
| 非因果性联系原理 | 与因果律互补的普遍原理，不推翻因果性而是为其划界 |
| 原型激活 | 共时性多在原型情境（危机、转化、个体化节点）中聚集出现 |
| 心理型（psychoid）层面 | 原型处于心物交界，既非纯心理亦非纯物理（本书暗示，术语的充分展开在其后著作，此处从简） |
| 单一体（Unus mundus） | 心物未分的原初统一，炼金术的遗产 |
| 占卜作为共时性技术 | 《易经》蓍占、占星等以随机程序"读出"当下时刻的品质 |
| 系列性（Serialität） | 卡梅雷（1919）提出的相似事件在时间上成簇聚集的假说，被荣格视为共时性的直接前驱 |
| 双面一元论 | 心与物是同一底层实在（单一体）的两个面向——其结构与当代泛心论、形态共振等学说的亲缘常被论者提及 |

## 四、经典引文

> "共时性……是两个或更多因果上无关、却具有相同或相似意义的事件在时间中的巧合；以此区别于单纯的'同时性'——后者仅仅指两个事件同时发生。"
> —— 荣格，《共时性》（1952）

> "我正背对关着的窗户坐着，忽然听到身后有轻微的敲击声。我转过身，看见一只飞虫从外面撞着窗玻璃。我打开窗，在它飞进来的瞬间将其捉住。那是在我们纬度能找到的、最接近金圣甲虫的东西——一只金龟子，常见的玫瑰金龟（Cetonia aurata）。……它一反常态，显然急于在这一刻进入这间暗室。我必须承认，这样的事在我此前此后的经验中从未发生过。"
> —— 荣格，《心灵的结构与动力》（CW 8，§843-845）

> "《易经》的科学不建立在因果律之上，而建立在一个我们至今未曾命名的原理上……我姑且称之为共时性原理。"
> —— 荣格，1930年卫礼贤纪念演讲

## 五、影响与评价

- **正面遗产**：共时性成为深度心理学的临床常用概念，被视为理解占卜、宗教体验与个体化转折不可或缺的一翼；现代心理占星学几乎完全建立在荣格对占星的共时性重构之上；"泡利-荣格猜想"与单一体思想持续激发当代心物问题的哲学讨论。
- **科学界的批评**：主流科学多批评其不可证伪，或将其解释为"模式错觉"（apophenia）与概率盲点；占星统计实验三批结果互相抵消，也常被引为反面证据。
- **历史评价**：有评论者称此论是荣格学说中"最危险"的一支——它使临床心理学公开跨入心物形而上学领域，也因此在他酝酿三十余年后才在泡利护航下正式发表。
- **荣格本人的担忧**：荣格自认是经验主义者（他最愿意别人用这个词形容他），深知此论会危及"来之不易的诚实、可靠与科学判断力的声誉"，但仍坚持如实报告观察所得。
- **澄清**：本书并不主张量子力学"证明"了共时性；泡利提供的是认识论上的互补性论证与对因果性适用界限的物理学内省。现象学论证（人们真实经验到的有意义巧合）通常被认为强于统计学论证（占星实验三批结果互相抵消即是例证）。
- **相关后续**：泡利-荣格书信集以《原子与原型》（*Atom and Archetype*，2001）出版；阿瑟·库斯勒（Arthur Koestler）《巧合的根源》（1972）与《助产士蟾蜍案》（1971）延续了对巧合与系列性现象的探讨。
