# 《回忆、梦、思考》（Memories, Dreams, Reflections）

> 初版：1961年（德文，荣格逝世后出版；版权页标注1961–1963）｜全集卷号：未收入全集（荣格特意指定）｜一句话定位：与阿妮拉·雅菲合作、以内在经历为主线的"心灵自传"，也是删节与争议最多的一部荣格遗作。

---

## 一、成书背景

### 缘起：爱诺思会议上的提议

- 1956年夏，在阿斯科纳（Ascona）举行的爱诺思（Eranos）会议上，出版人库尔特·沃尔夫（Kurt Wolff，Pantheon Books）表示希望出版一本荣格传记；荣格的同事乔兰德·雅科比（Jolande Jacobi）推荐由**阿妮拉·雅菲（Aniela Jaffé）**执笔。
- 众所周知荣格厌恶公开私生活，他犹豫良久才同意，并每周拨出一整个下午与雅菲工作——对年过八旬、极易疲劳的荣格而言，这是非常大的投入。
- 合作从1957年春天开始。形式上定为"自传"而非"传记"，由荣格本人作为叙述者；雅菲最初的任务只是提问与记录。

### 荣格的亲笔章节

- 1957年底，一系列自童年起长期潜伏的意象重新浮现，荣格决定亲笔写下早年回忆："把早年的回忆写下来，已经成了非做不可的事。如果哪天没这么做，就会立即出现让人不适的躯体症状。一旦开始动笔，这些不适都烟消云散。"
- 1958年4月，荣格完成前三章："童年""中学时代""大学时代"。
- 1959年1月，在波林根（Bollingen）审阅书稿时，他归还《论死后的生活》一章并对雅菲说："我心中有个地方被触动了，一种不一样的东西已经形成，我必须写下来。"于是有了**《晚期思想》**一章——全书最深邃的篇章。
- 雅菲在引言中说明：《西格蒙德·弗洛伊德》与《直面无意识》两章，她融入了荣格1925年研讨班的材料（荣格首次在课上谈及自己内在发展的场合）；《精神病治疗活动》一章基于1956年荣格与布尔格霍茨利医院年轻医生的谈话。

### 定位与命名

- 荣格从不把此书视为一份科学工作，甚至不认为是"他自己写的书"。他总说这是**"阿妮拉·雅菲的项目"**，自己只是有所贡献；在他的特别要求下，本书**未收入《荣格全集》**。
- 荣格读遍并审定了全部书稿，不时修正、补充；雅菲则用谈话记录补足荣格亲笔章节、删削重复。"工作越往后，他与我工作的融合就越紧密"（雅菲引言）。

## 二、内容结构与核心思想

### 全书结构

| 章节 | 内容概要 |
|---|---|
| 引言（雅菲） | 本书如何写成 |
| 序幕 | 荣格晚年的自我定位 |
| 一、童年 | 人格一号/二号的分裂；上帝幻象；湖畔刻木偶仪式 |
| 二、中学时代 | 学业、晕厥症与意志的自我克服 |
| 三、大学时代 | 医学与精神科的抉择 |
| 四、精神病治疗活动 | 布尔格霍茨利时期 |
| 五、西格蒙德·弗洛伊德 | 相识、合作与决裂 |
| 六、直面无意识 | 1913年后的自我实验（《红书》时期的自述） |
| 七、塔楼 | 波林根石屋作为自性的外化 |
| 八、旅行 | 普韦布洛印第安人、北非、肯尼亚与乌干达、印度、拉文纳和罗马 |
| 九、幻象 | 1944年濒死体验等 |
| 十、论死后的生活 | 对死后世界的思考 |
| 十一、晚期思想 | 上帝、恶、时间、心灵整体 |
| 回顾 | 一生总结 |
| 附录 | 弗洛伊德致荣格书信；致艾玛·荣格的信；卫礼贤小传 |

### 核心思想

1. **内在经历优先于外在事件**。雅菲问具体日期往往徒劳："只有他生命体验的精神实质留存在记忆中，也只有这个在他看来值得一说。"全书是"一束束快速移动的光"，照亮的是心灵世界而非履历表。
2. **"我的一生是无意识自我实现的故事。"** 这是全书的定调之句：荣格把生平理解为无意识逐步彰显自身的过程。
3. **根茎的比喻**：

> "生命就像以根茎来延续生命的植物，真正的生命是看不见、深藏于根茎的；露出地面的那部分生命只能延续一个夏季，随后便走向凋谢。然而，我从未失去的是埋藏于内心深处的无意识，它持续地在永恒的流动中生存。"
> ——荣格，本书开篇（据中文译本）

4. **人格一号与二号**贯穿全书：适应外界的少年与年长、亲近永恒的内在本性；这一童年发现后来发展为面具（persona）与阴影、个体化理论。
5. **《直面无意识》章**是理解《红书》的钥匙：荣格首次公开讲述1913–1918年与无意识的对峙及其理论后果（原型、集体无意识皆由此出）。
6. **晚期思想**：上帝与恶、时间的非实在性、心灵作为唯一可直接经验的实在——"心灵之外，别无实在"（大意，转述）。

## 四、经典引文

> "我的一生是一段无意识充分发挥的故事……"
> ——荣格（本书题记语，据中文译本）

> "我的作品常常是命中注定的。写作过程中有些事情无法预料……这本'自传'现在走向一个与我原先的想象大相径庭的方向。对我而言，把早年的回忆写下来，已经成了非做不可的事。"
> ——荣格，1957年底（雅菲记录的口述，据中文译本）

> "我用一台望远镜审视自己的心灵，从那些看起来茫无头绪的东西里，认出了美丽的星座，为意识增添了世间不为人知的东西。"
> ——柯勒律治《笔记本》（本书扉页题词，据中文译本）

## 五、影响与评价

### 删节争议

- 荣格1961年6月6日去世后，书稿在付印前遭到删改。据相关研究综述：荣格家庭（以女儿玛丽安娜·尼胡斯为首）要求删去可能损害其"严肃思想家"形象的内容——尤其是**与托妮·沃尔夫（Toni Wolff，荣格的长期合作者与恋人，1953年去世）相关的材料**、超常实验以及非正统的宗教观点。
- 出版人库尔特·沃尔夫又出于市场考虑进一步压缩，要求线性叙事、突出外在生平。荣格学者索努·沙姆达萨尼（Sonu Shamdasani）指出："沃尔夫想要的是他那个路数的第一人称自传……强调人格一号（外在人格）甚于把荣格与内在世界相连的人格二号。"
- 雅菲被夹在家庭体面与荣格信任之间。她在1961年的信中悲叹："我看起来要被从这本书里完全抹掉了，它将仅作为'C.G.荣格著'出版。"
- 被删材料中究竟包含多少、是否曾有独立的"托妮·沃尔夫章节"，各家说法不一，**完整清单待核实**；后来《荣格书信集》等文献的出版部分恢复了被删内容。

### 总体评价

- 本书被公认为荣格的**精神遗嘱**：它不追求"发生了什么"，而追求"它对我意味着什么"，开创了以内在经历为经线的自传文体。
- 学界提醒：因删节问题，应将本书与《荣格书信集》《红书》《黑书》互证阅读（当代研究综述观点）。
