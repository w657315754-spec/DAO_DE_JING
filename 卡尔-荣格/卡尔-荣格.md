# 卡尔·古斯塔夫·荣格 (Carl Gustav Jung)

> 1875年7月26日 – 1961年6月6日

瑞士心理学家、精神科医生，**分析心理学（Analytical Psychology）**的创始人。被认为是二十世纪最具影响力的思想家之一，其理论深刻影响了心理学、哲学、文学、宗教研究和流行文化。

---

## 一、生平概要

### 早年

- 出生于瑞士康斯维尔（Kesswil），博登湖畔的小村庄，父亲是乡村牧师
- 母系家族有深厚的神秘主义传统：外祖父萨缪尔·普莱斯沃克（Samuel Preiswerk）是巴塞尔归正会领袖、希伯来学者，笃信灵异现象；母亲艾米莉常自述夜间有"灵性"来访
- 自幼对神话、宗教、梦境和神秘现象有强烈兴趣
- 从小自觉内心住着**两个人格**："一号"是适应世俗的普通瑞士少年，"二号"则年长、孤僻、亲近自然、黑夜与梦——这种双重性贯穿了他毕生的思想
- 1900年获巴塞尔大学医学学位
- 1902年获苏黎世大学医学博士学位，论文题为《所谓神秘现象的心理学与病理学》，研究对象是自称能通灵的少女（其表妹海伦娜·普莱斯沃克）——这是他日后心灵理论的萌芽
- 早期在苏黎世布尔格霍茨利精神病院（Burghölzli）工作，师从院长欧根·布洛伊勒（Eugen Bleuler，"精神分裂症"一词的创立者）

### 布尔格霍茨利时期：词语联想实验与"情结"的发现（1903–1909）

这是荣格科学生涯的第一个里程碑，也是他日后全部理论的实证基础：

- 1903年起，荣格与助手弗朗茨·里克林（Franz Riklin）开展**词语联想实验**：向被试朗读约100个刺激词（如"面包""母亲""金钱""罪"），要求以脑中浮现的第一个词尽快回应，同时用秒表记录反应时间，并观察呼吸、皮肤电等生理反应
- 荣格发现：当某些词触碰到被试的情绪创伤时，回应会出现**延迟、重复刺激词、怪异回答、遗忘**等系统性紊乱，而且这些紊乱总是围绕特定的情感主题聚集
- 他将这些被压抑的、带有强烈情感色彩的心理聚集命名为**"情感色调的情结"（feeling-toned complexes）**，并留下名言：

> "人们'有'情结，这如今人尽皆知；但理论上更重要的是：**情结也会'有'我们**。" —— 荣格（《心灵的结构与动力》，CW 8, §200）

- 情结概念为弗洛伊德的"压抑"理论提供了第一个实验室证据。弗洛伊德本人视之为自己理论的实证支持
- 1907年，荣格赴维也纳拜访弗洛伊德，两人**首次会面即畅谈十三小时**
- 1909年，两人同赴美国，在马萨诸塞州**克拉克大学**讲学——荣格报告了词语联想研究，这是精神分析第一次系统地被介绍到美国
- 词语联想测验至今仍是少数经过统计验证、可用于支持精神分析模型的实验方法之一，后来还被引入司法领域用于测谎的雏形

### 与弗洛伊德的决裂

- 1906年，荣格阅读《梦的解析》后开始与弗洛伊德通信；弗洛伊德年长近二十岁，一度视荣格为精神分析的**"王储"与继承人**
- 但分歧从一开始就存在：关于无意识的本质、超常现象的意义、研究方法
- 1909年赴美航程中两人互相分析梦境，关系已现裂痕
- 1912年出版《力比多的转化与象征》（后修订为《转化的象征》），与弗洛伊德的泛性论产生根本分歧
- **核心分歧**：荣格认为力比多（libido）不仅是性驱力，而是普遍的心理能量；无意识不仅包含个人压抑的内容，还有更深层的集体维度
- 1913年正式决裂，此后经历了一段深刻的心理危机（"直面无意识"时期）

### 成熟期

- 1913年11月12日，荣格在书房中开始了直面灵魂的自我实验："我的灵魂，你在哪里？你听见我吗？……"——此后数月的一系列冥想式记录，构成**《红书》**的核心材料
- 1913-1918年间通过自我分析（记录梦境、幻象、积极想象）发展出核心理论；当代学界普遍认为这一时期并非精神病发作，而是深度冥想式的自我实验
- 这些记录1914年起被誊抄为手抄本**《新之书》（Liber Novus，即《红书》）**，配以亲手彩绘，工作持续到1930年代初；2009年才公开出版，其底稿《黑书》于2020年出版
- 1920年代起广泛游历考察：新墨西哥普韦布洛印第安人、东非埃尔贡人、埃及、突尼斯，1938年访问印度——在不同文化中寻找集体无意识的跨文化证据
- 1944年，荣格跌倒骨折后突发心脏病，陷入濒死状态，经历了一系列宏大幻象（自太空俯瞰地球、悬浮于宇宙庙宇之前）；这次体验深刻影响了他晚年关于心灵与死亡的思考
- 1948年4月24日，**苏黎世荣格学院（C.G. Jung Institute）**成立，系统培养分析心理学家，1953年颁发首批文凭
- 此后数十年致力于理论建构、临床实践和跨文化研究
- 晚年隐居苏黎世湖畔的波林根塔楼（Bollingen Tower）
- 1961年6月6日，逝于屈斯纳赫特（Küsnacht）家中，享年85岁

## 二、家庭与重要人物

荣格的思想不是在真空中产生的。他生命中几位关键女性与同事，深刻参与了他的理论形成：

| 人物 | 关系 | 说明 |
|------|------|------|
| **艾玛·荣格**（Emma Rauschenbach，1882–1955） | 妻子 | 沙夫豪森万国表（IWC）家族继承人；1896年与荣格相识（她14岁，他21岁），1903年2月14日结婚，育有五个孩子。她本人也是分析师与学者：1916年参与创立苏黎世心理学俱乐部并任**首任主席**，后任荣格学院副主席；著作《阿尼姆斯与阿尼玛》《圣杯传奇》（与冯·法兰兹合著）是分析心理学的重要文献。她去世后，荣格在其墓碑上刻下："你是我房屋的基石" |
| **托尼·沃尔夫**（Toni Wolff，1888–1953） | 学生、合作者 | 先是荣格的患者，1914年起成为他数十年的亲密合作者，荣格称她为"第二任妻子"。她的名篇《女性心灵的结构形式》（1956）提出女性心灵的四种结构：亚马逊、母亲、赫泰拉（伴侣）、媒介女性。1930年代，正是她把18岁的冯·法兰兹引荐给荣格 |
| **萨宾娜·斯皮勒林**（Sabina Spielrein，1885–1942） | 患者 → 学生 → 同事 | 俄裔犹太人。1904年因精神崩溃入住布尔格霍茨利，经荣格治疗后留院协助词语联想实验，后入苏黎世大学医学院。1911年以精神分裂症研究获医学博士——史上**第一篇出自女性之手的精神分析博士论文**。1912年发表《作为生成之因的毁灭》，比弗洛伊德早八年提出"死本能"雏形；弗洛伊德在《超越快乐原则》（1920）脚注中承认她"先行了一大部分我的思辨"。据斯皮勒林协会研究，她对荣格的阿尼玛、人格面具、阴影、个体化等概念的形成均有贡献。1942年与两个女儿一同被纳粹杀害于罗斯托夫 |
| **玛丽-路易丝·冯·法兰兹**（Marie-Louise von Franz，1915–1998） | 最重要的弟子 | 18岁起追随荣格，协助炼金术研究，后以童话分析和炼金术心理学著称，是荣格晚年学术遗嘱的主要继承者 |

## 三、核心理论体系

### 1. 心灵结构

```
意识（Consciousness）
  ├── 自我（Ego）—— 意识的中心
  └── 个体无意识（Personal Unconscious）
        ├── 情结（Complexes）
        └── 集体无意识（Collective Unconscious）
              └── 原型（Archetypes）
```

#### "集体无意识"概念的起源

- 在布尔格霍茨利时期，荣格观察到一位精神分裂症患者的幻象——"太阳悬垂着一根阳具，风吹动它，便产生了风"——与数年后才公开发表的古代密特拉教礼拜文书中的描述惊人一致。荣格在1959年BBC访谈中回忆此事，视之为超个人无意识存在的第一个证据
- 1936年伦敦讲演中，荣格给出了经典定义（《原型与集体无意识》，CW 9.1, §88）：

> "集体无意识是心灵的一部分，它可以通过否定性的方式与个人无意识区分：个人无意识的内容曾经被意识到，只是由于遗忘或压抑而消失；**集体无意识的内容则从未进入过意识，从未被个体获得，其存在完全归于遗传**。个人无意识主要由情结构成，集体无意识的内容则主要是原型。"

### 2. 原型（Archetypes）

原型是集体无意识中的先天模式，是人类共同经验的结晶。主要原型包括：

| 原型 | 含义 |
|------|------|
| **人格面具（Persona）** | 社会角色，对外展示的面孔 |
| **阴影（Shadow）** | 被压抑、否认的自我部分 |
| **阿尼玛/阿尼姆斯（Anima/Animus）** | 男性内在的女性面 / 女性内在的男性面 |
| **自性（Self）** | 心灵的完整统一体，个体化的终极目标 |
| **智慧老人（Wise Old Man）** | 智慧、指引、内在导师 |
| **大母神（Great Mother）** | 滋养、保护、也可能吞噬的原型 |
| **英雄（Hero）** | 克服困难、实现自我的旅程 |
| **骗子/恶作剧者（Trickster）** | 打破规则、带来转变的力量 |

### 3. 心理类型

荣格在《心理类型》（1921）中提出：
- **两种态度**：内倾（Introversion）vs 外倾（Extraversion）
- **四种功能**：思维、情感、感觉、直觉
- 组合形成 **8种心理类型**

> 这一理论后来成为 MBTI（迈尔斯-布里格斯类型指标）的基础

### 4. 个体化（Individuation）

荣格心理学的核心目标——成为完整的自己：

1. **认识人格面具** —— 区分"我是谁"和"我扮演的角色"
2. **整合阴影** —— 接纳被否认的自我部分
3. **与阿尼玛/阿尼姆斯对话** —— 整合内在异性面
4. **接近自性** —— 实现心灵的完整与统一

> "我宁愿完整，也不愿完美。" —— 荣格

### 5. 共时性（Synchronicity）

- 定义为"有意义的巧合"——内在心理状态与外在事件之间存在非因果性的对应关系
- 概念雏形约在1929年前后成形；荣格曾回忆，爱因斯坦多次在他家晚餐（与布洛伊勒等人），席间关于相对论与时间的讨论，启发了他对"时间的心理相对性"的思考
- 挑战了西方科学严格的因果律思维
- 这一概念与东方哲学（尤其是道家和易经思想）高度共鸣；其与物理学的深层对话见下文"第五节"

## 四、荣格与东方思想

### 荣格与道家

荣格是对东方思想最感兴趣的西方心理学家之一。他深入研究了中国道家、佛教、印度教和瑜伽传统，认为东方智慧与他的心理学理论在许多层面不谋而合。

#### 关键交汇点：

**1. 道（Tao）与自性（Self）**
- 道家之"道"——无形无名、万物之母、对立统一的整体
- 荣格的"自性"——超越意识与无意识对立的心灵整体
- 两者都指向一种超越二元对立的完整性

**2. 阴阳与对立面统一**
- 道家的阴阳互生、对立统一
- 荣格的"对立面整合"（conjunctio oppositorum）——个体化的核心过程
- 阴影的整合如同认识阴中有阳、阳中有阴

**3. 无为与积极想象**
- 道家的"无为"——不强为，顺应自然
- 荣格的"积极想象"（Active Imagination）——不干预无意识内容，让其自然涌现
- 两者都强调一种"有意识的放手"

**4. 内丹与个体化**
- 道家内丹修炼：精→气→神→虚
- 荣格的个体化过程：从意识碎片到心灵完整
- 荣格对《太乙金华宗旨》（The Secret of the Golden Flower）深感兴趣，认为其中的"金丹"象征自性的圆满

### 荣格与《易经》

荣格通过汉学家卫礼贤（Richard Wilhelm）的翻译接触《易经》，深受震撼：

- 1950年为卫礼贤的英文版《易经》撰写序言（长达60页）
- 认为《易经》是"探索命运与意义"的工具，而非简单的占卜
- 将《易经》的非因果性思维与"共时性"理论联系起来
- 认为易经的64卦是原型模式的系统化表达

> "易经是唯一一个让我承认因果律可以被超越的体系。" —— 荣格

### 荣格与《太乙金华宗旨》

- 卫礼贤将《太乙金华宗旨》译为德文，荣格撰写了长篇评述
- 荣格将"金华"（Golden Flower）解读为曼陀罗（Mandala）——自性圆满的象征
- 认为内丹修炼中的"回光"等同于心理学中的自我觉察（self-observation）
- 这一研究帮助他理解了欧洲炼金术的心理学意义

### 荣格与佛教/禅宗

- 荣格对禅宗有深入接触，曾与禅宗学者铃木大拙交流
- 认为禅宗的"开悟"（Satori）与个体化过程有平行关系
- 对藏传佛教的《中阴闻教得度》（Bardo Thödol）做了心理学评述
- 认为曼陀罗在藏传佛教和荣格心理学中都是自性的象征

## 五、荣格与现代物理学：与泡利的合作

这是荣格晚年最重要、也最鲜为人知的一段学术合作——**分析心理学与量子力学的正面相遇**。

### 泡利其人

沃尔夫冈·泡利（Wolfgang Pauli，1900–1958），量子力学奠基人之一，**不相容原理**提出者，1945年获诺贝尔物理学奖。

### 从患者到合作者

- 1930年前后，泡利深陷个人危机（酗酒、婚姻破裂、理性与无意识的严重撕裂），来到荣格处求治。荣格立即意识到他的梦材料的非凡价值——为避免自己"污染"数据，他让助手埃尔娜·罗森鲍姆（Erna Rosenbaum）先行分析
- 泡利留下了超过**八百个梦的记录**。这些梦自发涌现出曼陀罗、四位一体结构、炼金术意象——一个从未接触过炼金术的20世纪物理学家，梦中却出现了与16世纪炼金术士相同的象征系统。荣格将之作为《心理学与炼金术》（1944）的核心案例，视为原型不是文化产物、而是心灵先天结构的实证
- 两人关系很快从医患转为平等的学术对话，持续至1958年泡利去世，留下大量通信（后结集为《原子与原型》，80余封）

### 1952年合著：《自然解释与心灵》

两人唯一的合著（Naturerklärung und Psyche / The Interpretation of Nature and the Psyche），包含两篇互补论文：
- 荣格：《共时性：一个非因果性联系原理》
- 泡利：《原型观念对开普勒科学理论的影响》

### 核心思想

| 概念 | 内容 |
|------|------|
| **共时性与因果性互补** | 现实存在两种联系原理：因果性（能量传递）与共时性（意义性的巧合），二者互补，如同波粒二象性 |
| **一元世界（Unus Mundus）** | 借自16世纪炼金术士格哈德·多恩（Gerhard Dorn）：心灵与物质的分裂不是根本的，二者是同一个底层实在的两面显现 |
| **原型的"心理物理"中性地位** | 原型既非纯心理也非纯物理，而是居于心物之间的"心理因子"（psychoid），是秩序的共同根源 |

### 余波：CPT对称与"中国女子"

- 据科学史家阿瑟·米勒（Arthur I. Miller）的研究，泡利将自己后来关于**镜像对称与CPT对称**的思考，归因于与荣格的讨论以及一个"镜子房间"之梦
- 泡利梦中反复出现一位"中国女子"——荣格将其解读为泡利阿尼玛的整体性面向，因为中国哲学（阴阳）正是调和对立面的传统。多年后，恰是一位华裔物理学家吴健雄做出了关键实验
- 泡利生前对这段合作讳莫如深；他的葬礼上，其遗孀将荣格安排到了后排座位

### 与本知识库的呼应

"一元世界"（Unus Mundus）与道家的**天人合一**、本库"量子纠缠"专题所讨论的非定域关联，形成了跨越学科与文明的奇妙三角——荣格-泡利合作正是这一三角的西方科学支点。

## 九、在道德经/道家语境下的意义

荣格之所以出现在"道德经"知识库中，是因为他可能是**西方科学传统中最接近道家思维方式的学者**：

1. **超越二元对立**：荣格的"对立面统一"与道家的"有无相生"高度一致
2. **尊重无意识**：如同道家尊重"不可道"的维度，荣格认为理性有其边界
3. **象征性思维**：荣格用原型和象征理解心灵，如同道家用水、谷、玄牝等意象理解道
4. **实践性**：个体化不仅是理论，更是修炼——如同道家的修行传统
5. **整体论**：荣格追求心灵的完整，如同道家追求天人合一——而他与泡利共同阐发的"一元世界"（Unus Mundus），几乎就是"天地与我并生，万物与我为一"的西方科学版表述

荣格为东方思想在现代心理学中找到了科学的语言，同时也为西方心理学打开了一扇通往东方智慧的窗户。
