# 山中因子（Yamanaka Factors）

> 山中因子是指日本科学家**山中伸弥**（Shinya Yamanaka）于 2006 年发现的四个转录因子——**Oct4、Sox2、Klf4、c-Myc**（合称 **OSKM**）。将这四个因子同时导入成体细胞（如皮肤成纤维细胞），可以将其**重编程**（reprogramming）为类似胚胎干细胞的多能状态，称为**诱导多能干细胞**（induced Pluripotent Stem Cells, iPS 细胞）。
>
> 这一发现颠覆了「细胞分化不可逆」的传统认知，证明成熟细胞可以被「时光倒流」回到未分化状态。山中伸弥因此获得 **2012 年诺贝尔生理学或医学奖**。

## 四个山中因子

### Oct4（Pou5f1）

| 属性 | 内容 |
|------|------|
| 全称 | Octamer-binding transcription factor 4 |
| 基因 | POU5F1 |
| 功能 | 多能性的主调控因子，维持胚胎干细胞的未分化状态 |
| 表达 | 仅在胚胎干细胞和生殖细胞中表达，分化细胞中关闭 |
| 重要性 | **四个因子中最关键的一个**，缺失则重编程几乎不可能 |

### Sox2

| 属性 | 内容 |
|------|------|
| 全称 | SRY-box transcription factor 2 |
| 基因 | SOX2 |
| 功能 | 与 Oct4 协同作用，维持多能性和自我更新 |
| 表达 | 胚胎干细胞、神经干细胞、早期胚胎中表达 |
| 协同 | Oct4 和 Sox2 经常形成复合物，共同结合在 DNA 上 |

### Klf4

| 属性 | 内容 |
|------|------|
| 全称 | Krüppel-like factor 4 |
| 基因 | KLF4 |
| 功能 | 促进细胞增殖、抑制分化，协助打开多能性相关基因 |
| 表达 | 广泛表达，在干细胞中高表达 |
| 特点 | 相对「温和」的因子，可以被某些小分子药物部分替代 |

### c-Myc

| 属性 | 内容 |
|------|------|
| 全称 | Myc proto-oncogene protein |
| 基因 | MYC |
| 功能 | 强大的细胞增殖驱动因子，促进细胞周期和代谢重组 |
| 风险 | **已知的癌基因**，c-Myc 过表达显著增加肿瘤风险 |
| 争议 | 后来的研究发现，在某些条件下可以省略 c-Myc，虽然重编程效率降低，但安全性大幅提高 |

## 2006 年里程碑实验

### 论文

> Takahashi, K. & Yamanaka, S. (2006). "Induction of pluripotent stem cells from mouse embryonic and adult fibroblast cultures by defined factors." *Cell*, 126(4), 663-676.

### 实验设计

**核心问题：** 能否用少数几个转录因子将已分化的成体细胞「逆转」回胚胎干细胞状态？

**实验过程：**

1. **候选因子筛选** — 从 24 个在胚胎干细胞中高表达的转录因子开始
2. **逐步排除** — 每次去掉一个因子，观察是否仍能产生干细胞样集落
3. **最终确定** — 筛选出 4 个必要因子：Oct4、Sox2、Klf4、c-Myc
4. **验证** — 对这 4 个因子诱导产生的细胞进行全面的多能性检测

**验证标准（证明 iPS = ES）：**

| 验证项目 | 结果 |
|---------|------|
| 形态 | iPS 细胞与 ES 细胞形态相似（圆而紧凑的集落） |
| 表面标志物 | SSEA-1、Fbx15 等干细胞标志物表达阳性 |
| 基因表达 | 多能性基因（Nanog、Oct4 等）重新激活 |
| 表观遗传 | 多能性基因启动子区域去甲基化 |
| 分化能力 | 体外可分化为三个胚层（内胚层、中胚层、外胚层） |
| 畸胎瘤实验 | 注入免疫缺陷小鼠后形成包含三胚层的畸胎瘤 |
| 嵌合体 | iPS 细胞可参与嵌合体小鼠发育 |

### 效率

- 原始效率：**~0.01%**（每万个成纤维细胞中约有 1 个成功重编程）
- 后来通过优化培养基、添加小分子化合物等，效率提升到 **1-5%**

## 从 24 到 4：筛选逻辑

山中伸弥的筛选过程是一个经典的「减法实验」：

```
起始：24 个候选转录因子
  ↓ 全部导入成纤维细胞 → 少量干细胞样集落出现（Fbx15+）
  ↓
逐一去掉一个因子
  ↓ 去掉后集落消失 → 该因子为必要因子
  ↓ 去掉后仍有集落 → 该因子非必需
  ↓
最终：Oct4 + Sox2 + Klf4 + c-Myc = 4 个必要因子
```

**关键洞察：** 山中伸弥选择的初筛标志物是 **Fbx15**（而非 Nanog），Fbx15 阳性代表细胞进入了多能性状态。后来研究者们改用 Nanog 或 Oct4 作为筛选标志物，获得了更高质量的 iPS 细胞。

## 2007 年：人类 iPS 细胞

> Takahashi, K., Tanabe, K., Ohnuki, M., Narita, M., Ichisaka, T., Tomoda, K., & Yamanaka, S. (2007). "Induction of pluripotent stem cells from adult human fibroblasts by defined factors." *Cell*, 131(5), 861-872.

- 使用同样的 4 个因子（OSKM），成功将**人类皮肤成纤维细胞**重编程为 iPS 细胞
- 人类 iPS 细胞同样具有三胚层分化能力和畸胎瘤形成能力
- 这证明了 OSKM 重编程的**跨物种通用性**

## 后续重大进展

### 2008 — c-Myc 可省略

> Nakagawa, M. et al. (2008). *Nature Biotechnology*, 26(1), 101-106.

- 发现不使用 c-Myc 也可以生成 iPS 细胞（效率降低约 10 倍）
- 不含 c-Myc 的 iPS 细胞**肿瘤发生率显著降低**
- 实际应用中常省略 c-Myc 以提高安全性

### 2011 — 部分重编程与抗衰老

> 后续研究表明，短暂表达山中因子（不完全重编程）可以逆转细胞的衰老表观遗传标记，而不使细胞完全回到多能状态

- 这引出了「表观遗传重编程抗衰老」的全新研究方向

### 2013 — 化学重编程

> Hou, P. et al. (2013). *Science*, 341(6146), 651-654.（邓宏魁团队）

- 完全使用**小分子化合物**（不需要导入任何转录因子）即可实现细胞重编程
- 称为「化学诱导多能干细胞」（CiPS 细胞）
- 证明了山中因子的功能可以被小分子药物模拟

### 2016 — 体内重编程抗衰老

> Ocampo, A. et al. (2016). "In Vivo Amelioration of Age-Associated Hallmarks by Partial Reprogramming." *Cell*, 167(7), 1719-1733.（Belmonte 团队）

- 在早衰小鼠（Hutchinson-Gilford Progeria）中短暂表达 OSKM
- 结果：多个衰老指标改善，**寿命延长 30%**
- 关键：**短暂表达**（不导致完全重编程/肿瘤），只逆转表观遗传衰老标记

### 2020 — 表观遗传时钟逆转

> Lu, Y. et al. (2020). "Reprogramming to recover youthful epigenetic information and restore vision." *Nature*, 588(7836), 124-129.（David Sinclair 团队）

- 在小鼠视神经节细胞中表达 OSK（山中三因子，去掉 c-Myc）
- 成功**逆转了表观遗传时钟**，恢复了老年小鼠的视力
- 证明表观遗传重编程可以恢复特定器官的年轻功能

### 2022 — Altos Labs 成立

- 贝索斯（Jeff Bezos）等投资 **30 亿美元**成立 Altos Labs
- 核心研究方向：基于山中因子的**细胞重编程抗衰老**
- 聘请了山中伸弥本人作为顾问
- 成为抗衰老领域最大的单一投资

### 2024 — 人类 iPS 细胞临床试验

- iPS 细胞衍生的视网膜细胞移植治疗黄斑变性（日本理化学研究所）
- iPS 细胞衍生的多巴胺能神经元移植治疗帕金森病
- iPS 细胞衍生的心肌细胞片治疗心力衰竭

## 山中因子与衰老研究的核心关系

### 为什么山中因子与抗衰老相关？

传统理解：
- 细胞衰老 = 表观遗传标记的累积改变（DNA 甲基化模式漂移）
- 山中因子重编程 = **重置**表观遗传标记回到年轻状态

```
年轻细胞 → [衰老过程] → 衰老细胞
                              ↓
                    表达山中因子（短暂）
                              ↓
                    「部分重编程」细胞
                              ↓
                    表观遗传时钟回拨
                    衰老标记减少
                    功能恢复
```

### 「完全重编程」vs「部分重编程」

| 项目 | 完全重编程 | 部分重编程 |
|------|-----------|-----------|
| OSKM 表达时间 | 持续（2-3周） | 短暂（脉冲式） |
| 结果 | 回到多能干细胞状态 | 回到更年轻的体细胞状态 |
| 细胞身份 | 失去（变成干细胞） | 保持（还是原来的细胞类型） |
| 肿瘤风险 | 高（畸胎瘤） | 低 |
| 抗衰老价值 | 不适用（失去组织功能） | 高（恢复年轻功能） |

**核心挑战：** 如何在逆转衰老的同时保持细胞身份——即只「回拨时钟」而不「抹去记忆」。

## 与道教丹道思想的对照

山中因子的发现与道教内丹修炼思想之间存在着深层的共鸣：

| 山中因子/现代生物学 | 道教丹道思想 |
|-------------------|-------------|
| 成体细胞可被重编程为多能状态 | 「返老还童」「复归婴儿」的修炼理想 |
| 山中因子逆转细胞命运 | 丹道「逆则成仙」——顺则生人、逆则成道 |
| 细胞分化 = 表观遗传锁定 | 丹道「后天之气」遮蔽「先天之炁」 |
| 重编程 = 解除表观遗传锁定 | 丹道「取坎填离」恢复纯阳之体 |
| 四个因子协同作用 | 精、气、神三宝合一（三归一） |
| c-Myc 的风险（癌基因） | 命功修炼中的「火候」风险——过了就走火入魔 |
| 部分重编程（只回拨不抹除） | 丹道「炼神还虚」但不失人身——与道合真仍保持个体 |
| 山中因子可被小分子替代 | 「药在自身」vs 借助外药——殊途同归 |

**最深刻的对照：**

道教丹道认为人的生命是一个从先天到后天的「顺行」过程（道→一气→阴阳→五行→万物），修炼就是逆转这个过程（万物→五行→阴阳→一气→道）。山中因子在生物学层面实现了类似的「逆转」——将已分化的成体细胞逆转到未分化的多能状态。

丹经说「一粒金丹吞入腹，始知我命不由天」（张伯端），山中因子说「导入四个因子，细胞命运可以逆转」——两者都在表达同一个核心信念：**生命的既有轨迹不是不可改变的。**
