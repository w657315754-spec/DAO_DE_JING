# 善用其心

## 概述

《善用其心》是万行法师「三心」著作体系的第二部，2011年由新华出版社出版。本书是继《降伏其心》之后，万行法师于2008年至2010年间，在建寺安僧之余每晚共修时，针对四众弟子在信佛学佛、参禅打坐、为人处事等方面提出的问题所讲的开示合集。

如果说《降伏其心》教我们「降」，那么《善用其心》就是教我们「用」——降心之后，必经的用心阶段。

## 核心理念——「用心」

在三心体系中，「善用其心」对应**人生青壮年阶段**：学会如何善用自己的身口意，如何广结善缘，如何培植自己的福慧，如何为人类、为社会多做贡献。

### 为什么要「善用其心」？

- 降之不善用，为愚夫
- 心降伏之后，还要学会正确运用
- 佛法在世间，不离世间觉——心要在日用中体现

### 如何「善用其心」？

1. **觉照为纲**：万千法门不离觉照
2. **提起放下**：提起是为了放下，善用一切而不执着
3. **心为总开关**：心灵是万物的总开关，管好心即管好一切
4. **终点即起点**：每一次圆满都是新征程的开始

## 核心内容

### 学佛问答
- 针对四众弟子在修行中遇到的具体问题
- 家庭、工作、社会关系中的修行智慧
- 如何将佛法运用于现实生活

### 参禅指导
- 打坐中常见问题的解答
- 妄念与觉照的对治
- 不同修行阶段的注意事项

### 为人处事
- 如何在人际关系中修行
- 如何平衡学佛与家庭责任
- 如何在工作中保持觉照

### 融佛法于生活
万行法师坚持「以人为本」，将佛法与深奥的禅理融入生活，让弟子们在「农禅并重」的道风里，在「信教先爱国，学佛先做人，修道先发心」的家风下：

- 借人炼心
- 借事检心
- 堂上坐禅，堂下禅做
- 在工作中修行，在修行中工作
- 在降伏身心的同时，融入生活，融入自然，融入道
- 在消除自我的同时圆满自我

## 特色

- **问答形式**：一问一答，贴近弟子真实困惑
- **生活化**：将深奥禅理转化为生活智慧
- **觉照贯穿**：始终围绕「觉照」这一核心
- **温暖慈悲**：相比《降伏其心》的刚猛，《善用其心》多了几分柔和与引导
