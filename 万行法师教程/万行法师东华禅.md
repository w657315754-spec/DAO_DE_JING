# 万行法师 · 东华禅

## 一、万行法师生平简介

释万行，1971年6月出生于湖北省随州市的一个普通家庭。现任东华禅寺方丈、韶关市人大代表、中共中央党校慈善书画院常务理事、广东省佛教协会副监事长。

- **出家师承**：安景大和尚（浙江籍僧人），「万行」意为「行人所不能行，忍人所不能忍」
- **闭关因缘**：23岁在九华山遇空有老和尚，受其感召激发闭关之志
- **密法传承**：在西藏闭关期间结识拉蒙上师，得莲花生大士法脉真传

- **传法弟子**：东华禅寺四众弟子，遍布中国及东南亚

## 四、东华禅概述

### 4.1 东华禅的创立

万行法师根据三十年对佛法的修学和十多年真修实证的经验，汲取古人智慧精华，结合当代众生根基，创立了「东华禅」，延禅宗之血脉，续佛祖之慧命。

### 4.2 东华禅三大来源

| 来源 | 内涵 |
|------|------|
| **释迦牟尼佛的思想** | 以人为本，众生平等；以做人为基础，以成佛为目标 |
| **祖师禅的手法** | 不怕妄念起，只怕觉知迟；在行住坐卧中培养觉知、成为觉知、运用觉知 |
| **以人为本** | 借事炼心，觉悟人生，奉献人生 |

### 4.3 东华禅核心精神

**四大实践方针**：

1. **将信仰落实于生活** ——在工作生活中修行
2. **将修行落实于当下** ——当下即是道，当下即是修
3. **将佛法融入世间** ——佛法不离世间法
4. **将个人融入大众** ——在奉献中成就自我

**修行路径**：

- 在工作中修行，在修行中工作
- 在尽责中修福报，在觉照中修智慧
- 在奉献中修解脱

**四大关系**（需要通过修行调和）：

1. 我与家庭的关系
2. 我与社会的关系
3. 我与国家的关系
4. 我与自然的关系

### 4.4 东华禅的心法核心

| 阶段 | 核心 | 说明 |
|------|------|------|
| **降心** | 降伏其心 | 降伏贪嗔痴，显现戒定慧；自我反省就是修道，守住真心胜过所有法门 |
| **用心** | 善用其心 | 万千法门不离觉照；提起是为了放下，心灵是万物的总开关 |
| **无住** | 其心无住 | 一切境界皆是沿途风光；行藏有道，顺其自然，活在当下，用在当下 |
| **自在** | 心本自在 | 三心讲十年，悟则刹那间；降心为用，用了若无住，吾心本自在 |

> **其心大而无外，小而无内。大时包太虚，小时不容针。成事由其心，败事亦由心。**
> —— 万行法师

## 五、东华禅静功

东华禅静功是万行法师揉合**禅、净、密**三家法门的精髓而创编的，根据万咒之源「三字明」的咒语，结合「金刚诵」和「瑜伽诵」念咒法形成。

**原理**：人的身体如同一朵莲花——头是莲花苞，身体脊柱是莲花杆。通过莲花杆把莲藕（丹田）的大能量输送给莲花苞（头顶），花苞才能层层绽放。

### 5.1 打坐三调（基础预备）

打坐用功不外乎三个要素，无三调则十人九禅病：

#### 一、调姿势

| 姿势 | 说明 |
|------|------|
| **散盘** | 左右脚叉开，手搭膝盖上或大拇指交合置丹田下，肩自然垂 |
| **单盘** | 左脚放右大腿上，右脚压左腿下，左手托右手，脊柱立直 |
| **双盘** | 在单盘基础上右脚拉上，左手托右手，身体往前倾 |

**姿势要点**：

1. 肩要开、往下沉、自然垂直
2. 脊柱立直，身体微微前倾，重心落在两膝盖上
3. 臀下垫约2寸厚坐垫，尾巴骨悬空（避免压迫缺血、脑供氧不足）
4. 全身放松，面带微笑
5. 精神时闭眼，昏沉时睁眼（灵活运用）
6. 饭后半小时至一小时后再静坐
7. 舌顶上颚（年轻人可不顶；更年期过的人需舌底部顶住上颚）
8. 牙齿自然松闭合，腰带放松舒展

> **「在没有降伏你的心灵之前，先降伏你的双腿。」** —— 万行法师

#### 二、调呼吸

**调呼吸要领**：

1. 用鼻子吸，嘴巴呼
2. 气从鼻腔→咽喉→胸腔→丹田，在丹田停留3-5秒再呼
3. **呼气要把丹田的气呼干净**，肚子呼瘪，稍停顿再吸气
4. 反复做到丹田没气了、不能再呼了，才算调完呼吸
5. 调完后正式静坐呼吸顺其自然，鼻孔吸、鼻孔呼
6. 习惯于有意识地将呼吸沉入丹田

**对治方法**：

- **昏沉时** → 粗犷呼吸（快速产生氧气）
- **胸闷、眩晕、打嗝、胃胀、虚火时** → 深呼深吸，呼净丹田之气

#### 三、调意念

| 步骤 | 方法 |
|------|------|
| **1. 意念透过眉间往外看** | 意念不是「守」在眉间，而是「透过」慧眼往外看出去 |
| **2. 观想莲花开放** | 观想头顶一朵开放的莲花，脊柱是莲花杆，身体空掉成莲花 |
| **3. 保持觉照** | **觉是觉察，照是照顾**。对起心动念既能觉察到，也能照顾住 |

> **「八万四千法门离不开觉照，同样东华禅也是在觉照二字上面下功夫。」**

### 5.2 三字明咒 · 修行要诀

「嗡、嘎、吽」三字明是**万咒之源**，宇宙间万事万物的演变都在三个字中体现。

#### 念诵方法

| 步骤 | 操作 |
|------|------|
| **吸气** | 鼻孔吸气到丹田，肚子吸鼓，停留约10秒 |
| **念「嗡——」** | 呼气念「嗡」，注意力和观想在头部（囟门/顶轮），舌头平贴上颚 |
| **吸气** | 再吸到丹田 |
| **念「嘎——」** | 呼气念「嘎」，肚子念瘪，注意力仍在头部 |
| **吸气** | 再吸到丹田 |
| **念「吽——」** | 呼气念「吽」，舌头必须往上抬，气从头顶梵穴轮出去 |

> **关键**：舌头必须往上抬、平贴上颚。若舌头下垂，气就憋在口腔，不会通过气管上升至头顶。

#### 三字明含义（破 · 立 · 施）

| 字 | 含义 | 观想 |
|------|------|------|
| **嗡（破）** | 摧毁、清理 | 观想周围不好的磁场、旧思想、坏习惯、业力全部散开，黑色能量从体内释放到虚空 |
| **嘎（立）** | 建立、收获、成功 | 观想美好的白色能量从遥远天边包围过来，把全身灌满 |
| **吽（施）** | 分享、布施 | 观想能量从全身扩散，分享给周围和天下所有众生（最大的法布施）|

> **「你有多大的破，就有多大的立；有多大的立，就有多大的施。不破则不立，不立则无以施。」**

## 六、东华禅动功（莲花生大士动功）

万行法师在西藏闭关期间从拉蒙上师处获得莲花生大士法脉真传，其中包括一套动功。此套功法共 **七节**：

### 第三节「河住江翻」详解

这是七节动功中最关键的一节：

- 「河住」：前面的河流停止，不再漏掉
- 「江翻」：能量从下边翻到上边
- **核心理念**：「河住江翻水倒流」——逆流者为圣人，顺流者为凡夫
- 通过这一节打通尾闾骨，能量顺着后脊梁往上升

### 动功功效

- 三条脉（中脉、左脉、右脉）约**一年时间**可修通
- 即使不信仰宗教，也能强身健体、延年益寿、祛病健身
- 对于修道者，可高效提升能量

## 八、入定、住定、出定的秘诀

万行法师在《如何修炼东华禅》中详细开示：

### 入定
- 身心放松后，呼吸调柔，杂念渐息
- 逐步从粗住、细住进入欲界定、未到地定
- 不要急于求成，顺其自然

### 住定
- 安住在定的境界中，保持觉照
- **能觉也能照**才算功夫成片
- 功夫成片成势后才是「能所脱空知已灭」——身心都变成觉知

### 出定
- 听引磬声或自己作意出定
- 先在定中活动手指脚趾，再缓缓睁眼
- 不可猛然出定，避免头晕不适

## 十、常见问题解答

### Q1：什么是东华禅最核心的修行方法？
**A**：「不怕妄念起，只怕觉知迟。」在行住坐卧中培养觉知、成为觉知、运用觉知。核心是 **觉照**二字：觉是觉察，照是照顾。对起心动念既能察觉，也能照住。

### Q2：初学者打坐最需要注意什么？
**A**：三个要素——**调姿势、调呼吸、调意念**。特别是臀下要垫约2寸垫子，尾巴骨悬空，身体微微前倾。不要刻意追求双盘，自然进阶：散盘→单盘→双盘。

### Q3：念三字明时舌头为什么要抬起来？
**A**：舌平贴上颚，口腔下方的空间留出来，念咒时的音流振动才能从气管往上升至头顶梵穴轮。如果舌头下垂，气全部憋在口腔里，无法上行。

### Q4：修行中如何平衡出世与入世？
**A**：东华禅的核心就是「在生活中修行，在修行中生活」。「将信仰落实于生活，将修行落实于当下，将佛法融入世间，将个人融入大众。」真正的修行在生活之中，离世隐修只是一个短暂的阶段。

### Q5：万行法师说「农禅并重」是什么意思？
**A**：「堂上坐禅，堂下禅做，一日不作，一日不食。」白天出坡劳动（建寺、耕种），晚上参禅打坐。以农入禅，以禅耕农，农禅合一。

### 推荐学习顺序

万行法师的「三心」体系有严格的递进逻辑：**欲用先降，用过无住**。建议按以下顺序阅读：

```
心中月（起点）→ 降伏其心 → 善用其心 → 其心无住 → 心灯（圆满）→ 微言大义（日常）
                                     ↓
                           如何修炼东华禅（实操并行）
```

| 顺序 | 书名 | 定位 | 理由 |
|------|------|------|------|
| ① | **《心中月》** | 起点 · 证悟根基 | 闭关七年的第一手实录，是所有后续思想的总源头。先了解万行法师的证悟经历，才能理解他后来为什么这样讲法 |
| ② | **《降伏其心》** | 入门 · 降伏烦恼 | 三心第一步——先降伏贪嗔痴。不降心，一切修行无从谈起 |
| ③ | **《善用其心》** | 进阶 · 善用智慧 | 三心第二步——降伏之后，学会正确运用。欲用先降，这是必经之路 |
| ↔ | **《如何修炼东华禅》** | 实操 · 动静并行 | 与②③同步进行，学完降心、用心理论后立刻上手实修 |
| ④ | **《其心无住》** | 深入 · 放下执着 | 三心第三步——用过不留痕迹。一切境界皆是沿途风光 |
| ⑤ | **《心灯》** | 圆满 · 三心归一 | 历经降心、用心、无住之后，发现心本自在，三心本无差别 |
| ⑥ | **《微言大义》** | 日常 · 随时翻阅 | 精华语录集，作为日常提醒随身阅读 |
