## 书籍简介

《气功心法》是复旦附中语文教师孔宪德所著，由复旦大学出版社于 1990 年出版。孔宪德师承成都昭觉寺清定法师（学白骨观）和苏州灵岩寺明学方丈（学《观无量寿佛经》），融儒释道三家修行于一体。

王德峰教授（复旦大学哲学系）在公开视频中讲述孔宪德的"神通"事迹——他曾准确预测美国驻上海总领事妻子怀孕，复旦教师亲眼见证。复旦大学为其出版此书，堪称"认证过的修行者"。

本书系统阐述了气功修炼的理论与方法，涵盖正念修养、调身调息、经络疏通、站桩功法、坐禅功法、采气功法、减肥保健、祛病自强等内容，是一部非常全面的实修手册。

## 关键修行法门

### 观想法（核心法门）
孔宪德最擅长的法门。从《观无量寿佛经》学来，以"日观"（落日悬鼓）为起手。
- 正坐西向，观想落日
- 练到透墙可见落日 → 掌握透视
- 任何时候意念合一 → 遥视/预测

### 修行次第
```
调身 → 调脉 → 调息 → 六穴通明 → 经络畅达 → 站桩（罗汉神功）→ 坐禅（静定生慧）→ 采气（广采博收）
```

### 与《观无量寿佛经》的关系
书中"观想"法门直接来源于佛家《观无量寿佛经》的十六观。孔宪德跟苏州灵岩寺明学方丈学习此经，将观想法融入气功修炼体系。
